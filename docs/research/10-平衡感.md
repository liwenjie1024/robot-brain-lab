# 平衡感：机器人怎么知道自己快倒了

2026-11-09。用户问：机器人的传感器里有平衡传感器吗？

**有，但不是一个，而是一组。** 和人一样：
- 人的平衡感来自内耳（前庭）、脚底、肌肉和关节、眼睛，大脑把它们合在一起。
- 闭上眼睛单脚站会更难，就是因为少了一路。

## 1. 人和机器人的对应

| 人 | 感觉什么 | 机器人 | Nova 有的 |
|---|---|---|---|
| 内耳的半规管（三个，互相垂直） | 头怎么转（角速度） | **陀螺仪** | IMU 里都有 |
| 内耳的耳石 | 加速度和重力方向（哪边是下） | **加速度计** | IMU 里都有 |
| 脚底的感受器 | 脚底哪里受力 | **足底压力传感器** → 压力中心 | 每只脚：脚跟、脚掌、脚趾，含切向力 |
| 肌肉和关节的感受器 | 每个关节的角度和用力 | 关节编码器、电机电流 | 每个关节两个编码器 |
| 眼睛 | 地平线、周围在怎么动 | 相机（视觉里程计） | 两只眼、深度相机、事件相机 |

**IMU（惯性测量单元）是最接近"平衡传感器"的**：一个陀螺仪 + 一个加速度计（三个方向）。手机里也有，用来感知屏幕转向。

Nova 有 7 个 IMU：

| 位置 | 用来做什么 |
|---|---|
| 骨盆 | 平衡控制主要用这个（最靠近重心） |
| 头 | 相当于内耳：前庭眼反射（头动时眼睛反向转，视线不晃）、知道头的姿态 |
| 胸 | 上身的姿态 |
| 两手 | 手的动作快慢、碰撞 |
| 两脚 | 脚着地、打滑、脚的姿态 |

## 2. 从传感器到"快倒了没有"

这些传感器给的都是原始数据。脊髓层的状态估计把它们合在一起，算出下面几个量。小脑层靠这几个量保持平衡：

| 量 | 意思 | 从哪来 |
|---|---|---|
| 身体的姿态 | 身体前后左右倾了多少 | IMU（陀螺仪 + 加速度计融合） |
| 重心的位置和速度 | 全身质量的中心在哪、往哪动 | 关节角度 + 身体模型 + IMU |
| 压力中心 | 脚底受力的中心点 | 足底压力 |
| 支撑面 | 两只脚着地的范围 | 足底压力、脚的位置 |
| **捕获点** | "现在要站住，脚得踩到哪里" | 重心的位置和速度 |

判断方法：
- **站着不动**：重心落在支撑面里面，就不会倒。
- **动着的时候**：压力中心到了脚的边上，就快翻了。
- **最有用的是捕获点**：
  - 捕获点在脚底范围里：动动脚踝、晃晃身体就能站稳。
  - 在脚外面：**必须迈一步**，踩到捕获点附近才能停下。

这和人被推时的三种反应一样：

| 被推得多重 | 人的做法 | 机器人 |
|---|---|---|
| 轻 | 踝策略：只动脚踝 | 一样 |
| 中 | 髋策略：弯腰、摆身体 | 一样 |
| 重 | 跨步策略：迈一步 | 一样 |

用强化学习训练出来的平衡策略，会自己学出这三种做法，不用一条条写。

## 3. IMU 的几个坑（仿真里也要模拟）

| 问题 | 说明 | 怎么办 |
|---|---|---|
| 陀螺仪会漂 | 积分久了，角度慢慢偏掉 | 和加速度计融合（加速度计知道重力方向，能纠正前后左右的倾斜） |
| 水平方向的朝向会漂 | 加速度计纠正不了"朝哪个方向"（偏航） | 用视觉（视觉惯性里程计）或者磁力计纠正 |
| 加速度计分不清"加速"和"重力" | 突然加速时，会以为身体歪了 | 融合时结合腿的运动学和接触 |
| 冲击时会超量程 | 摔倒、落地时数值顶到头 | 选大量程（如 ±16 g、±2000°/s）；冲击时多信腿的数据 |
| 振动 | 电机和落地的振动混在信号里 | 机械减振 + 滤波 |

在仿真里，MuJoCo 的陀螺仪和加速度计给的是完美的数值。所以要自己加上噪声、零点偏移、漂移、量程上限和延迟，否则训练出来的策略到了真机上会出问题。

## 4. 建议给 Nova 加的三点

| 建议 | 为什么 |
|---|---|
| **骨盆放两个 IMU**，互相对照 | 平衡最依赖它。一个坏了或读数异常，另一个马上能发现、能接替（冗余） |
| **视觉惯性里程计** | 用两只眼的相机 + IMU，纠正朝向和位置的漂移。在家里长时间走动，要一直知道自己在哪、朝哪 |
| **脚底打滑反射** | 和指尖的防滑反射一样：足底的切向力突然变化 → 脊髓层马上调整（踝变硬、重心往回收），同时告诉小脑层。人踩到滑的地方，也是先反射，然后才意识到 |

都加上的话：IMU 从 7 个变成 8 个；视觉惯性里程计放进小感知模块；反射表里多一项"脚底防滑"。
