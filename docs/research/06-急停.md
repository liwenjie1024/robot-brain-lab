# 急停：肌肉结构会不会更好

2026-11-09。用户问：电机正反都能出力，但要急停的时候，肌肉结构会不会是更好的选择？

## 结论

**不会更好。** 设计得当的电机在急停上可以比人更快。真正决定急停好坏的是四件事，和"肌肉还是电机"关系不大：

1. **反应时间**
2. **等效惯量**：要刹住的东西有多重
3. **阻尼**：停下时会不会来回晃
4. **断电后的姿态**：人形机器人一断电就会倒

肌肉在急停上确实有三个长处，Nova 能学的都学过来：
- 被拉长时比主动收缩更有力
- 自带阻尼
- 惯量小

## "急停"有三种意思

| 意思 | 例子 | 难在哪 |
|---|---|---|
| A. 刹住一个动作 | 手臂挥到一半，前面突然出现人 | 反应快、刹得住 |
| B. 断电急停 | 按下急停按钮 | 断电后会怎样 |
| C. 整个身体停下来 | 走路中突然要停 | 平衡（这是控制问题） |

## A. 刹住一个动作：谁停得快

| | 人的肌肉 | 关节电机 |
|---|---|---|
| 反应时间 | 脊髓反射 30~50 ms；有意识的反应 150 ms 以上 | 1 kHz 控制，1~2 ms 内开始刹车 |
| 刹车力 | 肌肉被拉长时（离心收缩）的力约是主动收缩的 1.5 倍，刹车比发力更强 | 正反方向的峰值力矩一样 |
| 要刹住的惯量 | 只有手臂本身 | 手臂 + 转子惯量 × 减速比² |
| 阻尼 | 自带：肌肉被拉长越快，阻力越大 | 要靠控制或加阻尼器 |

### 举例（假设的数）

手臂绕肩的惯量 0.6 kg·m²，以 3 rad/s 挥动，肩用 120 N·m 刹车，电机转子惯量 1×10⁻⁴ kg·m²：

| | 减速比 15（Nova 的做法） | 减速比 100（谐波减速器常见） | 人 |
|---|---|---|---|
| 转子换算到关节的惯量 | 0.02 kg·m²（+4%） | 1.0 kg·m²（+167%） | - |
| 要吸收的动能 | 2.8 J | 7.2 J（转子里的比手臂本身还多） | 2.7 J |
| 开始刹车前多转的角度 | 0.3°（2 ms） | 0.3° | 7°（反射 40 ms）~ 26°（有意识 150 ms） |
| 刹车用的时间 / 角度 | 16 ms / 1.3° | 40 ms / 3.4° | 取决于用力 |

结论：
- **电机的反应比人快 20 倍以上。**
- **减速比越高，转子里存的动能越多，越难刹住。** Nova 用低减速比，电机靠近身体中心，所以手臂的等效惯量小。
- 弹簧有一个副作用：急停时弹簧会把能量弹回来，造成来回晃。所以弹簧旁边要并联阻尼器，控制里也要加阻尼。这和肌肉加肌腱一样：肌腱是弹簧，肌肉是阻尼。

## B. 断电急停：断电后会怎样

| | 断电后 |
|---|---|
| 人 | 昏倒时全身一软就瘫倒 |
| 气动、液压肌肉 | 泄压就瘫倒；阀门关住就僵住；液压还有漏液的风险 |
| 电机，能反推 | 瘫倒 |
| 电机 + 保持制动器 | 断电时立刻锁住，整个人僵住，可能像木头一样倒下 |
| 电机 + **短路制动** | 把电机的三根相线短接，电机就变成阻尼器，**不用电**。动得越快阻力越大，机器人会**慢慢坐下**，不是一下子瘫倒 |

**肌肉也没有更好的断电表现。** 人形机器人的难处在于：机械臂断电就停在原地，人形机器人一断电就会倒。
所以正在制定的 ISO 25785-1（用于靠主动控制保持平衡的工业移动机器人，包括双足的，还在委员会草案阶段）把摔倒和倾倒放在中心。

## Nova 的做法

1. **分级停止**（按 IEC 60204-1 的停止类别，改成适合人形机器人的做法）

   | 级别 | 做什么 | 什么时候用 |
   |---|---|---|
   | 2 类：受控停止，保持通电 | 站着不动、保持平衡 | 平时的"停" |
   | 1 类：受控停止后再断电 | 先停下动作，降低重心（蹲下或跪下），再断电并锁住 | 要断电的急停，首选 |
   | 0 类：立刻断电 | 每个驱动器立刻安全断扭矩（STO），同时短路制动，机器人慢慢坐下 | 硬件急停按钮；控制失灵时 |

2. **低等效惯量**：低减速比，电机靠近身体中心。前面的提案里已经是这样。
3. **阻尼**：控制里加阻尼；弹簧旁边并联阻尼器（踝、膝、足弓）。
4. **短路制动**：每个大电机断电时自动短路，让机器人慢慢坐下。
5. **保持制动器只装在少数关节上**：先短路制动让机器人慢慢坐下，停稳后再锁住，不让它僵着倒下。哪些关节装，用仿真实验定。
6. **刹车能量的去处**：平时回收到电池；电池断开或充满时，用制动电阻把能量烧掉。否则电压会冲高，把驱动器损坏。
7. **保护性摔倒**：实在要倒时，护住头、用手撑、顺势翻滚。这是训练出来的反射，属于第 1 层（脊髓）。
8. **看门狗链**：大脑 → 实时控制器 → 驱动器，每一级都定时报"我还活着"。哪一级停了，下一级就自动做受控停止。
9. **急停的入口**：机身上的急停按钮、无线急停，再加上全身触觉皮肤。用力撞到人时自动降级停止。

## 仿真里怎么验证

| 实验 | 比什么 | 测什么 |
|---|---|---|
| 手臂刹车 | 减速比 15 / 50 / 100 | 刹车的时间和角度、撞到假人时的力 |
| 弹簧加阻尼 | 只有弹簧 / 弹簧 + 阻尼器 | 急停后的晃动 |
| 断电 | 瘫倒 / 立刻锁住 / 短路制动 / 短路制动后再锁住 | 倒地时的冲击、头部的加速度、最后的姿态 |
| 受控停止 | 站着停 / 蹲下后断电 / 跪下后断电 | 停下用的时间、稳不稳 |
| 保护性摔倒 | 没有 / 训练过 | 头、手、关节受到的冲击 |
