## 1. 先看人们最想让机器人做什么

| 调查 | 结果 |
|---|---|
| YouGov（2025 年 1 月，美国 1247 人） | 想让机器人帮忙的：扫地拖地 93%、洗碗 87%、洗衣服 86%、收拾整理 86% |
| BEHAVIOR（Stanford） | 从约 2000 种日常活动里打分：最想要的几乎都是家务，最前面的是清洁（擦浴室地板等），最不想要的是娱乐 |

## 2. 第一个家："Nova 的第一个家"

按**中国城市常见的两室一厅**来做（约 90 m²）。

| 房间 | 里面有什么 |
|---|---|
| 门口 | 入户门、鞋柜、拖鞋 |
| 客厅 | 沙发、茶几（有抽屉）、电视柜、书架、收纳箱 |
| 餐厅 | 餐桌、4 把椅子 |
| 厨房 | 吊柜、地柜（门 + 抽屉）、水槽、冰箱（两扇门 + 抽屉）、微波炉、电饭煲、热水壶、洗碗机、垃圾桶 |
| 卧室 ×2 | 床、衣柜（门、抽屉、挂衣杆）、床头柜 |
| 卫生间 | 洗手台、马桶、毛巾架 |
| 阳台 | 洗衣机（前开门）、晾衣杆、衣架 |
| 楼梯（建议加） | 一段约 14 级的楼梯，通到阁楼或储物间。家里没有楼梯就考不了上下楼 |

**尺寸按中国住宅的常见值**：
- 房门约 80 cm 宽，卫生间门约 70 cm；Nova 肩宽 0.44 m，能过。
- 灶台和操作台约 80~85 cm 高，吊柜底约 1.5 m，餐桌约 75 cm，沙发座约 42~45 cm，床约 45~50 cm。
- 层高约 2.7~2.8 m；门槛 1~2 cm。
- 地面：客厅和卧室是木地板，厨房和卫生间是瓷砖，客厅有一块地毯。

**有中国家庭特点的家务**：
- 垃圾分类：可回收、厨余、有害、其他四个桶
- 筷子
- 在阳台晾衣服
- 用电饭煲
- 进门换拖鞋

**家里的人和宠物**：
- 2~3 个家人：成年人、老人、小孩。按脚本走动、坐下、说话（下指令）、接东西，偶尔挡路。
- 一只猫或狗。
- 第一版用简单的人形；以后换成我们自己动作捕捉录的人。

## 3. 第一批家务

**选的原则**：
- 人们最想要（收拾整理、洗碗、洗衣服、清洁）。
- 现在的仿真做得到：先只用硬的东西和能开关的家具，不用布料和水。
- 由易到难。

### 第一批：硬的东西 + 能开关的家具

| # | 家务 | 考的能力 |
|---|---|---|
| 1 | **收拾餐桌**：碗、盘、筷子、杯子放进水槽或洗碗机；剩菜的饭盒放进冰箱 | 抓各种形状的东西、开关电器、不打碎 |
| 2 | **整理客厅**：散落的东西放回原处（遥控器放茶几、书放书架、玩具放收纳箱、拖鞋放鞋柜） | 记住每样东西该放在哪 |
| 3 | **垃圾分类**：把垃圾分到对的桶里 | 认东西、常识 |
| 4 | **开关和取放**：从冰箱、柜子、抽屉里拿出指定的东西，用完放回去 | 有关节的家具、找东西 |
| 5 | **递东西**：听中文指令（"把遥控器拿给我"），找到、拿过去、递到人手里 | 对话、走动、交接 |
| 6 | **擦桌子**：用抹布把桌面擦干净 | 接触力的控制。第一版用硬的海绵块代替抹布；桌上的"脏"用标记表示 |

### 第二批：软的东西

| # | 家务 |
|---|---|
| 7 | 叠毛巾、叠 T 恤 |
| 8 | 把衣服放进洗衣机、拿出来 |
| 9 | 晾衣服：挂到衣架上，再挂上晾衣杆 |
| 10 | 铺床、换枕套 |

### 第三批：工具、水、做饭（以后）

| # | 家务 |
|---|---|
| 11 | 用吸尘器、拖地 |
| 12 | 洗碗（要先能模拟水） |
| 13 | 简单的做饭：用电饭煲煮饭、用微波炉热饭 |

**一轮家务**（连续 2 小时）：第一版由第一批的六项组成，乱的程度每次随机。

**能力证明**的题（站、走、楼梯、被推、摔倒后起来、蹲……）也在这个家里考。另加一块**体能场**：平地、坡道、台阶、球，考跑、跳、踢、扔。

## 4. 题目怎么写

用**我们自己的格式**写每道题，规约只写一处。
- 裁判程序和训练环境读同一个文件。
- BEHAVIOR 的任务描述语言（BDDL）可以参考。

每道题写清楚：

| 项目 | 内容 |
|---|---|
| 名字、批次 | - |
| 开始的状态 | 随机的范围：哪些物品、放在哪类地方、多乱、有没有人 |
| 完成的条件 | 从仿真状态自动判断：东西在某个容器里、门关着、桌上的"脏"都没了、东西在人手里 |
| 时间上限 | - |
| 不许发生的 | 安全事件、打碎、东西掉在地上 |
| 记的指标 | 按 Nova 考试的指标 |

例子：

```text
名字：收拾餐桌
批次：1
开始：
  餐桌上：碗 2~4 个、盘 1~3 个、筷子 2~4 双、杯子 1~3 个、剩菜的饭盒 0~2 个
  人：0~2 个在客厅走动
完成：
  所有碗、盘、筷子、杯子 在 水槽或洗碗机 里
  所有饭盒 在 冰箱 里
  冰箱门、洗碗机门 关着
时间上限：10 分钟
不许：安全事件、打碎、东西掉在地上
```

**怎么判"打碎"**：玻璃杯、瓷碗这类易碎的东西，各有一个能承受的撞击力上限；超过就算打碎。

**怎么判"擦干净"**：桌面上的"脏"是一些标记；用够大的力、擦到那里，标记才消失。

## 5. 难度、随机、不公开的考场

| 难度 | 内容 |
|---|---|
| 1 | 东西少、摆得整齐、光线好、没有人 |
| 2 | 东西多一些、有遮挡 |
| 3 | 很乱、有人走动、灯暗 |
| 4 | 再加故障：东西打滑、门卡住、传感器坏、通信变慢 |

**每次都随机**：物品的种类、位置、数量；家具的位置（小范围）；纹理；灯光；摩擦；质量。

**训练和考试分开**：
- 随机种子：训练用的和考试用的不重叠。
- **不公开的考场**：别的户型、别的装修风格，训练时从来不用，专门测"没见过的家"。
- 以后再加手机扫描的真实的家，做成照片级的考场。

## 6. 裁判和成本

- **判分全部自动**，从仿真的状态直接读，不信 Nova 自己报的。这和上一个项目一样：用身体报告的值，不用大脑数的值。
- **快考**：
  - 一个家，每批家务各一题，难度 1~2。
  - 几分钟。
  - 这台电脑上用同步方式跑。
- **全考**：
  - 多个家，全部题，难度 1~4，加一轮家务和不公开的考场。
  - 几个小时。
  - 放到云上并行跑。

## 7. 素材从哪来（要能商用）

| 素材 | 来源 | 许可证 |
|---|---|---|
| 房子的结构 | 自己的代码按户型生成（MjSpec） | 自己的 |
| 很多种不同的家 | Infinigen Indoors：程序化生成室内场景；Infinigen-Sim 生成能开关的门、柜子、电器 | BSD-3，可以商用。能不能直接导出成 MuJoCo 格式，只在第三方资料里看到，要实测 |
| 日用品 | Google Scanned Objects：1030 件扫描的日用品 | CC BY 4.0，可以商用（要注明出处） |
| 纹理、灯光 | 自己做的，或者 CC0 的素材库 | - |
| 参考 | ProcTHOR / AI2-THOR 的户型 | 代码和户型据第三方说是 Apache 2.0，自带物品的许可证要另查 |
| 只参考题目 | BEHAVIOR-1K | 素材要签另外的数据协议，条款没查到，所以不用它的素材 |

## 8. 先建哪些

| 版本 | 内容 | 什么时候 |
|---|---|---|
| v0 | 一个家（固定户型，代码生成）+ 第一批家务 + 简单的人 + 约 50 种物品 | 和 P1、P2 一起 |
| v1 | 很多个家（Infinigen 一类生成）+ 更多物品 + 不公开的考场 | 动作脑开始练的时候 |
| v2 | 软的东西（第二批家务） | 叠衣服之前 |
| v3 | 照片级的真实的家（手机扫描） | 视觉要从仿真转到真机之前 |

## 9. 要你定的

1. **第一个家**：中国城市常见的两室一厅，约 90 m²，阳台放洗衣机和晾衣杆。可以吗？要加一段楼梯吗？
2. **第一批家务**：收拾餐桌、整理客厅、垃圾分类、开关和取放、递东西、擦桌子。可以吗？
3. **题目**用我们自己的格式写，裁判从仿真状态自动判。可以吗？
4. **素材**：自己生成 + Infinigen + Google Scanned Objects；BEHAVIOR-1K 只参考题目。可以吗？
5. **考场分四步建**（v0~v3）。可以吗？
6. **家里的人**：先用简单的人形，按脚本走动、说话、接东西；以后换成动作捕捉录的人。可以吗？
