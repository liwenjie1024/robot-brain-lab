## 2. 看得出的共同方向

1. **驱动分成两类，按关节的动作分工**
   - 旋转型：无框电机 + 减速器。行星减速（准直驱）能反推、抗冲击，Unitree 用这种；谐波减速精确，但薄的柔轮怕摔。
   - 直线型：电机 + 行星滚柱丝杠。抗冲击、几乎没有间隙、能自锁，用在腿这种负载大的地方。
   - 趋势是"转的关节用旋转，伸缩的动作用直线"。直线推杆就像一块能伸缩的肌肉。
2. **手的电机移到前臂，用肌腱拉手指**
   - Optimus V3、1X NEO 都这样做，和人的手一样（手指的肌肉大部分在前臂）。
   - 手的自由度都向人靠：约 22 个。
3. **触觉集中在指尖和手掌**：Figure 能感到约 3 克的力；Atlas 有手掌感知。Figure 还把相机放进手掌，用来近距离看。
4. **自由度越来越多**：从 20~30 个增加到 56（Atlas）、82（IRON）。多出来的主要是手、脊柱、肩胛。
5. **像人的方向和超人的方向并存**
   - 像人：IRON 的脊柱和肩胛、NEO 的软身体、Clone 的肌肉。
   - 超人：Atlas 的关节能 360° 转，人做不到。
6. **家用机器人看重安全**：NEO 用低减速比 + 肌腱，又轻又软，被碰到或夹到也不伤人。

## 4. 对 Nova 的启发

1. **"伸缩自如的关节"有现成的方向**：膝、踝这类伸缩动作，可以用直线推杆当肌肉（像 Optimus 的腿）；转动用旋转电机。可以和 [多电机关节](02-多电机关节.md) 的方式 E（直线推杆当肌肉）一起讨论。
2. **手**：电机在前臂 + 肌腱，约 22 个自由度。每条手臂约 25 个驱动器，可以拿 Optimus V3 的专利当参考。和 02 文档的方向一致。
3. **肩胛和脊柱要重新考虑**。第一轮调研说第一版不做肩带，但 IRON 已经做了 4 个自由度的肩胛和仿生脊柱。Nova 的目标是成人大小、完全像人，可以考虑第一版就加上。
4. **安全**：如果以后要在人身边，低减速比 + 肌腱 + 软外壳（NEO 的做法）值得参考。
5. **研究方法**：先把 Menagerie 里的 G1 模型拿来，看真机的关节排法和质量分布，再定 Nova 的。
