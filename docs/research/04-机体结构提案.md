# Nova 机体结构提案 v0

状态：**提案，待讨论**。2026-11-09。
依据：[第一轮调研](01-第一轮调研.md)、[多电机关节](02-多电机关节.md)、[领先公司的机器人构造](03-领先公司的机器人构造.md)，加上人体测量学数据。
人体数据来自教科书：各段质量比例 de Leva 1996，各段长度比例 Winter（引自 Drillis & Contini），关节活动范围用常见的成人值。
力矩、质量都是**初估**。P1 在仿真里按目标动作实测后再定，然后才去选能买到的驱动器。

这份取代第一轮调研 2.2 节的自由度分配。

## 0. 一句话

- 成人大小：1.70 m、65~70 kg，比例照人。
- **86 个自由度**（身体 42 + 两手 44），**76 个驱动器**。
- 转动用旋转电机，伸缩用**直线推杆（像肌肉）**。
- 手的电机全部在前臂，用肌腱拉手指。
- 电机尽量放在靠近身体中心的地方，手和脚做轻。

```text
Nova（86 个自由度 / 76 个驱动器）
├─ 头：颈 3、眼 2×2
├─ 躯干：腰 3、肩胛 2×2
├─ 手臂 ×2：肩 3、肘 1、前臂转 1、腕 2
├─ 手 ×2：22（18 个驱动，全部在前臂）
└─ 腿 ×2：髋 3、膝 1、踝 2、脚趾 1（被动）
```

## 1. 先定 Nova 要能做的动作

结构由这些动作倒推。每个动作卡住一部分设计：

| 动作 | 目标 | 卡住的设计 |
|---|---|---|
| 平地走 | 1.4~1.5 m/s（人的平常速度） | 腿的速度、踝的蹬地 |
| 上下楼梯 | 17 cm 台阶 | 膝、髋的力矩 |
| 蹲到底再站起来 | 膝弯到 130° 以上 | 膝的活动范围和力矩 |
| 弯腰从地上捡东西 | 髋屈 120° + 腰屈 | 腰、髋的活动范围 |
| 双手搬 10 kg 的箱子 | - | 腰、肩、肘的力矩 |
| 被推后不倒；摔倒后自己站起来 | - | 全身力矩、外壳 |
| 小跳 | 10~20 cm | 腿的功率、踝的弹性 |
| 手的操作 | 拿鸡蛋不捏碎、拧瓶盖、用工具、拿起一张纸 | 手指自由度、触觉、力控制 |
| 和人在一起 | 握手、被人碰到不伤人 | 柔顺、软外壳 |
| 跑步 | 第一版不要求，但腿的设计不排斥 | - |

## 3. 每个关节的自由度和驱动

"驱动"一栏：
- 旋转 = 无框电机 + 行星减速器。能反推，可以用力矩控制。
- 直线推杆 = 电机 + 行星滚柱丝杠，通过连杆推拉关节，像肌肉。

| 部位 | 关节 | 自由度 | 人的活动范围 | 驱动 | 驱动器放在哪 | 峰值力矩初估 | 参考 |
|---|---|---|---|---|---|---|---|
| 腿（每条） | 髋 前后 | 1 | 屈 120°、伸 30° | 旋转 | 骨盆 | 250~300 N·m | G1：行星准直驱 |
| | 髋 侧摆 | 1 | 外展 45°、内收 30° | 旋转 | 骨盆 | 150~200 N·m | |
| | 髋 转 | 1 | 内旋、外旋各 45° | 旋转 | 大腿上部 | 80~120 N·m | |
| | 膝 | 1 | 0~135° | **直线推杆** + 像髌骨的连杆 | 大腿 | 250~300 N·m（换算到关节） | Optimus 的腿（据分析） |
| | 踝 前后 + 侧 | 2 | 背屈 20°、跖屈 50°；内翻 35°、外翻 20° | **两根直线推杆并联** + 串联弹簧（像跟腱） | 小腿上部（像小腿肌肉） | 前后 150~250、侧 60~100 N·m | 很多机型的踝用并联 |
| | 脚趾 | 1 | 伸 70°、屈 35° | **被动**：弹簧 + 阻尼。仿真里比较后再定要不要加电机 | 脚 | - | 人的绞盘机制：脚趾上翘时足底筋膜绷紧，帮助蹬地 |
| 躯干 | 腰 转 | 1 | 左右各 30° | 旋转 | 骨盆上方 | 80~120 N·m | |
| | 腰 前后 + 侧 | 2 | 屈 60°、伸 25°、侧弯各 25° | 两根直线推杆并联 | 腹部两侧（像竖脊肌、腹斜肌） | 前后 150~250、侧 100~150 N·m | IRON 的仿生脊柱 |
| | 肩胛（每侧） | 2 | 上提/下降、前伸/后缩 | 两根直线推杆 | 胸背 | 推杆力几百 N（待测） | IRON 的肩胛 |
| 手臂（每条） | 肩 前后 | 1 | 屈 180°（和肩胛一起）、伸 60° | 旋转 | 胸内 | 80~120 N·m | |
| | 肩 侧摆 | 1 | 外展 180°（和肩胛一起） | 旋转 | 肩 | 80~120 N·m | |
| | 肩 转 | 1 | 内旋 70°、外旋 90° | 旋转 | 上臂上部 | 40~60 N·m | |
| | 肘 | 1 | 0~150° | 旋转 | 上臂下部 | 60~80 N·m | |
| | 前臂转 | 1 | 旋前、旋后各 80° | 旋转 | 前臂靠肘的一端 | 10~15 N·m | |
| | 腕 | 2 | 屈 80°、伸 70°；桡偏 20°、尺偏 30° | 两根直线推杆并联 | 前臂 | 10~20 N·m | Optimus：前臂里 2 个腕驱动 |
| 头 | 颈 | 3 | 屈 50°、伸 60°、侧屈 45°、转 80° | 旋转 ×3 | 颈底 | 10~20 N·m | |
| | 眼（每只） | 2 | 实用范围：左右 ±35°、上下 ±25° | 微型驱动 | 头里 | 很小 | 人的扫视、前庭眼反射 |

为什么这样分：
- **伸缩的地方用直线推杆。** 膝、踝、腰、肩胛、腕的动作像肌肉收缩。推杆抗冲击，有人形机器人厂商的腿据报道也用这种。推杆的力矩随关节角度变化，这一点和人的肌肉一样，仿真里要照实模拟。
- **转动范围大的地方用旋转电机。** 髋、肩、肘、前臂转动的范围大，用推杆加连杆很难转到底。
- **膝有一个风险。** 推杆加连杆能不能做到 0~130° 以上、同时速度够快，要在 P1 的仿真里先验证。做不到就换旋转电机，像 Unitree 那样。
- **全部选能反推的驱动**，不用难反推的谐波减速器做大关节。这样能用力矩控制调软硬，被碰到时也安全。

## 4. 手（每只 22 个自由度、18 个驱动）

| 部分 | 关节 | 自由度 | 主动驱动 |
|---|---|---|---|
| 拇指 | 腕掌 2、掌指 2、指间 1 | 5 | 5 |
| 食指~小指（每根） | 掌指：屈伸 1 + 侧摆 1；近指间 1；远指间 1 | 4 | 3：远指间和近指间联动（人也是一根肌腱跨这两节） |
| 手掌 | 小指侧掌骨（让手掌能拢成碗） | 1 | 1 |
| 合计 | | **22** | **18** |

- **驱动**：
  - 18 个电机全部在前臂，用低减速比。
  - 每个主动自由度用一对肌腱（一根拉弯、一根拉直），由一个电机经滑轮来回拉。
  - 肌腱上串一段弹簧：既柔顺，又能从弹簧的伸长量量出张力。
- **前臂里一共 20 个驱动**（手 18 + 腕 2），和 Optimus V3 每条前臂 25 个同一量级。
- **传感**：
  - 每个手指关节都有角度传感器。肌腱会伸长，电机的转角不等于关节角，所以要在关节这边直接量。
  - 每根肌腱的张力。
  - 指尖高密度触觉，指节和手掌中密度。
- **手腕的影响**：肌腱穿过手腕，手腕一动，肌腱长度就会变。走线要尽量靠近腕的转轴，剩下的由控制补偿。MuJoCo 的空间肌腱会自动算出这种耦合。
- **目标**：
  - 手 ≤ 0.6 kg，前臂 ≤ 2.5 kg。
  - 指尖力 10~20 N，握力 100~200 N（成年男性约 400 N，第一版先做到一半以下）。
  - 指尖能感到几克的力（Figure 03 是约 3 克）。
- **参考**：Optimus V3 的专利（前臂电机 + 肌腱），1X NEO（肌腱 + 低减速比）。

## 5. 感觉（传感器）

分成两组。**像人的**默认全装；**比人多的**是研究上很有用、但人没有的。

像人的：

| 感觉 | 放在哪 | 说明 |
|---|---|---|
| 驱动器状态 | 每个驱动器 | 电机编码器、电流（换算力矩）、温度 |
| 关节角度 | 每个关节 | 绝对角度编码器。推杆、连杆、肌腱、弹簧中间都有弹性，必须在关节这边直接量 |
| 跟腱的力 | 踝的弹簧 | 从弹簧的变形量算出来 |
| 肌腱张力 | 手 | 同上 |
| 平衡感 | 头、骨盆各一个 IMU | 头上的相当于前庭，骨盆上的给平衡控制用 |
| 足底压力 | 每只脚：脚跟、脚掌内侧、脚掌外侧、脚趾 | 算压力中心 |
| 触觉皮肤 | 指尖约 2 mm 间距；手掌约 5~10 mm；手臂、躯干、大腿约 3~4 cm | 和人皮肤能分辨两点的距离差不多 |
| 视觉 | 两只眼的相机 | 全局快门，间距 63 mm |
| 听觉 | 两耳的麦克风 | |
| 保护 | 全身 | 过热、过载、超限、撞击 |
| 内部状态 | 电池、各处 | 电量、温度 |

比人多的（可选）：

| 传感器 | 用处 | 谁在用 |
|---|---|---|
| 腕部 6 轴力/力矩传感器 | 操作研究里最常用 | 很多机械臂 |
| 踝部 6 轴力/力矩传感器 | 平衡研究 | 研究机器人 |
| 额头深度相机 | 比双目更稳的深度 | 很多人形机器人 |
| 手掌相机 | 近距离看要抓的东西 | Figure 03 |
| 头顶麦克风阵列 | 更准的声源方向 | 很多机器人 |
| 后方或广角相机 | 看到身后 | Atlas 有 360° 视野 |

**建议第一版：像人的全装，再加腕部 6 轴力传感器。** 其它先不装，模型里留位置。

## 6. 身体里面的布置

| 位置 | 放什么 | 目标质量 |
|---|---|---|
| 头 | 眼（相机 + 4 个微型驱动）、耳、头部 IMU | 3.5~4.5 kg |
| 胸 | 主电脑（带 GPU，要散热）、网络交换机、肩前后的电机、肩胛推杆、颈底电机 | 躯干合计约 28 kg |
| 腹和骨盆 | **电池**（约 2~2.5 kWh，按每公斤约 200 Wh 算约 10~12 kg）、电源分配、骨盆 IMU、安全控制板、腰和髋的电机 | 同上 |
| 四肢 | 电机驱动板就近放在电机旁 | 见第 7 节 |
| 外层 | 软的包覆（像 1X NEO），里面是触觉皮肤；关节缝隙做防夹 | - |

电池放在腹部和骨盆，是为了让重心接近人的位置（约在身高的 55% 处）。

| 上臂 ×2 | 1.8 kg | 2.0 kg | 肩的另外两个关节、肘 |
| 前臂 ×2 | 1.1 kg | **2.3 kg** | 手 18、腕 2、前臂转 1 |
| 手 ×2 | 0.4 kg | 0.6 kg | 没有电机，只有关节、肌腱、传感器 |
| 大腿 ×2 | 9.2 kg | 8.5 kg | 髋转、膝的推杆 |

- 腿的质量照人的分布；电机靠上，小腿和脚基本和人一样轻。

## 8. 电子和通信

这一节是为以后的真机准备的。仿真里先按这个结构模拟延迟。

| 部分 | 做法 |
|---|---|
| 实时控制器 | 1 kHz，负责关节控制和保护反射（实时系统） |
| 大电机 | EtherCAT 总线，1 kHz |
| 手的小电机 | 前臂里的驱动板，CAN-FD |

## 9. "伸缩自如"在这一版里的做法

| 你要的效果 | 这一版怎么做 |
|---|---|
| 像肌肉一样伸缩 | 膝、踝、腰、肩胛、腕用直线推杆 |
| 能软能硬 | 全身驱动都能反推，用力矩控制（阻抗控制）由软件调软硬；落地冲击最大的踝加机械弹簧（像跟腱） |
| 力量叠加 | 踝、腰、腕、肩胛是两根推杆合力驱动两个自由度 |
| 关节之间传力（双关节肌） | 研究选项：仿真里试一根从大腿跨到脚跟的弹性连接（像腓肠肌），看走路是不是更省力 |

**没有用成对电机拮抗**，因为那样电机数会翻倍。
- 所以驱动器数（76）比自由度（86）少：手指远端联动、脚趾被动。
- 这修正了多电机关节讨论稿里"80~90 个电机"的估计。
- 如果要机械上真正的"绷紧/放松"，可以只在少数关节（如肘、膝）加拮抗，待讨论。
- **为什么不用液压或人工肌肉**：Clone 的液压肌肉最像人，但现在还要吊着才能站，还有泵、噪声、漏液的问题。电动驱动成熟，也好仿真。

## 11. 仿真里怎么验证（P1 预告）

1. 建**两个模型**：
   - 完整机构模型：推杆的闭链、手的肌腱、踝的弹簧，用来检验设计。
   - 简化训练模型：每个关节直接给力矩，用来大规模训练。
2. 让 Nova 在仿真里做第 1 节的动作，**实测每个驱动器要的力矩、速度、功率**，再拿这些数去找能买到的驱动器。
3. 验证有风险的地方：
   - 膝用推杆能不能达到活动范围和速度
   - 脚趾要不要主动
   - 前臂里放 20 个驱动器放不放得下、重不重
4. 用 MuJoCo Menagerie 里的 Unitree G1 模型做对照：看真机的质量分布，和 Nova 比。

## 12. 要你确认的

3. 传感器：像人的全装 + 腕部 6 轴力传感器，其它先不装，可以吗？

5. 手指的肌腱用成对拉（建议），还是一根肌腱 + 弹簧回弹？
