# 驱动、感觉、大脑：是不是最优解

> 2026-11-11 用户定：**所有改进都按最优解做**，第 6 节全部加进规格。原来写了"或者"的地方，选了更好的那个：
> - 手指：用"小电机 + 低减速比 + 绞盘"拉肌腱（两种做法里最能反推、摩擦最小）。大脚趾也用它。
> - 膝：电机放在大腿上部，经连杆带动膝（腿的转动惯量小）；用一级连杆、两级连杆还是同步带，P1 里在仿真里比。
> - 只记当场看到的东西（工作记忆）：用户确认。
>
> 见 [机体规格](../机体规格.md) v1.0、[系统结构](../系统结构.md) v1.2、[AI 模型](../AI模型.md) v1.2、[Nova 考试](../Nova考试.md) v1.3、[决定记录](../决定记录.md)。

2026-11-10。用户问了三件事：
1. 自由度和驱动（旋转电机、直线推杆、微型；踝的弹簧和阻尼器），现在是不是**做灵活动作**的最优解？先不考虑电量。
2. 感觉（[设计一览](16-设计一览和升级.md) 1.3 节的清单）是不是最优解？
3. 大脑和系统（4 层 + 两条旁路）是不是最优解？

这里的"灵活"指两样：全身的动作（跑、跳、翻、踢、扔）和手的灵巧。

## 0. 先说结论

| 部分 | 是不是最优解 | 建议 |
|---|---|---|
| 自由度的分法（98 个） | **接近最优**：人做动作要用的主要关节都有 | 保留；补上每个关节的范围目标（第 3 节） |
| 驱动 | **膝、踝、腕不是**：推杆不够快，膝和踝落地时的冲击也不好吸收 | 这三处改成旋转电机 + 连杆；踝保留弹簧和阻尼器；其它不变（第 2 节） |
| 手指的驱动 | 不考虑电量以后，"自锁"就不必要了 | 改成能反推、更快的驱动（第 2 节） |
| 感觉 | **接近最优** | 加两台相机：朝前下方看脚下的深度相机、小的热成像相机（第 4 节） |
| 大脑和系统 | **结构是对的** | 按新定的两条（数据主要来自仿真；在哪里都一样地想），补上"老师教学生"、一开始就用很多个家、"先想一想"（第 5 节） |

## 1. 做灵活动作，驱动要看什么

| 要看的 | 为什么 |
|---|---|
| 速度和峰值功率 | 人踢球时，膝伸直的角速度约 860~1900°/s；跳、翻要在零点几秒里放出很大的功率 |
| 能不能被推回去（反推） | 能反推的驱动，电流就能反映力，力控快、细；被撞、落地时能顺着让一下 |
| 抗冲击 | 落地、摔倒时的冲击很大，减速器和丝杠不能被冲坏 |
| 关节范围 | 蹲到底、跪坐、劈叉、侧手翻都要大的范围 |
| 四肢要轻 | 小腿、前臂、手越轻，甩得越快，撞到人也越轻 |

先不考虑电量以后，"省电"不再是选驱动的条件。

## 2. 驱动

### 2.1 两种主要的驱动比一比

| | 旋转：电机 + 低减速比的减速器 | 直线推杆：电机 + 行星滚柱丝杠 |
|---|---|---|
| 速度 | 快 | 慢一些：丝杠的转速有上限，经过连杆变成关节的转动还要再打折 |
| 反推和力控 | 好：减速比低（约 5~20 倍），看电流就能估出力 | 细螺距的接近自锁，推不回去；要另加力传感器，力控慢一些 |
| 抗冲击 | 好：落地时能被推回去一点，冲击小 | 力分散在很多螺纹上，很结实；但推不回去时，冲击会传给结构 |
| 力量密度 | 中等：电机要大一些 | 高：同样的重量，出的力大 |
| 关节范围 | 大 | 受推杆的行程和连杆限制 |
| 适合 | 要快、要灵活、要抗冲击的关节 | 要大力、速度中等、空间窄的地方 |

业界（大部分是第三方资料）：
- 动作最灵活的几款用的都是旋转驱动：
  - Boston Dynamics 的电动 Atlas：大多数关节是自己做的大功率旋转驱动，范围比人还大。
  - Unitree H1：全用自己做的电机，膝的峰值力矩 360 N·m；第一个不靠液压做出原地后空翻；跑 3.3 m/s。
- Tesla Optimus：14 个旋转 + 14 个直线（行星滚柱丝杠），直线的主要在腿上。行业分析的说法是：旋转的管手臂和躯干，滚柱丝杠管"重负载的腿"。

### 2.2 每个关节的建议

| 关节 | 现在 | 建议 | 为什么 |
|---|---|---|---|
| 膝 | 推杆 + 像髌骨的连杆 | **旋转**（低减速比），电机放在膝或大腿上部；范围 0~150° 以上 | 跑、跳、踢要快；落地时冲击最大的关节之一；推杆加连杆很难做到 150°。规格里本来就写了"做不到范围和速度就换旋转" |
| 踝（前后 + 侧） | 两根推杆并联 + 弹簧和阻尼器 | **两个旋转电机放在小腿上部 + 两根连杆并联**；连杆里串弹簧和阻尼器（还是像跟腱） | 落地的冲击最先到这里；电机在小腿上部，脚和小腿下部就轻 |
| 腕（屈伸 + 侧偏） | 两根推杆并联 | **两个小的旋转电机放在前臂靠肘的一端 + 连杆** | 扔东西、甩动时腕要快；前臂里已经有手的 12 个驱动，很挤。P1 里核对速度和空间 |
| 手指（前臂里 12 个） | 自锁的推杆 | **能反推、更快的驱动**：大导程的丝杠，或者旋转小电机 + 绞盘拉肌腱 | 自锁唯一的好处是"拿着东西不费电"，现在先不考虑电量。能反推的力控更细、更快、更安全；前臂已经在液冷里，一直出力也不怕热 |
| 髋、肩、肘、前臂转、腰和胸的转、颈 | 旋转 | 不变 | 已经是最合适的 |
| 腰椎、胸椎的前后和侧弯 | 推杆 | 不变 | 力大（腰前后 250 N·m）、速度中等、空间窄，推杆合适。"像肌肉一样推拉"在这里保留 |
| 肩胛 | 推杆 | 不变 | 同上 |
| 手掌 8 个、眼、眼睑 | 微型 | 不变 | - |
| 大脚趾；其它脚趾、足弓 | 肌腱从小腿拉；被动 | 不变 | - |

不考虑电量以后，所有驱动都能做得更好的地方：
- **按峰值功率和速度选电机**，选力矩密度高的。
- **母线电压可以高一些**：同样的电机能转得更快。
- **液冷**（已加）：电机能更长时间出大力。
- **成对电机**（膝、肘）：在仿真里比（机体规格第 7 节第 1 条，原来就有）。

## 3. 自由度：接近最优，补上范围

98 个自由度已经包含人做动作要用的主要关节：颈 4、脊柱 6、肩胛 6、手臂 7×2、手 22×2、腿 9×2（含大脚趾、被动的脚趾和足弓），加上眼和眼睑。
比别的机器人多出来的（脊柱、肩胛、脚趾、眼）都在"复杂度要有证据"里比（机体规格第 10 节）。**不建议再加。**

缺的是**每个关节的范围目标**：现在只有手写了范围，身体没有。建议按人定，髋和膝按柔韧的人再加一些（劈叉、侧手翻、跪坐）：

| 关节 | 人的正常范围（临床常用的约数） | Nova 的目标 |
|---|---|---|
| 颈 | 前屈约 45°、后伸约 45~60°、转约 70~80°、侧屈约 45° | 同人 |
| 脊柱（腰和胸合起来） | 前屈约 80°、后伸约 25°、转约 45°、侧弯约 35° | 同人 |
| 肩（含肩胛） | 前屈约 180°、后伸约 60°、外展约 180°、内旋约 70°、外旋约 90° | 同人 |
| 肘 | 0~150° | 同人 |
| 前臂转 | 旋前约 80°、旋后约 80° | 同人 |
| 腕 | 屈约 80°、伸约 70°、桡偏约 20°、尺偏约 30° | 同人 |
| 髋 | 屈约 120°、伸约 30°、外展约 45°、内收约 30°、内外旋各约 45° | 屈 ≥ 130°、外展 ≥ 60° |
| 膝 | 0~135~150° | ≥ 150° |
| 踝 | 背屈约 20°、跖屈约 50°、内翻约 35°、外翻约 15~20° | 同人 |

这些是临床常用的正常值。P1 里按资料核对，再按仿真里做动作的需要调。

## 4. 感觉：接近最优，加两台相机

现在的清单已经是"像人的全装 + 对做对动作有用的机器人传感器"。这次新加的嗅觉、冷却液和进水的检测，已经写进规格。还可以更好的两处：

| 加什么 | 为什么 |
|---|---|
| **朝前下方看脚下的深度相机**（把胸前那台环视相机换成它） | 现在走楼梯、走不平的地靠额头的深度相机，但头要看任务、看人。看人的时候，脚下只能靠刚才扫过的记忆。换成一直看着脚下的，就不和"看哪里"抢。楼梯的踏步比脚还短，更要一直看着 |
| **小的热成像相机**（额头） | 锅烫不烫、灶开着没有、水热不热，不碰就知道；暗处也能看到人和宠物。人的皮肤能感到热；Nova 只有指尖能测温，要碰到才知道 |

不用加的：
- 激光雷达：深度相机和两只眼的双目已经够了。
- 每个旋转关节的力矩传感器：低减速比的电机看电流就能估力；碰到东西另有全身的触觉皮肤。

## 5. 大脑和系统：结构是对的，补三处

4 层 + 两条旁路是对的。Figure 2026 年 1 月的 Helix 02 也分三层：慢的视觉语言模型、200 Hz 的全身动作、1 kHz 的全身控制（自报）。
层数、一台计算机分区、C++ 和 Python 的分工、ROS 2 + zenoh，都不建议改。

按刚定的两条，要补三处：

### 5.1 仿真里的数据怎么来："老师教学生"

数据主要来自仿真里的训练（用户定）。要让动作脑也能主要靠仿真学会，建议这样做：
1. **老师**：在仿真里用强化学习训练。老师能直接看到仿真里的全部信息（每样东西的位置、重量、摩擦），所以学得快。
2. **学生**：动作脑只看相机和触觉，跟着老师学：老师做，学生看着学；学生做错时，老师纠正。小脑层已经这样做（HOVER），动作脑也照做。
3. **任务自动生成**：家、物品、任务都由程序生成。Nova 考试的裁判自动判成败，这既是老师的奖励，也是价值模型的答案。不用人一条条录。

风险是**仿真和真的不一样**：画面、接触、软的东西都有差别。办法：
- 随机化的范围要大；
- 以后用手机扫描的真实的家（考场 v3）；
- 真机来了以后，用少量真实的数据校正。

### 5.2 一开始就用很多个家

用户要的是"像人一样，在哪里都能一样地想、一样地反应"。所以：
- 训练从一开始就用**很多个程序生成的家**（Infinigen 一类），不等到考场 v1。考场 v0 的那个家只是第一份考卷。
- **不公开的考场**（从来没见过的家）是最重要的分数。
- 到了一个没去过的家，不用先建模型、不用先校准，就能开始做事。

### 5.3 "先想一想"（以后）

人做有风险的事之前，会在心里预演：叠高了会不会倒，倒水会不会洒。
- 做法：用"世界模型"想象做了以后会怎样，再决定做不做、怎么做。GR00T N2 预告的"世界-动作模型"就是这一类。
- 现在：先在结构里留位置（思考脑和动作脑都能用），等模型成熟再接上。

## 6. 要你定的

1. **驱动**：膝、踝、腕改成旋转电机 + 连杆（踝保留弹簧和阻尼器）；腰椎、胸椎、肩胛保留推杆。可以吗？
2. **手指的驱动**：改成能反推、更快的，不再要求自锁。可以吗？
3. **关节范围**：按第 3 节的表定目标（髋、膝比一般人再大一些）。可以吗？
4. **感觉**：胸前的环视相机换成朝前下方的深度相机；额头加一台小的热成像相机。可以吗？
5. **数据**：动作脑也用"老师教学生"；训练从一开始就用很多个家。可以吗？
6. **"先想一想"**：在结构里留位置，以后接世界模型。可以吗？
