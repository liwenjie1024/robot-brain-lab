# 多电机关节（讨论中）

2026-11-09 起讨论。决定：Nova 用关节电机，但不是一个关节一个电机，要多个电机组合，让关节伸缩自如。
这份文档整理：人是怎么做的、机器人有哪几种组合方式、每个关节适合哪种、仿真里怎么做、还要讨论什么。

## 1. 人的关节是怎么被驱动的

| 人的做法 | 例子 | 带来什么 |
|---|---|---|
| **一对肌肉对着拉**（屈肌和伸肌） | 肱二头肌弯肘，肱三头肌伸肘 | 肌肉只能拉不能推，所以要成对 |
| **两边一起用力（共同收缩）** | 端着满杯水时手臂"绷紧"，放松时"软" | 同一个姿势下，**关节可以软也可以硬**。软的时候被碰到不受伤，硬的时候拿得稳 |
| **一个关节有很多块肌肉** | 肩关节周围有十几块肌肉 | 力可以叠加；一块累了别的分担；同一个动作有多种做法 |
| **一块肌肉跨两个关节（双关节肌）** | 小腿的腓肠肌跨膝和踝；大腿后侧跨髋和膝 | 力和能量能在关节之间传递。跑步时膝盖伸直的能量传到踝，用来蹬地 |
| **肌肉在近处，用肌腱传到远处** | 手指的大部分肌肉在前臂，靠长肌腱拉手指；踝靠跟腱 | 手和脚很轻，所以甩得快、省力 |
| **肌腱有弹性** | 跟腱像弹簧，跑步时存能量再放出 | 缓冲冲击、省能量 |

**最值得学的一条：动力源放在靠近身体中心的地方，用连杆或肌腱传到末端。**
末端（手、脚）越轻，动作越快、越省力，也越安全。

## 2. 机器人里"多个电机组合"的几种方式

| 方式 | 怎么做 | 好处 | 代价 | 真实机器人里 |
|---|---|---|---|---|
| A. 并联 | 两个电机（常是两根直线推杆）一起驱动一个两自由度关节，比如踝的前后弯和左右弯 | 电机可以放在小腿上部，脚很轻；两个电机分担负载，每个都可以小一点 | 运动学要换算（电机位置 ↔ 关节角度）；活动范围受连杆限制 | 很常见，多数新人形机器人的踝用这种 |
| B. 差动 | 两个电机通过差动齿轮驱动两个自由度：同向转是一个动作，反向转是另一个 | 每个方向都能用上两个电机的力 | 齿轮复杂，有间隙 | 腕、踝、腰常用 |
| C. 拮抗 + 可变刚度 | 一对电机分别拉关节两侧（通过肌腱），中间有非线性弹簧。同方向拉 → 转动；一起拉紧 → 变硬 | **最像人的共同收缩**：同一姿势下软硬可调，碰撞时能缓冲 | 电机数翻倍、更重、更贵，控制难 | 主要在研究机器人里 |
| D. 冗余（多个电机并在一个关节上） | 一个关节装两个电机一起出力 | 力更大；一个坏了还能动 | 重、费电 | 少见，用在负载大的关节 |
| E. 直线推杆当"肌肉" | 丝杠推杆像肌肉一样伸缩，跨在关节上拉动骨头。也可以跨两个关节，做成双关节肌 | 形状和受力像人；力大；能自锁 | 速度比旋转电机慢；推杆本身重 | 有人形机器人厂商采用（据报道） |
| F. 串联弹性 | 电机和关节之间串一个弹簧 | 像跟腱：缓冲、存能量；弹簧变形量就是力传感器 | 响应变软，精确位置控制更难 | 研究机器人和部分真机 |
| G. 准直驱 + 力控（单电机） | 低减速比、能反推的电机，加力矩控制（阻抗控制） | 软硬靠软件调，机构简单 | 软硬是"算出来的"，碰撞瞬间来不及反应；力矩密度有限 | 现在多数人形机器人的主流 |

注意 **G**：很多"伸缩自如"的效果，用一个能反推的电机加阻抗控制就能做到，软硬由软件调。
多电机组合（A~F）能多给的东西主要有四样：
- 把电机放到靠近身体的地方（A、E 加连杆或肌腱）
- 力的叠加（B、D）
- 机械上真正的软硬可调，碰撞的瞬间不靠软件（C、F）
- 关节之间传递能量（E 的双关节）

## 3. 每个关节的候选方案（初稿，待讨论）

| 部位 | 自由度 | 候选 | 理由 |
|---|---|---|---|
| 髋 | 3 | 3 个大电机，或部分并联 | 负载最大，离身体近，电机放在原位影响小 |
| 膝 | 1 | 大电机，或直线推杆；考虑和踝之间的双关节联动 | 起立、上台阶要大力；双关节联动有助于蹬地省力 |
| 踝 | 2 | **并联两推杆，电机放在小腿上部** + 串联弹性（像跟腱） | 脚要轻；落地冲击大；蹬地要存能量 |
| 脚趾 | 1 | 小电机或被动弹簧 | 先看仿真里有没有必要主动驱动 |
| 腰 | 3 | 并联或差动 | 要扛上半身的重量 |
| 肩 | 3 | 电机靠近躯干，部分差动 | 手臂要轻；举物要大力 |
| 肘 | 1 | 电机放在上臂，或直线推杆 | 前臂要轻 |
| 前臂转动 + 腕 | 3 | 腕用并联两推杆，电机在前臂 | 手要轻 |
| 手指 | 每只手约 20 | **电机在前臂，用肌腱拉手指**；每根手指一对肌腱（一拉弯、一拉直），或一根肌腱加回弹弹簧 | 和人一样，手才能轻；前臂空间够放 |
| 颈 | 3 | 并联 | 头要稳 |

这样算，**电机数会比自由度多**。初步估计：
- 身体 34 个自由度，大约 40~50 个电机
- 每只手约 20 个电机
- 合计约 80~90 个

具体数要看哪些关节用拮抗（C），C 会让电机数翻倍。

> 修正：[机体结构提案](04-机体结构提案.md) 没有用拮抗。软硬由力矩控制调，踝加弹簧；手指远端联动，脚趾被动。
> 这样共 86 个自由度、76 个驱动器，驱动器比自由度少。

## 4. 仿真里能不能做

MuJoCo 都能表达，但越像真机，仿真越慢：

| 机构 | MuJoCo 里怎么做 |
|---|---|
| 并联连杆 | 闭链：用等式约束（`connect`、`weld`）把连杆接起来 |
| 直线推杆 | 滑动关节 + 力或位置驱动 |
| 肌腱（手指、跟腱） | 空间肌腱 `tendon/spatial`：绕过导向点和圆柱，驱动器可以直接拉肌腱 |
| 弹簧（串联弹性、回弹） | 肌腱刚度、关节刚度 |
| 拮抗一对电机 | 两个驱动器拉两根肌腱 |

常见做法是**两个模型**：
- **完整机构模型**：用来检验设计、实测力和活动范围，也是以后真机的依据。
- **简化关节模型**：用来大规模训练，每个关节直接给力矩。控制层负责在"关节力矩"和"各个电机的力"之间换算。

两个模型的差别本身也要测：在简化模型里训练出的策略，放到完整模型里还能不能用。

## 5. 还要讨论的问题

1. **"伸缩自如"指的是哪种？** 可能是下面一种或几种：
   - 同一姿势下软硬可调（像人绷紧和放松）→ C、F，或 G 的软件做法
   - 力量大且灵活（几个电机合力）→ A、B、D
   - 像肌肉一样直线伸缩 → E
   - 关节之间传递力量（双关节肌）→ E 加跨关节连接
2. **全身都这么做，还是只在关键关节？** 每多一个电机：
   - 更重、更贵、更费电
   - 多一个会坏的地方
   - 控制更难
3. **以后做真机**，要不要先只做一条腿或一条手臂加手，当第一个实物试验台？
4. **手**的肌腱是成对拉（像人），还是一根加弹簧回弹（简单）？
5. **动力源**：全用电机，还是部分考虑液压或人工肌肉？
