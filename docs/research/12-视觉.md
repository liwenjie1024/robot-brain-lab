# 视觉

2026-11-10。讨论 Nova 的视觉：人的眼睛怎么看、机器人有哪些技术、Nova 的相机和眼睛怎么做、看哪里、仿真里怎么做。

顺便改正一处错：规格里原来写"9 台相机"，按清单数是 **10 台**（眼 2、额头深度 1、额头事件 1、手掌 2、环视 4），已经改了。

## 1. 人的眼睛

| 方面 | 人 | 对 Nova 的意义 |
|---|---|---|
| 中央凹 | 视野中心约 2° 最清楚（约 1 角分），越往外越模糊，大致跟着视锥细胞的密度走 | 不用整幅都高清：**中间清楚、周围模糊**就够，省很多算力 |
| 周围视野 | 看不清细节，但对运动很敏感 | 周围用低分辨率，专门发现"有东西在动" |
| 视网膜 | 先处理再送出去：边缘、对比、**只报变化**；视神经约 100 万根纤维 | 事件相机就是模仿这一点 |
| 扫视 | 每秒 2~3 次跳到新的地方，峰值 500~700°/s | 眼球要能快速转 |
| 平稳追踪 | 跟着移动的东西，约 30°/s，最快约 100°/s；要 200~300 ms 才跟稳 | - |
| 聚散 | 看近处时两眼往里转，看远处时往外转 | 两眼的角度本身就告诉你"有多远" |
| 前庭眼反射 | 头一动，眼睛约 10 ms 内反向转，视线不晃 | 已经在脊髓层的反射里 |
| 深度 | 两眼的视差（近处最准）、头动时的视差、遮挡、对大小的常识 | 双目 + 深度相机 |
| 明暗 | 从星光到阳光都能慢慢适应；同一时刻也能看清亮处和暗处 | 相机要有高动态范围（HDR） |
| 两条通路 | "是什么"（认东西）和"在哪、怎么拿"（给手和眼的动作）分开处理 | 动作脑和思考脑各取所需。你的 humen 项目里视觉也是这两条通路 |
| 反应 | 看到后约 200 ms 才开始动 | Nova 的目标是 100 ms 以内 |

## 2. 机器人视觉的技术

| 技术 | 做什么 | 好处 | 缺点 |
|---|---|---|---|
| 普通相机（全局快门） | 彩色图像；整幅同一时刻曝光 | 动起来时图像不变形 | 高分辨率的数据量大 |
| 普通相机（卷帘快门） | 一行一行曝光 | 便宜、分辨率高 | 动的时候图像会歪 |
| 双目 | 两台相机算视差得深度 | 被动、近处准 | 没有纹理的白墙算不出来 |
| 主动深度（ToF、结构光） | 发红外光测距离 | 白墙、暗处都行 | 怕阳光、怕黑色和反光的表面；边缘有"飞点" |
| 事件相机 | 每个像素只在亮度变化时报告 | 延迟微秒级、不怕明暗反差、数据少 | 静止的东西看不见 |
| 中央凹的做法 1：每只眼两台相机 | 一台广角（周围）+ 一台窄角（中央凹） | 两边都清楚 | 眼球重、转得慢；两台要一起校准 |
| 中央凹的做法 2：一台高分辨率传感器 | 交替读出"缩小的整幅"和"注视点的全分辨率小块" | 眼球轻；注视点在图里可以瞬间跳（"数字扫视"） | 要传感器支持分区读出 |

机器人的例子：
- iCub 的眼睛：基线 68 mm，但很多实验里眼睛是固定不动的。
- 有些人形机器人用"每只眼两台相机"。
- 2025 年的机器人头 DIJIT，扫视速度达到人的峰值的 85% 以上。

## 3. Nova 的相机（共 10 台）

| 相机 | 数量 | 位置 | 规格 | 用途 |
|---|---|---|---|---|
| **眼** | 2 | 头里，能转（左右 ±35°、上下 ±25°），间距 63 mm | 每只眼一台约 24 MP 的全局快门传感器 + 约 100° 的镜头；交替读出：缩小的整幅（周围，60 帧）+ 注视点约 19° 的全分辨率小块（中央凹，60~120 帧）；HDR | 看东西、双目深度、视觉惯性里程计 |
| 额头深度相机 | 1 | 额头 | ToF，0.2~5 m，30 帧，红外补光 | 稳定的深度：白墙、暗处；地形高度图；安全 |
| 额头事件相机 | 1 | 额头 | 微秒级延迟，高动态范围 | 快的东西：接球、飞来的东西、突然动的人和宠物 |
| 手掌相机 | 2 | 两只手掌 | 广角，对焦 2~30 cm，30 帧，红外补光 | 抓之前近距离看；柜子里暗的地方 |
| 环视相机 | 4 | 头的后面和两侧、胸前 | 鱼眼，低分辨率（约 640×480），15~30 帧 | 看身后和周围：有人从后面过来、走路时的周围 |

**为什么眼用"一台高分辨率传感器"**：
- 眼球轻，转得快：扫视要接近人的速度。
- 只有一台，要校准的少。
- 注视点在图像里可以瞬间移动，不用转眼球（"数字扫视"），又快又不费电。
- 机械的眼球转动只用在大的移动、聚散（看近处）、和人对视的时候。

**中央凹有多清楚**：约 5300 像素横跨约 100°，每度约 53 像素，也就是每个像素约 1.1 角分，接近人的中央凹（约 1 角分）。

**数据量**：
- 原始数据每秒约 450 MB，其中两只眼约 380 MB。
- 相机直接接中央计算机，图像进图像处理器和 GPU 内存后不再复制。
- 录下来的视频压缩后每秒约 20~40 MB。

### 眼的动作目标

| 指标 | 目标 | 人 |
|---|---|---|
| 扫视峰值速度 | ≥ 500°/s | 500~700°/s |
| 平稳追踪 | ≥ 100°/s | 约 30°/s，最快约 100°/s |
| 前庭眼反射 | ≤ 5 ms | 约 10 ms |
| 眼的角度精度 | 约 0.01° | - |

为什么精度要 0.01°：眼会转，两眼之间的角度直接决定双目深度。在 1 m 处，0.01° 的角度误差约等于 3 mm 的深度误差。

### 保护和照明

- 眼睑：保护镜头，眨眼时擦掉灰尘和水汽。
- 红外补光：深度相机、手掌相机用。人看不见，不晃眼。
- 不用强的可见光照人的眼睛。
- 相机工作时有指示灯（隐私，见[商用要求](../商用要求.md)）。

## 4. 看哪里：注意力和眼动

像人一样，Nova 每秒决定 2~3 次"接下来看哪里"（扫视），中间平稳追踪移动的东西，看近处时两眼聚拢。
这件事由动作脑的注视控制来做；前庭眼反射一直由脊髓层叠加在上面。

**优先级**（每次都按这个顺序打分）：

| 顺序 | 看什么 | 例子 |
|---|---|---|
| 1. 安全 | 突然动起来的东西（周围视野、事件相机）；靠近的人和宠物 | 有东西从桌上掉下来 |
| 2. 任务 | 要拿的东西；手（抓之前看目标，抓的时候看手和目标）；走路时前面一两步的地面 | 收拾餐桌时看下一个盘子 |
| 3. 社交 | 正在说话的人的脸（结合声音的方向）；叫 Nova 名字的人；别人指着的东西 | 有人说"把那个给我"并指着 |
| 4. 探索 | 没看过的地方；记忆里东西应该在的地方 | 找遥控器 |

- **眼和头的配合**：小的移动只动眼；大的移动先动眼、头跟着转，和人一样。
- **视线就是沟通**：家里的人会看 Nova 在看什么，就知道它要拿什么，所以 Nova 更好预测。也要守社交习惯：和人说话时看脸，但不一直盯着看。

## 5. 处理和数据的去向

按[系统结构](../系统结构.md)第 3 节：

| 处理 | 在哪 | 给谁 |
|---|---|---|
| 前庭眼反射 | 脊髓层（用 IMU，不用相机） | 眼 |
| **飞来物反射**（建议新加） | 事件相机 → 简单的"变大检测"（不用神经网络） | 脊髓层：闭眼睑、转头、抬手挡，目标约 20 ms |
| 视觉惯性里程计、地形高度图 | 小感知模块 | 脊髓层、小脑层 |
| 中央凹小块 + 缩小的周围 + 手掌相机 | AI 分区·快 | 动作脑（10~30 Hz） |
| 物体和人的识别、跟踪、"东西放在哪"的记忆 | 小感知模块 | 动作脑、思考脑 |
| 几张图 | AI 分区·慢 | 思考脑（1~10 Hz） |
| 深度 + 环视的几何判断 | 安全分区 | 安全（不用神经网络） |
| 全部压缩视频 | - | 记录 |

## 6. 仿真里怎么做

### 6.1 渲染

| 用在哪 | 用什么 | 说明 |
|---|---|---|
| 实时仿真、验证 | CPU 的 MuJoCo（OpenGL） | 每台相机单独设视角和分辨率 |
| 大规模训练 | **MuJoCo Warp 的批量渲染器**：用光线追踪同时渲染很多个并行世界里的相机 | 支持网格、纹理、高度图、可变形体、阴影；速度快，但不够真实（维护者自己也这样说）；可以换成自己的渲染函数 |

### 6.2 相机模型（真实相机的毛病，共用）

| 相机 | 要加上的 |
|---|---|
| 普通相机 | 镜头畸变（鱼眼）、噪声、曝光和自动曝光、高动态范围、运动模糊、白平衡、压缩、延迟；眼的交替读出（缩小的整幅 + 中央凹小块） |
| 深度相机 | 越远越不准、边缘的"飞点"、黑色和反光表面的空洞、墙角的多次反射 |
| 事件相机 | 用很高帧率渲染，再按亮度变化生成事件。很费算力，只在需要的场景里开 |

### 6.3 让仿真的画面在真机上也管用

MuJoCo 的画面不像照片。这是视觉从仿真到真机的主要差距，用四个办法补：

1. **随机化**：纹理、灯光、相机参数每次都变，模型就不会只认仿真的样子。
2. **照片级的考场**：
   - 用手机扫描真实的家，做成"3D 高斯泼溅"的数字孪生：外观像照片，碰撞形状另外配上。
   - 2026 年的 Splat2Act 就是这样：用手机扫描建出整栋楼的照片级孪生，在里面训练，到真机上的成功率和仿真里差不多（63.9% 对 66.7%，作者自报）。
   - GS-Playground（RSS 2026）能批量渲染高斯泼溅，给强化学习用。
3. **预训练的视觉**：动作脑、思考脑的主干是用大量真实图片训练过的，对画面的变化不太敏感。
4. **关键的回路不靠彩色图像**：安全、平衡、走路主要靠深度和本体感觉。

### 6.4 家的场景和物品

- **BEHAVIOR-1K**（Stanford）：1000 种家务活动、50 个可交互的家、1 万多件物品；2026 年的比赛用 π0.5 和 GR00T N1.7 当基线（第三方资料）。
  - 它跑在 Isaac Sim 上，这台电脑跑不了。
  - 但它的**家务任务的定义**可以拿来参考 Nova 考试的题目。
  - 素材的许可证要查（商用）。
- 自己扫描的家：自己拥有，商用没问题。

| 类 | 考题 |
|---|---|
| 找东西 | 在乱的房间里找到"红色的杯子"；看标签分出盐和糖 |
| 暗处 | 只开一盏小灯时收拾 |
| 快的东西 | 接住抛过来的软球；注意到从桌上掉下来的东西 |
| 社交 | 说话时看着对方的脸；别人指着东西时看过去 |

## 8. 要你定的

1. **眼**：每只眼一台高分辨率传感器（约 24 MP 全局快门、约 100° 镜头），交替读出周围和中央凹，加上能转的眼球。可以吗？另一种做法是每只眼两台相机（宽 + 窄）。
2. **眼动目标**：扫视 ≥ 500°/s、追踪 ≥ 100°/s、角度精度约 0.01°。可以吗？
3. **看哪里的优先级**：安全 > 任务 > 社交 > 探索。可以吗？
4. **飞来物反射**：东西飞向脸时闭眼睑、转头、抬手挡。要加吗？
5. **仿真画面**：先用 MuJoCo 自己的渲染加随机化；以后用手机扫描真实的家，做成照片级的考场。可以吗？
