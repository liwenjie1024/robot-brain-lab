# 触觉皮肤

2026-11-09。讨论 Nova 的触觉皮肤：人的皮肤怎么感觉、机器人有哪些技术、Nova 每个部位怎么做、仿真里怎么做。
"仿真里怎么做"放在第 5 节，因为它决定了我们能不能先在仿真里把触觉练好。

## 1. 人的皮肤

### 1.1 四种"压力"感受器

| 感受器 | 反应方式 | 感觉什么 | 机器人里对应 |
|---|---|---|---|
| Merkel（慢适应 I 型） | 一直按着就一直报 | 持续的压力、边缘、细的形状（摸出字的笔画） | 压力阵列 |
| Meissner（快适应 I 型） | 只在变化时报 | 轻触、**开始滑动**、低频振动（约 5~50 Hz） | 压力的变化率 |
| Pacinian（快适应 II 型） | 只在变化时报，非常灵敏 | 高频振动（约 40~400 Hz）：纹理、用工具时传过来的振动 | 振动传感器 |
| Ruffini（慢适应 II 型） | 一直报 | 皮肤被拉伸（手指弯曲时）、切向力 | 切向力 |

另外还有：
- 冷、热感受器：摸金属觉得凉，其实是它导热快。
- 痛觉。
- 毛发的感受器：很轻的拂过。
- 一种专门感觉"轻柔抚摸"的神经：和被人安慰、被拥抱的感觉有关。

### 1.2 有多密

- 一只手里约有 1.7 万根触觉神经纤维（Johansson & Vallbo, 1979）。
- 指尖的慢适应 I 型感受区，中心之间约 1.2 mm。
- 能分辨两个点的距离：指尖约 2~3 mm，手掌约 1 cm，手臂和背上几厘米。
- 神经越密的地方分辨得越细，手和脸特别密。

### 1.3 人靠触觉做什么

- 知道碰到了、碰在哪
- 用多大力
- 形状和边缘
- 纹理（靠振动）
- **东西开始滑了**（还没真的滑掉就知道）
- 软还是硬
- 冷热和材质
- 疼（快受伤了）
- 被人碰了、被谁怎么碰

## 2. 机器人的触觉技术

| 原理 | 量什么 | 好处 | 缺点 | 例子 |
|---|---|---|---|---|
| 磁式（弹性体里放小磁体，下面的霍尔传感器测磁场变化） | 每个点的三个方向的力（压力 + 切向力） | 灵敏、耐用、**能密封防水** | 怕外面的磁场 | XELA uSkin：已装进五指手，覆盖指尖、指节、手掌，还有指甲 |
| 电容式 | 压力；同一组电极还能测**接近**（快碰到了） | 薄、能做大面积、便宜 | **怕水**（水导电）；怕电磁干扰 | 大面积的机器人皮肤 |
| 压阻式（压了电阻会变） | 压力 | 简单、便宜、量程大 | 会漂、有迟滞 | 足底压力垫 |
| 压电式 | 只量变化：振动、冲击 | 反应极快 | 量不了持续的压力 | 振动、开始滑动 |
| 光学式（相机看凝胶表面的变形） | 很细的接触形状、力的分布 | 分辨率最高 | 体积大，主要用在指尖；耗电、数据量大 | GelSight、Meta Digit 一类 |
| 气压式（橡胶里埋小气压传感器） | 压力 | 结实、便宜 | 分辨率一般 | - |

2026 年的方向：
- 手：磁式和光学式。Figure 03 的自研指尖能感到约 3 克的力。
- 全身：电容式，能同时测压力和接近（有陪伴机器人用自电容覆盖全身；3D 打印的触觉 + 接近觉皮肤）。
- 仿生：
  - 把触觉变成"只在变化时发信号"，像神经一样。2026 年有用这种方式模仿慢适应、快适应两种神经的电子皮肤。
  - 在打滑真正发生之前就测出来的方法。

## 3. Nova 每个部位的皮肤

| 部位 | 技术 | 间距 | 格子数（约） | 每个格子测什么 | 频率 | 特别要求 |
|---|---|---|---|---|---|---|
| 指尖 ×10 | 磁式三轴 + 压电振动 + 温度 | 约 2 mm | 每个约 75，共 750 | 压力 + 两个方向的切向力；每个指尖另有振动和温度 | 500 Hz（振动 2 kHz） | 软指腹、指纹纹路、指甲；能密封防水 |
| 指节、手掌 ×2 | 磁式三轴 | 5~7 mm | 每只手约 320，共 640 | 压力 + 切向力；手掌另有温度 | 200 Hz | 防水 |
| 全身（手和脚底以外，约 1.7 m²） | 电容式 | 约 3.5 cm | 约 1400 | 压力 + 接近 | 100 Hz | 软外壳下面；能分辨轻拍和撞击 |
| 足底 ×2 | 大量程三轴阵列（压阻式或磁式） | 约 1 cm | 每只约 230，共 460 | 压力 + 切向力 | 1 kHz | 落地时要承受约 3 倍体重 |
| 关节缝隙 | 细条形的压力条 | - | 少量 | 有没有夹到东西 | 200 Hz | 防夹 |
| **合计** | | | **约 3250 格** | | | |

另有：接近觉电极约 200 个（全身）、振动 10 个、温度 12 个。

**原始数据量**每秒约 6 MB：指尖 2.3 MB、手掌和指节 0.8 MB、足底 2.8 MB、全身 0.3 MB。
用"只报变化"的方式会小得多。

## 4. 设计要点

### 4.1 每个格子输出两路，像人的两种神经

| 通道 | 像人的 | 内容 | 给谁 |
|---|---|---|---|
| 持续 | 慢适应（Merkel、Ruffini） | 现在的压力和切向力 | 动作脑（抓得多紧）、小脑层（足底的压力中心） |
| 变化 | 快适应（Meissner、Pacinian） | 压力的变化率、振动 | 脊髓层的防滑反射、碰撞反射 |

- **只在变化超过阈值时才上报**（像神经发信号），不变的格子不占带宽。
- 再从两路里算出"事件"：接触开始、接触结束、开始打滑、被拍、被抓、撞击、太热。

### 4.2 接线和电子

- 皮肤分成一块块的**模块**，每块下面有读取芯片，就近把信号变成数字。
- 每条手臂、每条腿有一个汇集的地方。
- 指尖和足底走 EtherCAT（给反射用，要快），其它走以太网或 CAN-FD。
- 所有格子都用统一时钟打时间戳。
- 模块坏了能单独换。指尖的软指腹会磨损，做成可以换的。
- 开机自检：找出不工作的格子，标出来，别的格子和模型照常用。

### 4.3 校准

- 每个格子的灵敏度和零点、随温度的变化，都要校准。没有接触的时候自动重新归零。
- **自己摸自己**：Nova 用一只手去摸自己的身体，校准每个格子在身体上的准确位置，顺便校准关节。
  - 这像婴儿认识自己的身体。iCub 机器人已经用这种方法校准了 970 个触觉格子的位置。
  - 用指尖在皮肤上滑过去，位置精度能到约 0.5 mm，比格子本身（5 mm）还细。

### 4.4 家务带来的要求

| 情况 | 要求 |
|---|---|
| 洗碗、擦桌子 | 手要防水、耐清洁剂。电容式怕水，所以手用磁式 |
| 热锅、热水 | 指尖和手掌测温度；外层耐热；太热 → 缩手反射 |
| 叠衣服 | 能感到很轻的力（几克）和布料在手指间的滑动 |
| 鸡蛋、玻璃杯 | 力要控制得很细 |
| 被家里的人拍肩膀 | 分辨轻拍和撞击；被拍时转头看 |
| 皮肤会脏 | 外面那层能擦、能洗；能换 |

## 5. 仿真里怎么做

**这是最难的地方之一**：触觉从仿真到真机的差距，比视觉还大（2026 年的综述也这样说），主要是软材料的变形很难模拟。

### 5.1 两套计算，输出一样的格式

| 用在哪 | 怎么算 | 说明 |
|---|---|---|
| 实时仿真、验证（CPU 的 MuJoCo） | MuJoCo 的 touch_grid 触觉格子 | 每块皮肤是一个格子阵，每格给压力和两个方向的切向力；还能设成"中间密、周围疏"（像中央凹）。碰撞形状要切细：MuJoCo 的盒子只在角上算接触，否则格子会"空" |
| 大规模训练（GPU 的 MuJoCo Warp） | **自己写的快速触觉**：在每个格子的位置放一个虚拟的点，按它和物体的距离、接触力算读数 | MuJoCo Warp 现在**还不支持插件类的传感器**，所以 touch_grid 在训练里用不了。2026 年已有用这种快速虚拟触觉、直接从仿真转到真实五指手的例子 |

两套的输出格式完全一样（写进观测和动作的规约），并且在测试场景上对比两套的读数，确认差别够小。

### 5.2 传感器模型（两套共用）

物理只给"理想的力"。真实的触觉传感器还有这些毛病，都要加上：

| 毛病 | 说明 |
|---|---|
| 空间上的模糊 | 力经过软的外层会散开，相邻的格子都有读数 |
| 噪声、分辨率 | 读数有抖动，有最小刻度 |
| 迟滞、漂移 | 按下和松开时读数不一样；时间长了零点会跑 |
| 串扰 | 一个格子受力，旁边的格子也有一点读数 |
| 坏格子 | 有的格子不工作 |
| 延迟、饱和 | 读数晚一点到；力太大时顶到头 |

这些参数先按资料估，以后用真实传感器的数据来拟合（让仿真的读数和真实的一样）。

### 5.3 物理里没有的，自己补

| 感觉 | 做法 |
|---|---|
| 振动（纹理） | MuJoCo 没有表面的细纹理，所以按"滑动速度 × 表面纹理的参数"合成振动；碰撞时加一个冲击 |
| 温度 | 每个物体有温度和导热快慢；接触时按简单的热传导算指尖的温度变化。金属会"摸起来凉" |
| 接近觉 | 从每个电极到附近物体（特别是人）的距离，按电容的规律换算 |

### 5.4 怎么让仿真里练的触觉在真机上也管用

1. **用简单的触觉特征**：给策略的不是每个格子的原始读数，而是"接触点、力的方向和大小、有没有在滑"。2026 年有研究说，这种接近物理的表示更容易从仿真转到真机。
2. **先练"老师"再教"学生"**：仿真里先训练能看到完美触觉的策略，再让只看真实触觉的策略去学它（PTLD 的做法）。
3. **把仿真校准成真机**：有了真实传感器后，用真实读数校准仿真的传感器模型。
4. **只开需要的部分**：约 3250 个格子很费算力。训练手的技能时只开手，训练平衡时只开足底。

## 6. 数据怎么走

按[系统结构](../系统结构.md)第 3 节：

| 数据 | 给谁 |
|---|---|
| 指尖、足底的原始读数（变化通道） | 脊髓层：手的防滑反射、脚底防滑、碰撞反射 |
| 足底的压力中心、接触 | 小脑层（平衡） |
| 手的接触摘要（30 Hz） | 动作脑（抓、放、用工具） |
| 全身的接触事件（被拍、被撞） | 动作脑（转头看）、思考脑（"有人拍我"） |
| 撞到人、太热 | 安全 |
| 全部原始读数 | 记录 |

## 7. 要你定的

1. 各部位的技术：手用磁式（防水），全身用电容式（同时测接近），足底用大量程阵列。可以吗？
2. 每个格子输出"持续"和"变化"两路，只在有变化时上报。可以吗？
3. 要不要"社交触觉"：分辨被拍肩膀、握手、拥抱、撞击？
4. 要不要"自己摸自己"来校准皮肤和关节？
5. 皮肤的规模（约 3250 格）先这样定下来，可以吗？
