# 听觉

2026-11-10。讨论 Nova 的听觉：人的耳朵怎么听、机器人有哪些技术、Nova 的耳朵和嘴怎么做、声音怎么处理、仿真里怎么做（MuJoCo 没有声音）。

顺便补一处漏掉的：Nova 要说话，但机体规格里没有扬声器（嘴）。这次一起补上（第 3 节）。

## 1. 人的耳朵

| 方面 | 人 | 对 Nova 的意义 |
|---|---|---|
| 频率 | 约 20 Hz~20 kHz；最灵敏的是 2~5 kHz（说话的辅音在这里） | 采样 48 kHz 足够 |
| 响度范围 | 很大：从很轻的声音到很响的声音 | 麦克风不能被很响的声音顶到头 |
| **方向：时间差** | 声音到两只耳朵的时间差，最大约 0.6~0.65 ms（从正侧面来时）；能分辨约 10~30 微秒的差；低频主要靠它 | 两只耳朵的距离按人的头来定 |
| **方向：响度差** | 头会挡住声音，离声源远的那只耳朵听到的轻一些；高频主要靠它 | - |
| **方向：外耳的形状** | 外耳对不同方向来的声音改变音色。靠它分辨**前后**和**上下** | 做人耳形状的外耳 |
| 精度 | 正前方最准，约 1°；侧面差一些 | - |
| 转头 | 分不清前后时，转一下头就清楚了 | 动作脑会转头 |
| 距离 | 响度、回声和直达声的比例、音色 | - |
| 鸡尾酒会效应 | 在很吵的地方，能专心听一个人说话 | 对准说话的人（波束形成） |
| 自己的声音 | 大脑会压低自己说话的声音 | 回声消除：减掉自己正在说的话 |
| 反应 | 简单的听觉反应约 150 ms，比视觉（约 200 ms）快；听到声音会转头（定向反射） | - |
| 保护 | 很响的声音时，中耳的小肌肉会收紧 | 麦克风的增益保护 |
| 帮触觉 | 敲一敲，听声音就知道是什么材料、瓶子是空的还是满的 | 指尖的振动传感器 + 麦克风 |

## 2. 机器人听觉的技术

| 技术 | 做什么 |
|---|---|
| 麦克风阵列定位 | 多个麦克风之间的时间差 → 声音从哪个方向来 |
| 波束形成 | 对准一个方向听，压低其它方向的声音 |
| **回声消除** | 减掉自己正在说的话，这样自己说话时也能听见人说话（能被打断） |
| **自身噪声消除** | 减掉自己的电机、风扇、脚步的声音。人形机器人的麦克风离电机很近，这是大问题 |
| 降噪 | 减掉电视、吸尘器这类背景声 |
| 有没有人说话（VAD） | 只在有人说话时才做语音识别 |
| 说话人识别 | 谁在说话 |
| 语音识别 | 说的话变成文字 |
| 声音事件识别 | 烟雾报警、玻璃碎、婴儿哭、门铃…… |
| 关键词识别 | 听到特定的词（"停"、"Nova"）；模型很小，单片机也能跑 |

**自身噪声**的做法：
- 用麦克风阵列分离出自身噪声。
- 用电机的状态（转速、开关）预测噪声，再减掉。
- 2012 年的一个系统把这几种合起来，机器人在动手臂、腿和头时，识别的正确率提高了多达 50 个百分点。
- Nova 的电机状态本来就都知道，可以直接用。

**开源的机器人听觉工具**：
- HARK（本田日本研究所）：定位、分离、语音识别，任何麦克风排法都能用，每年更新，有 ROS 接口。
- ODAS：更轻，给嵌入式设备用。

## 3. Nova 的耳朵和嘴

### 3.1 麦克风（6 个）

| 麦克风 | 数量 | 位置 | 用途 |
|---|---|---|---|
| 耳 | 2 | 头的两侧，在**人耳形状的外耳**里 | 像人一样听方向，能分前后、上下 |
| 头顶阵列 | 4 | 头顶 | 更准的方向；对准说话的人 |

规格：
- 48 kHz、24 位。
- **6 个麦克风用同一个时钟**：定位靠时间差，时钟不准方向就不准。
- 能承受很响的声音（约 130 dB）。
- 装的时候减振，离风扇和电机远一些。
- 有防水透气膜（厨房会溅水）。

**自身噪声的参考**：不加新的硬件。
- 电机的转速和电流、风扇转速、头部 IMU 的振动，本来就都知道。
- 用它们预测"自己发出的声音"，再减掉。

### 3.2 扬声器（新加）

| 扬声器 | 数量 | 位置 | 用途 |
|---|---|---|---|
| 全频扬声器 | 1 | 头部，嘴的位置附近 | 说话 |

- 音量按听的人有多远、周围有多吵自动调；夜里小声。
- 除了说话，还有简单的**提示音**，比如"我要过去了""我要拿东西了"。让家里的人能预料 Nova 要做什么。
- 扬声器放出去的声音就是回声消除要减掉的参考。

### 3.3 嘴和脸

脸（表情、口型）已经定了先不做。扬声器放在嘴的位置，以后加脸时可以和口型配合。

## 4. 声音怎么处理、给谁

```text
麦克风 ×6（同一个时钟）
  → 回声消除（减掉自己正在说的话）
  → 自身噪声消除（按电机的状态减掉自己的声音）
  → 定位：声音从哪个方向来（能分前后、上下）           → 动作脑：转头、看过去
  → 对准说话的人 → 有没有人说话 → 语音识别             → 思考脑：文字、情绪、谁在说
  → 声音事件：烟雾报警、玻璃碎、婴儿哭、门铃、敲门、
              水开了、水溢出、微波炉好了                → 思考脑；危险的也给安全
另一路：关键词"停" → 安全分区（独立运行，AI 卡住也能用） → 2 类停止
```

| 处理 | 在哪 | 给谁 |
|---|---|---|
| 关键词"停" | **安全分区**（很小的模型，像单片机上跑的那种） | 安全：2 类停止 |
| 回声消除、自身噪声消除、定位、对准说话的人 | AI 分区·快（或专门的音频处理芯片） | 动作脑（声音的方向） |
| 叫名字（"Nova"） | AI 分区·快 | 动作脑（转头看）、思考脑（开始听） |
| 语音识别 + 情绪 + 声音事件 | AI 分区·快：SenseVoice 一个模型就能同时给文字、语言、情绪和部分声音事件；处理 10 秒的语音约 70 ms（作者自报，不含 VAD） | 思考脑 |
| 专门的声音事件识别 | AI 分区·快：SenseVoice 的声音事件不如专门的模型，所以另加一个 | 思考脑；烟雾报警等危险的给安全 |
| 记录 | 按隐私规则：产品里不录原始声音 | - |

### 和人说话的设计

- **能被打断**：Nova 说话时，家里的人一开口，Nova 就停下来听。这要靠回声消除。
- **知道是不是在跟它说话**：叫了名字、看着 Nova、声音朝着 Nova，都算。
- **轮流说话**：等对方说完再回答；不确定时问。

### 隐私

- **声音事件识别一直开着**（这样才能听到烟雾报警），但**不录音**。
- **只有被叫名字或被问话时**，才把说的话转成文字。
- 听的时候有指示灯。
- 全部在机器人上处理。

### 反应目标

| 回路 | 目标 | 人 |
|---|---|---|
| 说完"停"到开始停下 | ≤ 300 ms | - |
| 听到声音到开始转头 | ≤ 200 ms | 简单的听觉反应约 150 ms |
| 被打断到停止说话 | ≤ 200 ms | - |
| 听完话到开始回答 | ≤ 1 s | 0.2~1 s |

## 5. 仿真里怎么做（MuJoCo 没有声音）

分两级。大部分时候用第一级，第二级专门验证"耳朵和音频处理"本身。

### 5.1 声音事件级（大规模训练、大部分考试）

不模拟声波，只模拟"听到了什么"：
- 每个声源记下：种类、位置、响度、开始和结束；说话的话直接记文字。
- 算出 Nova 听到的：
  - 方向：按几何算，再加误差；回声多、噪声大、在侧面时误差大；不转头时有一定概率把前后弄反。
  - 响度：按距离衰减；中间有墙时变小（用射线检测）。
  - 听不听得清：按信噪比，给语音识别加上相应的错字。
- 很快，足够考"听到声音转头""听到报警有反应""对话"。

### 5.2 波形级（验证耳朵和音频处理）

真的算出每个麦克风收到的声音：
- 声源的声音：用自己录的，或许可证允许商用的（比如 CC0 的语音数据）。
- 房间的回声：按 3D 场景的几何算"房间的冲激响应"，再和声源的声音卷积。
  - **SoundSpaces 2.0**：对任意 3D 网格按几何实时算，能做双耳；只用 CPU；快速模式约 33.5 帧/秒。用它的回声训练的语音识别，错字率比用简单方盒房间（pyroomacoustics）低（12.48% 对 16.24%）。
  - 代码是 CC-BY-4.0，商用可以（要注明出处）；但用 Matterport3D 做的数据只许非商业用途，不用。
- 两只耳朵：用 Nova 的头和外耳的模型算出"头相关传递函数"，也就是不同方向的声音到耳朵时音色怎么变。
- 自己的声音：
  - 电机和风扇的噪声，先按电机状态合成，以后换成真机录的。
  - Nova 自己说的话从扬声器模型放出来，用来测回声消除。

### 5.3 让仿真里的听觉在真机上也管用

- **随机化**：
  - 房间的回声（混响时间约 0.2~0.8 秒）
  - 背景声的种类和大小：电视、做饭、吸尘器
  - 麦克风的灵敏度，以及坏掉的麦克风
- 以后在真实的家里录音，校准仿真。

## 6. 考试要加的题

| 类 | 考题 |
|---|---|
| 方向 | 听到声音转头看过去；方向误差（前后、左右、上下） |
| 听懂 | 在吵的厨房里、开着电视时听懂指令（错字率） |
| 对话 | 自己说话时被打断，能停下来听；分出谁在说话 |
| 声音事件 | 烟雾报警（停下手上的事，告诉人）；玻璃碎（过去看看，小心碎片）；婴儿哭（告诉大人）；门铃；水开了、水溢出（去处理）；微波炉好了 |
| 安全 | 叫"停"以后多快停下 |
| 以后 | 敲一敲分出材料；分出瓶子是空的还是满的 |

## 7. 要你定的

1. **麦克风**：两耳（人耳形状的外耳）+ 头顶 4 个；48 kHz；6 个用同一个时钟。可以吗？
2. **扬声器**（规格里漏了）：嘴的位置附近；音量自动调；另有提示音。可以吗？
3. **"停"的关键词放在安全分区里独立运行**：AI 卡住也能用。可以吗？
4. **前端处理**：回声消除 + 自身噪声消除 + 定位 + 对准说话的人。可以吗？
5. **隐私**：声音事件一直听但不录音；叫名字或被问话时才转文字；有指示灯；全在机器人上处理。可以吗？
6. **仿真**：大规模训练和大部分考试用"声音事件级"；耳朵和音频处理用"波形级"（SoundSpaces 2.0 一类）验证。可以吗？
