# 第二轮讨论：肌肉还是电机、结构复杂度、传感器、目标动作、手

2026-11-09。接着 [机体结构提案 v0](04-机体结构提案.md) 的五个问题。
用户的回答：
- 传感器是做对动作的基建，**该有的都要有**。

另外三个是用户的提问：要不要模拟肌肉、结构要不要更复杂、手还能不能更好。
数值都是初估，P1 在仿真里实测后再定。

## 1. 机器人需要模拟肌肉吗

**结论：机器本身不用做成肌肉。一个关节一个电机就能当关节。要学的是肌肉带来的几种性质。**

人用肌肉，是因为生物只有肌肉这一种动力：只能拉，所以要成对；会累，所以要很多块轮流。
电机没有这些限制，能正反出力。但肌肉和肌腱有几种性质很有用，电机自己没有：

| 性质 | 人的肌肉 + 肌腱 | 关节电机（可反推） | 电机 + 弹簧 | 成对电机 + 弹簧（可变刚度） |
|---|---|---|---|---|
| 出力方向 | 只能拉，要成对 | 正反都能 | 正反都能 | 正反都能 |
| 软硬 | 两边一起用力（共同收缩），机械上立刻变 | 软件调，每 1 ms 调一次 | 弹簧本身是软的，软件再调 | 机械上可调，立刻有效 |
| 受到冲击时 | 肌腱和肌肉先吸收 | 冲击先打到齿轮，然后才等到控制反应 | 弹簧先吸收 | 弹簧先吸收 |
| 储存和放出能量 | 跟腱：落地时存，蹬地时放 | 几乎不能 | 能 | 能 |
| 精确定位 | 一般 | 很好 | 稍差 | 稍差 |
| 每个关节的驱动器数 | 好几块肌肉 | 1 | 1 | 2 |
| 控制难度 | - | 最简单 | 中等 | 难 |

### 为什么"软件调软硬"有时不够

- 电机转子的惯量，传到关节上要乘以**减速比的平方**。减速比 15 时是 225 倍，100 时是 1 万倍。
  对关节来说，就像挂着一个很重的飞轮。
- 脚落地、被撞，冲击只持续几毫秒。软件还没来得及"放软"，冲击已经经过齿轮了。
  齿轮会受伤，冲击力也会传到身体里。
- 所以：
  - 冲击大的地方（踝、膝）放一个**机械弹簧**，冲击时立刻就软。
  - 其它地方用**低减速比**（转子惯量小）加**软件调软硬**就够了。
  - Unitree G1 的腿用约 15:1 的行星减速，也是这个原因。

### 建议

- **第一版：每个自由度一个驱动（旋转电机或直线推杆）**。踝、膝等冲击大的地方加弹簧。软硬用力矩控制调。
- 直线推杆选它，不是为了"像肌肉"。是因为它抗冲击，又能把电机放到靠近身体的地方。功能上，旋转电机也能当膝关节。
- 成对电机（机械上"绷紧/放松"）**先不做**。在仿真里做对比实验，确实有明显好处的关节再加：

| 实验 | 比什么 | 测什么 |
|---|---|---|
| 踝的弹簧 | 有 / 没有 | 落地冲击的峰值、走路和跑步的耗电 |
| 膝的弹簧 | 有 / 没有 | 跳的高度、落地冲击 |
| 肘的驱动 | 一个电机 / 成对电机 | 接球、被撞时的冲击力、精细动作的误差 |
| 双关节连接 | 有 / 没有大腿跨到脚跟的弹性连接（像腓肠肌） | 走路、跑步的耗电 |

- **肌肉模型在仿真里的用处**：不用来做 Nova 本身，用来做"人类参照"。
  例如让 MyoSuite 的全身肌肉模型（416 块肌肉）做同一个动作，比较人和 Nova 用的力矩和能量，帮助定驱动器的规格。

## 2. 结构要不要更复杂

**原则：只在两种情况下加复杂度。**
1. 目标动作需要。
2. 人靠它获得明显的功能。

现在目标改成"人能做的都能做"，按更难的动作（投掷、舞蹈、瑜伽、倒立、攀爬）重看每个部位：

| 部位 | v0 | 人 | 建议 v0.1 | 多做到什么 | 代价 |
|---|---|---|---|---|---|
| 脊柱 | 腰一节 3 | 24 节可动的椎骨。**身体扭转大部分在胸椎**，腰椎每边只转约 5~10° | **腰椎 3 + 胸椎 3** | 扭身挥拍、投掷、回头看身后、坐着转身、瑜伽、舞蹈 | +3 个驱动；躯干里还要放电池 |
| 颈 | 3 | 上颈（点头、摇头）+ 下颈（前后弯） | **4**：下颈前后 + 上颈 3 | 探头、收下巴、看桌子下面 | +1 个驱动 |
| 肩胛 | 每侧 2 | 上提、前伸、**上旋**（手举过头时，约 60° 来自肩胛上旋） | **每侧 3**（加上旋） | 手臂伸直过头、倒立、游泳动作、投掷 | +2 个驱动 |
| 肩、肘、前臂、腕 | 7 | 同左 | 不变 | - | - |
| 髋 | 3 | 3 | 不变，活动范围按人的上限做 | - | - |
| 膝 | 1 | 弯曲时还能转 10~30° | 不变；转动用髋来补 | 少数运动的转身 | 不值得 |
| 踝 | 2 | 2（距小腿关节 + 距下关节） | 不变 | - | - |
| 脚 | 刚性脚 + 被动脚趾 1 | 26 块骨、33 个关节；有足弓；大脚趾和其它脚趾分开 | **大脚趾主动**（肌腱从小腿拉，像人的屈拇长肌）+ **其它脚趾被动** + **足弓被动弹簧** | 踮脚站、单脚平衡、不平的地面、落地缓冲 | +1 个驱动/脚；脚的结构更复杂 |
| 眼 | 2×2 | 每只眼 3（第三个是转动，用处小） | 不变；眼睑待定 | - | - |
| 脸、嘴 | 无 | 表情、口型 | **待定**：要不要做脸？ | 表情、口型 | 很多小驱动，和动作能力无关 |

## 3. 传感器：该有的都有

按用途分组。"人有"表示人身上有对应的感觉；"比人多"是人没有、但对做对动作有用的。

| 用途 | 传感器 | 放在哪 / 数量 | 人有 / 比人多 |
|---|---|---|---|
| 平衡和姿态 | IMU | 头、胸、骨盆、两手、两脚，共 7 个 | 头的相当于前庭；其它的帮助估计每段身体的状态 |
| 关节 | 电机编码器 + 关节侧绝对编码器 | 每个关节两个 | 人有（肌梭）。中间有弹性，两边都要量 |
| 力 | 电机电流（换算力矩） | 每个驱动器 | 人有（高尔基腱器） |
| | 推杆里的力传感器 | 每根直线推杆 | 丝杠有摩擦，用电流估不准，所以直接量 |
| | 弹簧变形量 | 踝、膝、手指的弹簧 | 人有（跟腱、肌腱） |
| | 肌腱张力 | 手、大脚趾 | 人有 |
| | 腕部 6 轴力/力矩 | 两腕 | 比人多 |
| | 踝部 6 轴力/力矩 | 两踝 | 比人多（地面反力更准） |
| 接触和触觉 | 足底压力阵列（含切向力） | 每只脚：脚跟、脚掌、脚趾 | 人有 |
| | 皮肤：压力 + 切向力 | 指尖约 2 mm 间距；手掌约 5~10 mm；全身约 3~4 cm | 人有 |
| | 指尖振动 | 每个指尖 | 人有（感受快速振动的环层小体，约 40~400 Hz）：感觉纹理、发现开始滑动 |
| | 指尖温度 | 每个指尖 | 人有：知道东西冷热，避免抓起烫的东西 |
| 视觉 | 眼的相机（全局快门） | 两只眼，间距 63 mm | 人有 |
| | 额头深度相机 | 1 | 比人多：深度更稳 |
| 听觉 | 两耳麦克风 | 2 | 人有 |
| 安全和自身状态 | 电机绕组和驱动器温度、母线电压、电池每节电芯的状态、碰撞检测（力矩 + 皮肤）、跌倒检测（IMU） | 全身 | 人有一部分（痛、累、饿） |

可选（研究用，模型里留位置）：
- 手掌相机（Figure 03 的做法）
- 头顶麦克风阵列
- 皮肤接近觉：快碰到时就知道
- 事件相机：像视网膜一样只报告变化，延迟极低

### 基建要求（比传感器本身还重要）

1. **统一时钟**：所有传感器用同一个时钟打时间戳。相机和 IMU 要硬件同步，否则融合时对不上。
2. **标定**：
   - 关节零点、IMU、相机内外参。眼会转，所以眼的角度要量得很准。
   - 触觉格子的灵敏度。
   - 仿真里的读数是完美的，所以要故意加上标定误差。
3. **全部记录**：每次运行都记下所有传感器和命令（rosbag2 → LeRobot 数据），以后用来训练和查问题。
4. **冗余**：关键的感觉有两个来源，坏一个还能动。比如关节角度有电机侧和关节侧两个，地面接触有足底压力和踝的力传感器两个。

### 数据量估计

| 数据 | 估算 | 每秒 |
|---|---|---|
| 触觉 | 指尖 10 个 × 约 75 格 + 指节、手掌约 600 格 + 全身约 1500 格 ≈ 3000 格 × 3 个值 × 200 Hz | 约 4 MB |
| 相机 | 两只眼 1280×1024 × 30 帧（原始数据） | 约 80 MB |
| 关节、IMU、力 | 84 个驱动 + 7 个 IMU，1 kHz | 约 2 MB |

总共每秒约 100 MB 以下，机载电脑处理得了。
**仿真里最贵的是 3000 个触觉格子和相机渲染**，要实测速度。大规模训练时可以只开需要的部分。

## 4. 目标：人能做的动作，Nova 都能做

| 类 | 例子 | 对设计的要求 |
|---|---|---|
| A 日常 | 走、上下楼、坐下站起、躺下再起来、蹲、弯腰捡东西、搬东西、开门 | 腿和腰的力矩，关节范围 |
| B 运动 | 跑（慢跑约 3 m/s）、跳（立定跳远、跳高）、踢球、投掷、爬梯子、攀爬 | **功率**：跑跳时踝的瞬间功率可到几百瓦到一千瓦左右；胸椎和肩胛（投掷）；**握力**（吊起全身） |
| C 柔韧和技巧 | 舞蹈、瑜伽、侧手翻、倒立、前滚翻、俯卧撑、引体向上 | 关节范围到人的上限；手腕撑得住；外壳和关节经得起着地、翻滚 |
| D 精细操作 | 写字、扣扣子、系鞋带、用筷子、打字、弹琴、穿针 | 手的自由度、指尖触觉、手指速度 |
| E 和人在一起 | 握手、拥抱、递东西、手势 | 柔顺、全身触觉、安全 |
| F 表情和说话 | 表情、口型 | 要不要做脸（待定） |

### 对力量的影响（按 70 kg 重估峰值）

| 关节 | v0 | 新目标 | 卡住的动作 |
|---|---|---|---|
| 髋 前后 | 250~300 N·m | 300 N·m | 跳、跑 |
| 膝 | 250~300 N·m | 300 N·m | 跳、深蹲站起 |
| 踝 前后 | 150~250 N·m | 250 N·m，瞬间功率约 1 kW | 跑、跳 |
| 腰 前后 | 150~250 N·m | 250 N·m | 搬重物、仰卧起坐 |
| 肩 | 80~120 N·m | 120~150 N·m | 引体向上（每只手臂要拉起半个身体）、俯卧撑、投掷 |
| 肘 | 60~80 N·m | 100 N·m | 引体向上 |
| 腕 | 10~20 N·m | 20~30 N·m | 俯卧撑、倒立、拧东西 |
| 握力（每只手） | 100~200 N | 350~400 N | 吊在单杠上：每只手撑半个体重 |
| 颈 | 10~20 N·m | 20~30 N·m | 仰卧起坐时抬头 |

### 现实的说法

- **仿真里可以按人的水平设计**：驱动器的规格可以随便设，先看人的每个动作要什么样的驱动器。
- **真机最难的是手**：要同时有人的力量（握力约 400 N，能吊起自己）和人的灵巧。现在还没有机器人公开做到。
- **手臂会变重**：手臂和手的驱动器变大，体重会往上走（估计 70~72 kg），这又会反过来增加腿要的力。这个循环要在 P1 里算清楚。
- 所以做法是：
  1. 先把"人的能力表"（每个关节的范围、力量、速度、功率）定为设计目标。
  2. 仿真验证。
  3. 每个关节标出"能买到 / 勉强 / 现在做不到"。
  4. 真机时再取舍。
- **动作数据**：全身用 AMASS；手和物体的交互有 GRAB、ARCTIC 等数据集。多数只许研究使用，用前要查许可证。

## 5. 手还能怎么更好

成对肌腱是基础。在它之上，还能学人的手的更多做法：

| 改进 | 学人的什么 | 好处 | 代价 | 建议 |
|---|---|---|---|---|
| **外在肌 + 内在肌分工** | 人的手指弯伸靠前臂的肌肉（外在肌）；手指张开合拢、拇指对掌，靠手掌里的小肌肉（内在肌：骨间肌、大鱼际肌） | 大力的弯伸从前臂来；精细的张开和拇指动作用手掌里的小驱动，走线短、准；穿过手腕的肌腱变少，手腕对手指的影响也小 | 手重约 0.25 kg | **建议** |
| **解剖学的拇指** | 拇指根部是鞍状关节，两根转轴不垂直、也不相交 | 对掌范围更大，拇指能碰到每个指尖 | 设计复杂 | **建议** |
| **软指腹 + 指甲** | 指腹会变形；指甲在背后顶着 | 接触面积大，抓得稳；指甲能捡硬币、掀纸边；指甲给指腹一个支撑，触觉更准 | 指尖结构复杂 | **建议** |
| **指纹一样的纹路** | 指纹 | 摩擦更大；放大振动，更容易感到纹理和滑动 | 皮肤要做纹路 | 建议，先在仿真里试 |
| **滑轮式走线** | 人的手指有一圈圈环形滑车，让肌腱贴着骨头走 | 摩擦小，力传得准，肌腱不会"弓起来" | 零件多 | **建议** |
| **拉住时能自锁** | 人会累，机器可以不累 | 提重物、吊着时不费电、不发热 | 自锁时不能反推，柔顺要靠肌腱上的弹簧 | 建议用在弯曲方向 |
| **拇指和食指的成对驱动** | 捏东西时两边一起用力 | 机械上可调软硬，捏、接更稳 | 每只手 +4 个驱动 | 可选，先做仿真实验 |
| 肌腱的维护 | - | 肌腱会磨损、会慢慢伸长：两端都量张力，能发现松弛；手指做成能整根换 | - | 真机必须 |

### 手 v0.1 的驱动分布（每只手）

| | 前臂里（外在肌） | 手掌里（内在肌） |
|---|---|---|
| 食指~小指 | 每根 2 个：掌指弯伸、近指间弯伸（远指间联动）→ 8 | 每根 1 个：张开合拢 → 4 |
| 拇指 | 2：掌指弯伸、指间弯伸 | 3：腕掌 2（对掌）、掌指侧摆 |
| 手掌 | - | 1：拢成碗 |
| 合计 | 10 | 8 |

一共还是 18 个驱动，但前臂里从 18 个减到 10 个，手掌里 8 个微型驱动：
- 手约 0.85 kg（人约 0.4 kg）
- 前臂约 1.8 kg（人约 1.05 kg）
- 加上更大的握力要求，弯曲方向的驱动要更有力，在 P1 里算

### 怎么验收

- **Kapandji 拇指测试**：拇指依次碰到各个指节和指尖。
- **人的 33 种抓握**：按 GRASP 抓握分类（Feix 等，2016），33 种都要能做出来。
- 握力 350~400 N；能感到几克的力；指尖能分辨约 2 mm 的两点。

## 7. 要你确认的

1. 第 1 节：机器本身不做肌肉，每个自由度一个驱动，踝、膝加弹簧，成对电机等仿真实验后再定。可以吗？
2. 第 2 节：胸椎、下颈、肩胛上旋、大脚趾主动、足弓，都加上。可以吗？**要不要做脸**（表情、口型）？
3. 第 3 节的传感器清单还缺什么？
4. 第 4 节：动作分类和力量重估。真机做不到的地方，先在仿真里按人的水平做，可以吗？
5. 第 5 节的手的改进：哪些要，哪些不要？
