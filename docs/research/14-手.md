## 1. 人的手

### 1.1 骨、关节、肌肉

- **骨**：27 块（腕骨 8、掌骨 5、指骨 14）。
- **关节**（每根手指从根到尖）：
  - 掌指关节（MCP）：能弯伸，也能左右摆。
  - 近指间关节（PIP）、远指间关节（DIP）：只能弯伸。
  - 拇指根部的腕掌关节（CMC）是鞍状的，两个方向都能动，所以拇指能"对掌"（转过来碰到别的手指）。
- **两组肌肉**：

| 组 | 在哪 | 管什么 |
|---|---|---|
| 外在肌 | 前臂，用长肌腱拉手指 | 有力的弯和伸：指浅屈肌拉中节、**指深屈肌拉末节（跨过近指间和远指间两个关节）**、拇长屈肌拉拇指末节；伸肌经过手背的"伸肌腱帽" |
| 内在肌 | 手掌里 | 精细的动作：骨间肌（手指张开、合拢）、蚓状肌、大鱼际肌（拇指对掌）、拇收肌（侧捏的力）、小鱼际肌（手掌拢成碗） |

- **滑车**：手指上一圈圈的环形韧带（A1~A5），让肌腱贴着骨头走。没有它，肌腱一拉就会像弓弦一样弹起来。
- **远指间跟着近指间动**：指深屈肌同时跨过这两个关节，指浅屈肌又在近指间那里分叉、包住它，所以远指间基本跟着近指间弯，两者的关系是一条 S 形的曲线。

### 1.2 能力

| 能力 | 人（大致） |
|---|---|
| 握力 | 成年男性约 400 N |
| 指尖捏（拇指尖对食指尖） | 年轻男性约 80 N |
| 侧捏（拇指压在食指侧面，像拿钥匙） | 约 115 N |
| 三指捏（拇指对食指、中指） | 约 115 N |
| 拇指 | 临床上常把拇指算作手的功能的约 40% |
| 速度 | 手指敲击每秒约 5~7 次 |

捏力是 Mathiowetz 1985 的成人常模（第三方表格，20~24 岁男性右手）。

### 1.3 协同：大脑只管几个"组合动作"

- 人做各种抓握时的手形，**前两个"组合动作"就能解释 80% 以上的变化，前三个约 90%**（Santello 1998，用 15 个关节的数据）。
- 也就是说，大脑先用少数几个组合定下大致的手形，再在上面做小的调整。
- 机器人里叫"本征抓握"，常用来先摆好手形。

## 2. 现在的机器人手

| 手 | 自由度 | 驱动 | 特点 |
|---|---|---|---|
| Tesla Optimus V3（专利） | 手 + 腕约 22 | 每条前臂 25 个直线驱动，每根手指 3 根肌腱 | 电机全在前臂 |
| 1X NEO | 手 22（加腕 25） | 前臂电机，低减速比（约 5:1~15:1） | 为家用的安全 |
| 小鹏 IRON | 22 | 很小的谐波关节 | - |
| Tesollo DG-5F-S（2026） | 20 | 电机在手里 | 880 g；捏取负载 1~2 kg、包握 7~12 kg（零售商资料） |
| BiDexHand（开源） | 16 | 拉线驱动 | 远指间用交叉四连杆跟着近指间动，按人的 S 形曲线 |
| Shadow Hand | 24 个关节、20 个驱动 | 前臂电机 + 肌腱 | 研究用的老牌灵巧手 |

**最大的差距是力气**：DG-5F-S 的捏取负载 1~2 kg（约 10~20 N），人的指尖捏约 80 N。

## 3. Nova 的手

### 3.1 尺寸和质量

- 手长约 0.18 m（身高的 0.108）；各节手指的长度比例按人手的测量数据。
- 每只手 ≤ 0.85 kg：
  - 手掌里的 8 个微型驱动约 0.25 kg
  - 骨架、关节、轴承约 0.25 kg
  - 肌腱和滑车约 0.05 kg
  - 皮肤、触觉、电子约 0.2 kg
  - 手掌相机约 0.03 kg
  - 合计约 0.78 kg

### 3.2 关节和活动范围

| 部分 | 关节 | 人的范围（大致） | Nova | 驱动 |
|---|---|---|---|---|
| 食指~小指（每根） | 掌指 弯伸 | 弯约 90°，往后伸约 20~45° | 弯 90°，伸 30° | 前臂 1 个（食指另加 1 个反向驱动，成对） |
| | 掌指 左右摆 | 约 ±20° | ±20° | 手掌 1 个 |
| | 近指间 | 0~100° 左右 | 0~105° | 前臂 1 个（同时带动远指间） |
| | 远指间 | 0~80° 左右 | 0~80°，跟着近指间动 | 联动（见下） |
| 拇指 | 腕掌（鞍状）弯伸 + 外展 | 约 50°、约 40~60° | 同人；两根转轴不垂直、也不相交 | 手掌 2 个 |
| | 掌指 弯伸 | 0~60° | 0~60° | 前臂 1 个 + 1 个反向驱动（成对） |
| | 掌指 侧摆 | 很小，约 ±10° | ±10° | 手掌 1 个 |
| | 指间 | 0~80° | 0~80° | 前臂 1 个 |
| 手掌 | 无名指和小指的掌骨（拢成碗） | 小幅弯 | 0~20°，小指比无名指多 | 手掌 1 个 |

- 合计：22 个关节；驱动：前臂 12 个（手指 8 + 拇指 2 + 成对 2），手掌 8 个。
- **远指间的联动**：用交叉四连杆让远指间按人的 S 形曲线跟着近指间动（BiDexHand 的做法）。连杆里加一段弹性，按到东西时末节能被动地顺着形状弯。

### 3.3 驱动和肌腱

| 部分 | 怎么做 |
|---|---|
| 前臂的 12 个驱动 | 小型直线推杆（丝杠），弯曲方向能自锁（拿着东西不费电）。一般的关节：一个推杆同时拉弯和伸两根肌腱，一边拉、一边放。成对的关节（拇指掌指、食指掌指）：弯和伸各一个推杆，可以一起拉紧，机械上调软硬 |
| 手掌的 8 个驱动 | 微型电机 + 减速，用短肌腱或连杆带动；密封在手掌里 |
| 穿过手腕 | 所有肌腱从手腕中间的"腕管"穿过，尽量靠近手腕的转轴。手腕动时肌腱长度变得最少，剩下的由控制补偿 |
| 手指上 | 环形滑车（像人的 A2、A4），让肌腱贴着骨头走；低摩擦的套管 |
| 伸的一侧 | 简化的"伸肌腱帽" |
| 肌腱 | 低蠕变的高强度纤维（会慢慢伸长的材料不行）；每根串一段弹簧（柔顺 + 测张力）；两端都测张力，发现松弛、磨损、摩擦变大；自动保持预紧力 |

**力量是手最难的地方**。估算一下：
- 指尖用 40 N 按东西时，指尖到掌指关节约 8~9 cm，屈肌腱绕掌指关节的力臂约 1 cm。
- 所以屈肌腱要拉约 300~360 N，前臂里的屈肌推杆每个要几百牛。
- 目标按人：握力 350~400 N、指尖捏约 80 N、侧捏约 115 N。
- P1 里按这些目标算出每个驱动要多大的力、多快、多重，再看前臂放不放得下。

**速度**：手指关节 ≥ 300~500°/s（人敲手指每秒约 5~7 次）。

### 3.4 传感器（已定的汇总）

| 传感器 | 位置 |
|---|---|
| 磁式三轴触觉，约 2 mm；振动；温度 | 指尖（软指腹、指纹纹路、指甲） |
| 磁式三轴触觉，5~7 mm；温度 | 指节、手掌 |
| 关节角度（小的磁编码器） | 每个关节，包括联动的远指间 |
| 肌腱张力 | 每根肌腱两端；弹簧的变形 |
| 手掌相机 | 手掌 |
| 6 轴力/力矩 | 手腕 |

**防水**：手里只有 8 个微型驱动和传感器，都密封在手掌里；肌腱从手腕穿出的地方也要密封。

### 3.5 耐用和维护

- **目标：100 万次抓握不坏**。家里每天约 1000 次的话，约是 3 年（初定）。
- 每根手指做成能整根换的模块，肌腱用快速接头。
- 指尖的软指腹可以换。
- 记下每根肌腱的张力随时间的变化，提前发现快要换的肌腱。

### 3.6 控制

| 层 | 做什么 |
|---|---|
| 脊髓层 | 关节和肌腱之间的换算：一个关节动，几根肌腱的长度都会变；手腕动也要补偿。保持预紧力、不让肌腱松掉；防滑反射；最大肌腱力和关节范围的保护；成对驱动的关节按需要调软硬 |
| 动作脑 | 给手的目标：关节角度 + 抓力 + 软硬，直接交给脊髓层（不经过小脑层） |

- **先在"手的协同"里学**：动作脑先在少数几个组合动作里学会大致的手形，再细化到每个关节。学得快，要的数据也少。
- **遥控很直接**：Nova 的手和人手几乎一样，VR 手部追踪的数据几乎能一对一转过来。这是做"像人的手"最大的好处之一。

### 3.7 仿真

| 项目 | 做法 |
|---|---|
| 关节和肌腱 | MuJoCo 的关节 + 空间肌腱：经过导向点，绕过圆柱或球（当作滑车）；肌腱上的弹簧；驱动器拉肌腱 |
| 远指间的联动 | 等式约束或连杆闭链 |
| 指腹 | 软接触（调接触的软硬）；要更真时用可变形体（慢） |
| 摩擦 | 指尖要有扭转和滚动摩擦（MuJoCo 的 condim 6）。拧瓶盖靠的就是扭转摩擦 |
| 参照 | MuJoCo Menagerie 里的 Shadow Hand、LEAP Hand |
| 训练 | 手的技能先在"只有手和前臂"的小场景里练，快；练好再放回全身 |
| 物品 | 日用品的 3D 模型（许可证要查） |

### 3.8 考试要加的题

| 类 | 考题 |
|---|---|
| 力量 | 握力、指尖捏、侧捏、三指捏，和人的数比 |
| 速度 | 手指每秒能敲几次 |
| 手里的动作 | 手里转笔；翻一张卡片 |
| 用工具 | 用剪刀、勺子；抹黄油 |
| 以后 | 扣扣子、拉拉链、打字、弹琴 |
| 耐用 | 连续抓放多少次不坏 |

## 4. 要你定的

1. **关节和范围**（3.2 节）按人手；远指间按人的曲线联动、带一点弹性。可以吗？
2. **驱动和走线**：前臂 12 个直线推杆、手掌 8 个微型驱动；腕管、滑车、套管、伸肌腱帽。可以吗？
3. **力量和速度按人**：握力 350~400 N、指尖捏约 80 N、侧捏约 115 N，关节 ≥ 300~500°/s；P1 里算出每个驱动要多大。可以吗？
4. **耐用**：目标 100 万次抓握；手指整根可换。可以吗？
5. **控制**：先在"手的协同"里学，再细到每个关节。可以吗？
