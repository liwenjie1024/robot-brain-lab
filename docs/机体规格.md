# Nova 机体规格（当前版本 v0.3）

**这份是当前的规格，只放现在定下的东西。** 为什么这样定，见各篇调研和讨论：
- v0：[机体结构提案](research/04-机体结构提案.md)
- v0.1：[第二轮讨论](research/05-第二轮讨论.md)
- 急停：[急停](research/06-急停.md)
- v0.3：加上家用要求、复杂度要有证据、能耗和续航（[怎样做成一个真正成功的机器人](research/09-怎样做成一个真正成功的机器人.md)）

力矩、质量都是初估。P1 在仿真里实测后改这份。

2026-11-09 用户定的原则：**能做得更好的地方，就做得更好。**
这里的"更好"指对目标动作和"做对动作"更有利，不是零件越多越好。

## 1. 定位

| 项目 | 规格 |
|---|---|
| 名字 | Nova |
| 大小 | 身高 1.70 m，体重目标 70~72 kg（P1 里算出来） |
| 比例 | 按人体测量学（各段长度 Winter，各段质量 de Leva） |
| 能力目标 | 人能做的动作都能做（日常、运动、柔韧和技巧、精细操作、和人在一起） |
| 做法 | 先在仿真里按人的水平做；做真机时，每个关节标出"能买到 / 勉强 / 现在做不到"再取舍 |
| 成功的标准 | 人能依靠它。两者都要：能力证明 + 家务可靠。**第一件要做到可靠的事是家务**。用 [Nova 考试](Nova考试.md) 衡量 |

## 2. 自由度和驱动：98 个自由度、90 个驱动器

```text
Nova（98 / 90）
├─ 头（10 / 10）：下颈 1、上颈 3、眼 2×2、眼睑 2
├─ 躯干（12 / 12）：腰椎 3、胸椎 3、肩胛 3×2
├─ 手臂 ×2（14 / 14）：肩 3、肘 1、前臂转 1、腕 2
├─ 手 ×2（44 / 40）：每只 22 个自由度、20 个驱动（前臂 10 + 手掌 8 + 拇指和食指的成对驱动 2）
└─ 腿 ×2（18 / 14）：髋 3、膝 1、踝 2、大脚趾 1（主动）、其它脚趾 1（被动）、足弓 1（被动）
```

驱动方式：
- **旋转** = 无框电机 + 行星减速器（低减速比，能反推）
- **直线推杆** = 电机 + 行星滚柱丝杠，像肌肉一样推拉
- **微型** = 小电机，用在眼、眼睑、手

所有大电机都有：安全断扭矩（STO）、断电时的短路制动、电机侧和关节侧两个编码器。

| 部位 | 关节 | 自由度 | 驱动 | 驱动器在哪 | 峰值力矩目标 |
|---|---|---|---|---|---|
| 头 | 下颈 前后 | 1 | 旋转 | 颈底 | 30 N·m |
| | 上颈 点头、侧屈、转 | 3 | 旋转 | 颈上部 | 各 20 N·m |
| | 眼 左右、上下（每只） | 2×2 | 微型 | 头里 | - |
| | 眼睑（每只） | 1×2 | 微型 | 头里 | 保护和清洁相机窗口、眨眼 |
| 躯干 | 腰椎 前后 + 侧弯 | 2 | 两根推杆并联 | 腹部两侧 | 前后 250、侧 150 N·m |
| | 腰椎 转 | 1 | 旋转 | 骨盆上方 | 60 N·m（人的腰椎只转一点） |
| | 胸椎 转 | 1 | 旋转 | 胸椎 | 100 N·m（身体扭转主要在这里） |
| | 胸椎 前后 + 侧弯 | 2 | 两根推杆并联 | 背部 | 各 100~150 N·m |
| | 肩胛 上提、前伸、上旋（每侧） | 3×2 | 推杆 | 胸背 | 推杆力几百 N（待测） |
| 手臂（每条） | 肩 前后、侧摆 | 2 | 旋转 | 胸内、肩 | 120~150 N·m |
| | 肩 转 | 1 | 旋转 | 上臂上部 | 60 N·m |
| | 肘 | 1 | 旋转 | 上臂下部 | 100 N·m |
| | 前臂转 | 1 | 旋转 | 前臂靠肘的一端 | 15 N·m |
| | 腕 屈伸、侧偏 | 2 | 两根推杆并联 | 前臂 | 20~30 N·m |
| 腿（每条） | 髋 前后 | 1 | 旋转 | 骨盆 | 300 N·m |
| | 髋 侧摆 | 1 | 旋转 | 骨盆 | 200 N·m |
| | 髋 转 | 1 | 旋转 | 大腿上部 | 120 N·m |
| | 膝 | 1 | 推杆 + 像髌骨的连杆；做不到范围和速度就换旋转 | 大腿 | 300 N·m，弯到 130° 以上 |
| | 踝 前后 + 侧 | 2 | 两根推杆并联 + 弹簧和阻尼器（像跟腱） | 小腿上部 | 前后 250 N·m（瞬间约 1 kW）、侧 100 N·m |
| | 大脚趾 | 1 | 肌腱从小腿拉（像人的屈拇长肌） | 小腿 | 约 10 N·m（待测） |
| | 其它脚趾、足弓 | 2 | 被动：弹簧 + 阻尼器 | 脚 | - |

## 3. 手（每只：22 个自由度、20 个驱动）

| 部分 | 关节 | 驱动 |
|---|---|---|
| 食指~小指 | 掌指屈伸、掌指侧摆、近指间、远指间（和近指间联动） | 前臂 2（弯伸）+ 手掌 1（张开合拢） |
| 拇指 | 腕掌 2（解剖学的鞍状关节）、掌指 2、指间 1 | 前臂 2（弯伸）+ 手掌 3（对掌、侧摆） |
| 手掌 | 拢成碗 | 手掌 1 |
| 成对驱动 | 拇指掌指弯曲、食指掌指弯曲各加一个反向驱动 | 前臂 2：捏东西时机械上可调软硬 |

其它设计：
- 成对肌腱 + 串联弹簧；滑轮式走线（像人的环形滑车）
- 弯曲方向能自锁：提重物不费电
- 软指腹、指甲、指纹纹路
- 肌腱两端都量张力；手指能整根更换

目标：
- 握力 350~400 N
- 能感到几克的力，指尖能分辨约 2 mm 的两点
- 通过 Kapandji 拇指测试
- 能做出人的 33 种抓握（GRASP 分类）

## 4. 感觉（全部都装；仿真里按实验需要打开）

| 用途 | 传感器 |
|---|---|
| 平衡和姿态 | IMU ×8：头、胸、骨盆 ×2（互相对照，一个坏了另一个接替）、两手、两脚 |
| 关节 | 每个关节两个编码器：电机侧 + 关节侧。被动关节（脚趾、足弓、手指远端）也量 |
| 力 | 电机电流（全部）；每根推杆的力传感器；弹簧的变形量；肌腱张力；腕部 6 轴 ×2；踝部 6 轴 ×2 |
| 接触 | 足底压力阵列（含切向力）×2 |
| | 皮肤：指尖约 2 mm、手掌约 5~10 mm、全身约 3~4 cm 间距 |
| | 指尖振动 ×10、指尖温度 ×10 |
| | 接近觉皮肤：手臂、躯干、大腿、头，快碰到时就知道 |
| 视觉 | 眼的相机 ×2（全局快门，间距 63 mm） |
| | 额头深度相机 ×1、额头事件相机 ×1（像视网膜，只报告变化，延迟极低） |
| | 手掌相机 ×2 |
| | 环视相机 ×4（低分辨率，看身后和周围，为了安全） |
| 听觉 | 两耳麦克风 ×2、头顶麦克风阵列 ×4 |
| 安全和自身状态 | 电机和驱动器温度、母线电压电流、电池每节电芯、STO 和制动器状态、碰撞检测、跌倒检测 |

基建：
- 统一时钟：相机和 IMU 硬件同步
- 标定：仿真里故意加标定误差
- 全部记录：rosbag2 → LeRobot 数据
- 冗余：关键感觉有两个来源

## 5. 停止和安全

| 级别 | 做什么 | 什么时候 |
|---|---|---|
| 2 类 | 受控停止，保持通电，站着保持平衡 | 平时的"停" |
| 1 类 | 受控停止，降低重心（蹲下或跪下）后再断电并锁住 | 要断电的急停（首选） |
| 0 类 | 立刻安全断扭矩 + 短路制动，机器人慢慢坐下 | 硬件急停按钮、控制失灵 |

其它措施：
- 低等效惯量
- 控制里加阻尼，弹簧旁并联阻尼器
- 保持制动器只装在少数关节上：先慢慢坐下，停稳再锁住。哪些关节装，用仿真定
- 制动电阻
- 保护性摔倒（训练出来的反射）
- 看门狗链：大脑 → 实时控制器 → 驱动器
- 急停入口：机身按钮、无线急停、全身触觉检测碰撞

## 6. 身体里面

| 位置 | 放什么 |
|---|---|
| 头 | 眼、眼睑、耳、头部 IMU、相机、麦克风 |
| 胸 | 主电脑（带 GPU，要散热）、网络交换机、肩前后的电机、肩胛推杆、胸椎驱动、颈底电机 |
| 腹和骨盆 | 电池（约 2~2.5 kWh）、电源分配、制动电阻、骨盆 IMU ×2、安全控制板、腰和髋的电机 |
| 四肢 | 电机驱动板就近放 |
| 外层 | 软的包覆，里面是触觉皮肤和接近觉皮肤；关节缝隙防夹 |

## 7. 还没定的

都要靠仿真实验或调研来定：

1. **成对电机**：除了拇指和食指，肘、膝等要不要加。用仿真实验定。
2. **保持制动器**装在哪些关节。用仿真实验定。
3. **膝**用推杆还是旋转电机。用仿真验证范围和速度。
4. **驱动器能不能买到**：P1 测出规格后调研。
5. **质量**：手臂变重 → 腿的要求变高。这个循环在 P1 里算清楚。
6. **哪些自由度和传感器进真机**：按第 10 节的仿真对比来定。

## 9. 家用的要求（2026-11-09 加）

第一件要做到可靠的事是家务，所以身体要适合家里：

| 项目 | 要求 |
|---|---|
| 尺寸 | 能过 80 cm 宽的门，在厨房里转身；肩宽 0.44 m |
| 高度 | 1.70 m，够得到厨房的吊柜和冰箱的上层 |
| 安静 | 尽量安静，目标 40 dB 以下（以后实测；1X NEO 说它约 22 dB） |
| 防水 | 手和前臂能碰水和清洁剂（洗碗、擦桌子）；防护等级以后定 |
| 安全 | 软外壳、防夹；靠近小孩和宠物时自动变慢、变软；接近觉皮肤 |
| 地面 | 木地板、瓷砖、地毯、门槛都能走；脚底防滑；楼梯 |
| 外观 | 友好，一看就是机器人，避开"恐怖谷" |
| 充电 | 自己回到充电座充电 |

## 10. 复杂度要有证据（2026-11-09 加）

每多一个关节、一个传感器，就多一个会坏的地方。所以：

1. **仿真里先全做**：98 个自由度和全部传感器。
2. **逐个对比**：在 Nova 考试上比较"有它"和"没有它"：
   - 身体：胸椎、肩胛上旋、大脚趾、足弓、眼球转动、拇指和食指的成对驱动……
   - 感觉：每一种传感器
3. **有证据才进真机**：
   - 让考试分数明显变好的，进真机。
   - 某一类考题（比如能力证明里的柔韧动作）非它不可的，进真机。
   - 都不是的，真机先不做，模型里留位置。
4. 对比的结果记进决定记录。

## 11. 能耗和续航（2026-11-09 加）

据行业估计，现在的人形机器人一次充电只能工作约 2 小时。Nova 关节多、前臂重，更要省电：

| 项目 | 要求 |
|---|---|
| 目标 | 一次充电做完一轮家务（连续 2 小时），还有余量自己回去充电；以后再提高 |
| 省电的身体 | 低减速比（转子惯量小）；踝和足弓的弹簧存放能量；弯曲方向能自锁的手指（拿着东西不费电） |
| 省电的行为 | 不动的时候坐下或靠着休息；思考脑安排家务的顺序时考虑电量；电量低了自己去充电 |
| 考试 | 每项家务的耗电都记在 Nova 考试里，和成功率一起看 |
