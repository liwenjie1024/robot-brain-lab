## 1. 定位

| 项目 | 规格 |
|---|---|
| 名字 | Nova |
| 大小 | 身高 1.70 m；**体重目标 ≤ 65 kg，力争 60 kg**：力量照人，体重比人轻（摔倒、撞到人时冲击小；同样的电机跳得更高）。P1 里算出来 |
| 比例 | 按人体测量学（各段长度 Winter，各段质量 de Leva） |
| 能力目标 | 人能做的动作都能做（日常、运动、柔韧和技巧、精细操作、和人在一起） |
| 做法 | 先在仿真里按人的水平做；做真机时，每个关节标出"能买到 / 勉强 / 现在做不到"再取舍 |
| 成功的标准 | 人能依靠它。两者都要：能力证明 + 家务可靠。**第一件要做到可靠的事是家务**。用 [Nova 考试](Nova考试.md) 衡量 |

## 2. 自由度和驱动：98 个自由度、90 个驱动器

```text
Nova（98 / 90）
├─ 头（10 / 10）：下颈 1、上颈 3、眼 2×2、眼睑 2
├─ 躯干（12 / 12）：腰椎 3、胸椎 3、肩胛 3×2
├─ 手臂 ×2（14 / 14）：肩 3、肘 1、前臂转 1、腕 2
├─ 手 ×2（44 / 40）：每只 22 个自由度、20 个驱动（前臂 10 + 手掌 8 + 拇指和食指的成对驱动 2）
└─ 腿 ×2（18 / 14）：髋 3、膝 1、踝 2、大脚趾 1（主动）、其它脚趾 1（被动）、足弓 1（被动）
```

驱动方式（2026-11-11 按做灵活动作的最优解定，为什么见 [驱动、感觉、大脑](research/17-驱动、感觉、大脑.md)）：
- **旋转** = 无框电机 + 行星减速器（低减速比，能反推）。要快、要灵活、要抗冲击的关节都用它。膝、踝、腕的电机放在靠身体的一端，经连杆带动关节，四肢的末端轻
- **直线推杆** = 电机 + 行星滚柱丝杠，像肌肉一样推拉。只用在要大力、速度中等、空间窄的地方：腰椎、胸椎的前后和侧弯，肩胛
- **绞盘** = 小电机 + 低减速比 + 绞盘拉肌腱，能反推。用在手指（前臂里 12 个）和大脚趾
- **微型** = 小电机，用在眼、眼睑、手掌

先不考虑电量，所以电机按峰值功率和速度选（选力矩密度高的）；母线电压可以高一些（同样的电机转得更快）；液冷让电机能更长时间出大力（第 12 节）。

所有大电机都有：安全断扭矩（STO）、断电时的短路制动、电机侧和关节侧两个编码器。

## 3. 手（每只：22 个自由度、20 个驱动）

2026-11-10 定了细节，为什么这样定见 [手](research/14-手.md)。

### 3.1 尺寸和质量

- 手长约 0.18 m（身高的 0.108）；各节手指的长度比例按人手的测量数据。
- 每只手 ≤ 0.85 kg（估计约 0.78 kg）：
  - 手掌里的 8 个微型驱动约 0.25 kg
  - 骨架、关节、轴承约 0.25 kg
  - 肌腱和滑车约 0.05 kg
  - 皮肤、触觉、电子约 0.2 kg
  - 手掌相机约 0.03 kg

### 3.2 关节、范围、驱动

| 部分 | 关节 | Nova 的范围 | 驱动 |
|---|---|---|---|
| 食指~小指（每根） | 掌指 弯伸 | 弯 90°，往后伸 30° | 前臂 1 个（食指另加 1 个反向驱动，成对） |
| | 掌指 左右摆 | ±20° | 手掌 1 个 |
| | 近指间 | 0~105° | 前臂 1 个（同时带动远指间） |
| | 远指间 | 0~80°，跟着近指间动 | 联动：交叉四连杆按人的 S 形曲线，连杆里有一段弹性，按到东西时末节能顺着形状弯 |
| 拇指 | 腕掌（解剖学的鞍状关节，两根转轴不垂直也不相交）弯伸 + 外展 | 约 50°、约 40~60° | 手掌 2 个 |
| | 掌指 弯伸 | 0~60° | 前臂 1 个 + 1 个反向驱动（成对） |
| | 掌指 侧摆 | ±10° | 手掌 1 个 |
| | 指间 | 0~80° | 前臂 1 个 |
| 手掌 | 无名指和小指的掌骨（拢成碗） | 0~20°，小指比无名指多 | 手掌 1 个 |

合计 22 个关节；驱动：**前臂 12 个**（手指 8 + 拇指 2 + 成对 2）、**手掌 8 个**。

### 3.3 驱动和肌腱

| 部分 | 怎么做 |
|---|---|
| 前臂的 12 个驱动 | **绞盘**：小电机 + 低减速比 + 绞盘，能反推（2026-11-11 改：不再要求自锁，力控更细、更快）。一般的关节：弯和伸两根肌腱绕在同一个绞盘上，一边拉、一边放。成对的关节（拇指掌指、食指掌指）：弯和伸各一个绞盘，可以一起拉紧，机械上调软硬 |
| 手掌的 8 个驱动 | 微型电机 + 减速，用短肌腱或连杆带动；密封在手掌里 |
| 穿过手腕 | 所有肌腱从手腕中间的"腕管"穿过，尽量靠近手腕的转轴；剩下的长度变化由控制补偿 |
| 手指上 | 环形滑车（像人的 A2、A4）+ 低摩擦的套管 |
| 伸的一侧 | 简化的"伸肌腱帽" |
| 肌腱 | 低蠕变的高强度纤维；每根串一段弹簧（柔顺 + 测张力）；两端都测张力（发现松弛、磨损、摩擦变大）；自动保持预紧力 |
| 指尖 | 软指腹、指甲、指纹纹路 |
| 防水 | 手里只有 8 个微型驱动和传感器，都密封在手掌里；肌腱从手腕穿出的地方也密封 |

### 3.4 力量和速度（目标按人）

| 项目 | 目标 | 说明 |
|---|---|---|
| 握力 | 350~400 N | 成年男性约 400 N |
| 指尖捏 | 约 80 N | 年轻男性约 80 N（Mathiowetz 1985 常模，第三方表格） |
| 侧捏、三指捏 | 约 115 N | 同上 |
| 手指关节速度 | ≥ 300~500°/s | 人敲手指每秒约 5~7 次 |
| 能感到的力 | 几克 | - |
| 指尖分辨两点 | 约 2 mm | - |

- **这是手最难的地方**：指尖用 40 N 按东西时，屈肌腱要拉约 300~360 N，前臂里屈肌的绞盘每个要拉几百牛。
- 现在商用的 20 自由度灵巧手，捏取负载只有 1~2 kg（零售商资料）。
- P1 里按这些目标算出每个驱动要多大的力、多快、多重，再看前臂放不放得下（第 7 节）。

### 3.5 耐用和维护

- 目标：**100 万次抓握不坏**（家里每天约 1000 次的话约 3 年，初定）。
- 每根手指做成能整根换的模块，肌腱用快速接头；指尖的软指腹可以换。
- 记下每根肌腱的张力随时间的变化，提前发现快要换的肌腱。

### 3.6 控制

- 脊髓层：
  - 关节和肌腱之间的换算：一个关节动，几根肌腱的长度都会变；手腕动也要补偿。
  - 保持预紧力，不让肌腱松掉。
  - 防滑反射。
  - 最大肌腱力和关节范围的保护。
  - 成对驱动的关节按需要调软硬。
- 动作脑：
  - 给手的目标：关节角度 + 抓力 + 软硬，直接交给脊髓层（不经过小脑层）。
  - **先在"手的协同"（少数几个组合动作）里学**，再细化到每个关节。
- 遥控：Nova 的手和人手几乎一样，VR 手部追踪的数据几乎能一对一转过来。

### 3.7 验收

- 通过 Kapandji 拇指测试。
- 能做出人的 33 种抓握（GRASP 分类）。
- 其它考题见 [Nova 考试](Nova考试.md)。

| 接触 | 触觉皮肤约 3250 格（手、全身、足底）+ 接近觉电极约 200 个 + 指尖振动 ×10 + 温度 ×12（指尖 10、手掌 2）。详见下面的"触觉皮肤" |

| 安全和自身状态 | 电机和驱动器温度、母线电压电流、电池每节电芯、STO 和制动器状态、碰撞检测、跌倒检测；冷却液的温度、流量和漏液，机身里进水（2026-11-10 加） |

### 触觉皮肤（2026-11-10 定）

| 部位 | 技术 | 间距 | 格子数（约） | 每个格子测什么 | 频率 | 特别要求 |
|---|---|---|---|---|---|---|
| 指尖 ×10 | 磁式三轴 + 压电振动 + 温度 | 约 2 mm | 每个约 75，共 750 | 压力 + 两个方向的切向力；每个指尖另有振动和温度 | 500 Hz（振动 2 kHz） | 软指腹、指纹纹路、指甲；能密封防水 |
| 指节、手掌 ×2 | 磁式三轴 | 5~7 mm | 每只手约 320，共 640 | 压力 + 切向力；手掌另有温度 | 200 Hz | 防水 |
| 全身（手和脚底以外，约 1.7 m²） | 电容式 | 约 3.5 cm | 约 1400 | 压力 + 接近（快碰到时就知道） | 100 Hz | 软外壳下面 |
| 足底 ×2 | 大量程三轴阵列（压阻式或磁式） | 约 1 cm | 每只约 230，共 460 | 压力 + 切向力 | 1 kHz | 落地时要承受约 3 倍体重 |
| 关节缝隙 | 细条形的压力条 | - | 少量 | 有没有夹到东西 | 200 Hz | 防夹 |

- **手用磁式**：要能防水、耐清洁剂（洗碗、擦桌子）。电容式怕水，所以只用在全身。
- **每个格子输出两路**，像人的两类神经：
  - "持续"：现在的压力和切向力，给动作脑、小脑层。
  - "变化"：变化率和振动，给脊髓层的反射。
  - **只在变化超过阈值时才上报。**
- **触觉事件**：接触开始和结束、开始打滑、撞击、太热，用简单规则判断，给反射和安全；**社交触觉**（被拍肩膀、握手、拥抱）用小模型判断，给动作脑和思考脑。
- **模块化**：皮肤分成一块块模块，每块就近数字化；坏了能单独换；指尖的软指腹做成可以换的；外层能擦、能洗。开机自检找出坏格子。
- **校准**：每个格子的灵敏度、零点、温度影响；没有接触时自动归零。**自己摸自己**：用手摸自己的身体，校准每个格子的位置，顺便校准关节（像婴儿认识自己的身体）。
- 原始数据每秒约 6 MB；只报变化时少得多。

| 额头深度相机 | 1 | 额头 | ToF，0.2~5 m，30 帧，红外补光 | 稳定的深度（白墙、暗处）、地形高度图、安全 |
| 额头事件相机 | 1 | 额头 | 微秒级延迟，高动态范围 | 快的东西：接球、飞来物、突然动的人和宠物 |
| 手掌相机 | 2 | 两只手掌 | 广角，对焦 2~30 cm，30 帧，红外补光 | 抓之前近距离看；柜子里暗的地方 |
| 额头热成像相机 | 1 | 额头 | 小的红外热像（分辨率和帧率 P1 里定） | 锅、灶、水烫不烫，不碰就知道；暗处的人和宠物（2026-11-11 加） |
| 看脚下的深度相机 | 1 | 胸前，朝前下方 | ToF，0.2~3 m，30 帧，广角 | 一直看着脚下：地形高度图、楼梯；不和"看哪里"抢（2026-11-11 加，换掉胸前的环视相机） |
| 环视相机 | 3 | 头的后面和两侧 | 鱼眼，约 640×480，15~30 帧 | 看身后和周围 |

- **眼球转动先在仿真里比**（第 10 节，2026-11-10 定）：比"能转"和"不能转 + 数字扫视 + 电子防抖 + 转头"。差别不大的话，真机先用固定的眼。
- **中央凹**：约 5300 像素横跨约 100°，每个像素约 1.1 角分（人约 1 角分）。注视点在图像里可以瞬间移动（"数字扫视"）。
- **眼的动作目标**：
  - 扫视峰值 ≥ 500°/s（人 500~700°/s）
  - 平稳追踪 ≥ 100°/s
  - 前庭眼反射 ≤ 5 ms
  - 眼的角度精度约 0.01°：在 1 m 处约 3 mm 的深度误差
- **保护和照明**：眼睑保护镜头、眨眼时擦掉灰尘和水汽；红外补光（人看不见，不晃眼）；不用强的可见光照人的眼睛；相机工作时有指示灯。
- **数据量**：原始约 450 MB/s（两只眼约 380 MB/s），直接进中央计算机的图像处理器和 GPU 内存，不再复制；录下来压缩后约 20~40 MB/s。

### 听觉和说话（2026-11-10 定）

| 部件 | 数量 | 位置 | 规格 | 用途 |
|---|---|---|---|---|
| 耳的麦克风 | 2 | 头的两侧，在**人耳形状的外耳**里 | 48 kHz、24 位 | 像人一样听方向，能分前后、上下 |
| 头顶麦克风阵列 | 4 | 头顶 | 同上 | 更准的方向；对准说话的人 |
| 扬声器 | 1 | 头部，嘴的位置附近 | 全频 | 说话；提示音 |

- **6 个麦克风用同一个时钟**：定位靠时间差。
- 能承受很响的声音（约 130 dB）；装的时候减振，离风扇和电机远一些；有防水透气膜（厨房会溅水）。
- **自身噪声的参考**：电机的转速和电流、风扇转速、头部 IMU 的振动，用来预测并减掉自己发出的声音。不加新的硬件。
- **扬声器**：音量按听的人有多远、周围有多吵自动调，夜里小声；除了说话，还有简单的提示音（"我要过去了""我要拿东西了"）。扬声器放出的声音是回声消除的参考。以后加脸时可以和口型配合。
- **隐私**：声音事件识别一直开着但不录音；只有被叫名字或被问话时才把说的话转成文字；听的时候有指示灯；全部在机器人上处理。

基建：
- 统一时钟：相机和 IMU 硬件同步
- 标定：仿真里故意加标定误差
- 全部记录：rosbag2 → LeRobot 数据
- 冗余：关键感觉有两个来源

## 5. 停止和安全

| 级别 | 做什么 | 什么时候 |
|---|---|---|
| 2 类 | 受控停止，保持通电，站着保持平衡 | 平时的"停" |
| 1 类 | 受控停止，降低重心（蹲下或跪下）后再断电并锁住 | 要断电的急停（首选） |
| 0 类 | 立刻安全断扭矩 + 短路制动，机器人慢慢坐下 | 硬件急停按钮、控制失灵 |

其它措施：
- 低等效惯量
- 控制里加阻尼，弹簧旁并联阻尼器
- 保持制动器只装在少数关节上：先慢慢坐下，停稳再锁住。哪些关节装，用仿真定
- 制动电阻
- 保护性摔倒（训练出来的反射）
- 看门狗链：大脑 → 实时控制器 → 驱动器
- 急停入口：机身按钮、无线急停、全身触觉检测碰撞
- **安全的力**（2026-11-11 加）：碰到人的力和压强，不超过 ISO/TS 15066 给的人身体各部位的上限。控制里照它限制，考试里照它判安全事件

## 6. 身体里面

| 位置 | 放什么 |
|---|---|
| 头 | 眼、眼睑、耳（外耳 + 麦克风）、头顶麦克风阵列、扬声器、头部 IMU、相机 |
| 胸 | 主电脑（带 GPU，液冷）、网络交换机、肩前后的电机、肩胛推杆、胸椎驱动、颈底电机 |
| 背 | 液冷的水泵、散热器和低转速的大风扇（第 12 节） |
| 腹和骨盆 | 电池（约 2~2.5 kWh）、电源分配、制动电阻、骨盆 IMU ×2、安全控制板、腰和髋的电机 |
| 四肢 | 电机驱动板就近放 |
| 外层 | 软的包覆，里面是触觉皮肤和接近觉皮肤；关节缝隙防夹；外面穿能换、能洗的外衣（第 9 节） |

**身体做成模块**（2026-11-11 加）：在手腕、颈、腰、肩、髋定好标准接口（机械、电、通信、冷却液）。
- 真机可以先装简单一些的模块（比如简单一些的手），以后直接换成完整的，不用重新设计身体。
- 坏了整块换，几分钟修好。这也是"能依靠"的一部分。
- 卖出去以后还能升级。

## 7. 还没定的

都要靠仿真实验或调研来定：

1. **成对电机**：除了拇指和食指，肘、膝等要不要加。用仿真实验定。
2. **保持制动器**装在哪些关节。用仿真实验定。
3. **膝的电机怎么带动膝**：一级连杆、两级连杆还是同步带。要 ≥ 150°、腿要轻、落地的冲击扛得住。P1 里在仿真里比。
4. **驱动器能不能买到**：P1 测出规格后调研。
5. **质量**：按 ≤ 65 kg（力争 60 kg）算。手臂变重 → 腿的要求变高；反过来，身体轻了腿也能轻。这个循环在 P1 里算清楚。
6. **哪些自由度和传感器进真机**：按第 10 节的仿真对比来定。
7. **前臂放不放得下**：手的 12 个绞盘驱动（屈肌的每个要拉几百牛）+ 腕的 2 个旋转电机。P1 里按第 3.4 节的力量目标算。
8. **液冷**：哪些关节要液冷、管路怎么走、水泵和散热器放在哪。P1 里按热预算定（第 12 节）。
9. **热成像相机的分辨率和帧率**：P1 里定。

## 9. 家用的要求（2026-11-09 加）

第一件要做到可靠的事是家务，所以身体要适合家里：

| 项目 | 要求 |
|---|---|
| 尺寸 | 能过最窄的门：卫生间门、阳台门的门洞只有 0.70 m，门框和门扇还要占掉一些；能在 0.90 m 宽的过道和厨房里转身；肩宽 0.44 m |
| 高度 | 1.70 m，够得到厨房的吊柜和冰箱的上层 |
| 安静 | 尽量安静，目标 40 dB 以下（以后实测；1X NEO 说它约 22 dB） |
| 防水 | 手和前臂能碰水和清洁剂（洗碗、擦桌子）；防护等级以后定 |
| 安全 | 软外壳、防夹；靠近小孩和宠物时自动变慢、变软；接近觉皮肤 |
| 地面 | 木地板、瓷砖、地毯、门槛（1~2 cm）都能走；脚底防滑 |
| 楼梯 | 能上下家里的套内楼梯：踏步高到 0.20 m、宽只有 0.22 m（比脚短，脚长约 0.26 m），有扇形的转角踏步；上下楼一直扶着扶手（规则见[系统结构](系统结构.md)第 2 节） |
| 外观 | 友好，一看就是机器人，避开"恐怖谷" |
| 外衣 | 身上（手、脸、脚底以外）穿一层能换、能洗的布外衣：更软、干净，保护皮肤，盖住关节的缝。接近觉隔着布也要能用（要实测）（2026-11-11 加） |
| 充电 | 自己回到充电座充电 |

## 10. 复杂度要有证据（2026-11-09 加）

每多一个关节、一个传感器，就多一个会坏的地方。所以：

1. **仿真里先全做**：98 个自由度和全部传感器。
2. **逐个对比**：在 Nova 考试上比较"有它"和"没有它"：
   - 身体：胸椎、肩胛上旋、大脚趾、足弓、眼球转动、拇指和食指的成对驱动……
   - **眼球转动排第一个**（2026-11-10 定）
   - 感觉：每一种传感器
3. **有证据才进真机**：
   - 让考试分数明显变好的，进真机。
   - 某一类考题（比如能力证明里的柔韧动作）非它不可的，进真机。
   - 都不是的，真机先不做，模型里留位置。
4. 对比的结果记进决定记录。

## 11. 能耗和续航（2026-11-09 加；2026-11-10 定为先不考虑）

**现在先不考虑电量**（2026-11-10 用户定）：选设计时不为省电牺牲动作能力。下面的内容留着，以后再用。

据行业估计，现在的人形机器人一次充电只能工作约 2 小时。Nova 关节多、前臂重，更要省电：

| 项目 | 要求 |
|---|---|
| 目标 | 一次充电做完一轮家务（连续 2 小时），还有余量自己回去充电；以后再提高 |
| 省电的身体 | 低减速比（转子惯量小）；踝和足弓的弹簧存放能量（手指 2026-11-11 改成能反推的绞盘，不再自锁） |
| 省电的行为 | 不动的时候坐下或靠着休息；思考脑安排家务的顺序时考虑电量；电量低了自己去充电 |
| 考试 | 每项家务的耗电都记在 Nova 考试里，和成功率一起看 |

## 12. 散热（2026-11-10 加）

关节的电机是最大的热源。据业内分析，只靠空气冷却的关节，能一直出的力只有峰值的 25~30%。Nova 要按人的力量做，又要安静（≤ 40 dB），所以：

| 项目 | 做法 |
|---|---|
| 热预算 | 算出每个关节、主电脑、电池在一轮家务里发多少热（P1） |
| 液冷 | 主电脑 + 负担重的关节（髋、膝、踝、腰、前臂里手的驱动）：小水泵和管路把热带到背上的散热器，像人的血液把热带到皮肤 |
| 骨架和外壳 | 当散热片用 |
| 风扇 | 低转速的大风扇，按声音来设计 |
| 漏液 | 管路用能自封的快速接头；检测漏液，漏了就停下、告诉人 |
| 控制 | 每个驱动器有热模型；热了先降额，再换姿势、歇一会（脊髓层降额，思考脑安排） |
| 仿真 | 模拟发热和液冷，让策略学会管理温度 |
| 考试 | 记最高温度和降额次数；一轮家务不许因为过热停下来 |

参考：小米 CyberOne 的手里做了液冷通道（3D 打印的金属）；港科大（广州）在做液冷的关节。见 [设计一览和升级](research/16-设计一览和升级.md) 升级 5。
