# 质量闭环的结果

**这份报告是程序算出来的，不要手改。** 要改就改 `body/nova_body` 里的假设，再运行：

```bash
docker compose run --rm body python -m nova_body.mass_report
```

质量闭环是什么：腿和躯干要出的力矩跟着体重变。身体重了，腿的驱动器就要更大、更重，身体又更重。
把这个循环算到不再变，得到的就是体重。

## 1. 结论

| 身体 | 自由度 | 驱动的假设 | 体重 | 多带 1 kg，总重加多少 |
|---|---|---|---|---|
| 核心版 | 75 | 今天最好的驱动 | **75 kg** | 1.77 kg |
| 核心版 | 75 | 保守的驱动 | **86 kg** | 1.91 kg |
| 完整版 | 98 | 今天最好的驱动 | **93 kg** | 1.80 kg |
| 完整版 | 98 | 保守的驱动 | **109 kg** | 1.96 kg |

- **今天最好的驱动**：按 8 个真实产品的数拟合，包括每公斤力矩最大的那个（Unitree M107，厂商的数）。
- **保守的驱动**：去掉最好的那个再拟合。
- 两个都是按**峰值**力矩算的。真实的体重大概在两者之间。

## 2. 每样东西加多少重量

基准：核心版、今天最好的驱动，**74.7 kg**。

| 改动 | 体重 | 和基准差 |
|---|---|---|
| 不要液冷 | 69.4 kg | -5.4 kg |
| 不要保底的东西（双绕组、超级电容、制动器、安全板） | 66.5 kg | -8.2 kg |
| 电池从 1 kWh 加到 2.3 kWh | 86.2 kg | +11.4 kg |
| 手换成全肌腱的（A） | 79.4 kg | +4.7 kg |
| 骨架占总重的 25%（基准是 20%） | 82.0 kg | +7.3 kg |
| 驱动器按人的峰值（初估）定，不按动作算的 | 80.2 kg | +5.5 kg |
| 力量减半（轻的家用身体） | 56.7 kg | -18.0 kg |
| 完整版（98 个自由度，全肌腱的手） | 92.9 kg | +18.2 kg |

## 5. 用的假设

| 项目 | 取值 |
|---|---|
| 身高 | 1.7 m |
| 驱动器的力量 | 做家务的动作要的（1.5 步从动作算的）；动作没算出目标的关节（颈、肩转、前臂转、腕）用人的峰值 |
| 规格里的力矩对应的体重和身高 | 70 kg、1.7 m；腿和躯干的力矩按"体重 x 身高"放大 |
| 驱动器怎么选 | 峰值力矩和一直要出的力矩（发热）里要求大的那个；怎么冷却按机体规格第 12 节（见驱动器的报告） |
| 骨架 | 占总重的 20% |
| 线 | 占总重的 4% |
| 电池 | 1 kWh，每公斤 200 Wh（高倍率的电池包） |
| 电脑 | 1.5 kg |
| 液冷（泵、散热器、冷却液、管） | 3 kg |
| 皮肤、软外壳、外衣 | 3.5 kg（身高 1.7 m 时；按身高²变） |
| 传感器（相机、麦克风等） | 1 kg |
| 脚里的东西（踝的六轴力传感器、脚底的压力皮肤、脚板） | 每只脚 0.6 kg |
| 超级电容 | 1 kg |
| 制动器 | 膝和髋共 4 个，每个 0.25 kg |
| 安全控制板 | 0.5 kg |
| 双绕组的电机 | 比单绕组重 10% |
| 手臂 | 水平伸直、手里端 5 kg，再乘 2 倍；和规格值取大的 |
| 推杆（腰椎、胸椎） | 按出同样力矩的旋转驱动器的重量算 |

## 7. 这个模型还不知道的

- **驱动器**：按峰值和发热选（[驱动器的报告](驱动器.md)）。电机常数、每公斤能散多少热来自公开的产品数和一篇论文，没有实测；转速只改绕组和电流，不改重量。
- **推杆**：没有核实过的重量数据，先按旋转驱动器算。
- **手**：三种手的重量都是估的。
- **骨架**：按总重的固定比例算，没有按受力算。
- **肩胛**：推杆要多大的力还没测，按每个 0.3 kg 估。
