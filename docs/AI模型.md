## 1. 脊髓层：不用 AI

| 功能 | 方法 |
|---|---|
| 关节控制 | 阻抗控制：按目标、刚度、阻尼、前馈力矩算出力矩 |
| 关节空间 ↔ 驱动器空间 | 并联推杆和连杆的运动学、肌腱和绞盘的换算（解析公式）；手：肌腱的耦合（一个关节动，几根肌腱都变）、手腕的补偿、保持预紧力 |
| 状态估计（身体的位置、速度、姿态） | 不变扩展卡尔曼滤波（InEKF）：融合 IMU（骨盆两个互相对照）、腿的运动学、接触；再用视觉惯性里程计纠正朝向和位置的漂移 |
| 接触判断 | 足底压力 + 关节力矩，概率判断 |
| 反射 | 阈值规则；防滑从指尖切向力和振动的变化判断；脚底防滑从足底切向力的突然变化判断；前庭眼反射从头部 IMU 的角速度直接算 |

**为什么不用 AI**：
- 要确定、要快、要能验证。安全出问题时，要能说清楚为什么。
- 神经网络会在没见过的情况下给出奇怪的输出。最下面一层不能这样。

AI 只用在**训练那一端**：
- 用真机驱动器的数据训练一个"驱动器网络"，放进仿真里，让仿真的驱动器更像真的（ANYmal 用过的做法）。
- 运行时不用它。

## 2. 小脑层：一个通用的全身控制策略

**要的能力**：
- 跟上动作脑给的任何全身动作，同时不倒。
- 被推后能恢复，走楼梯和不平的地，手拿重东西时自动补偿。
- 有保护性摔倒和自己站起来。
- 能用手扶着保持平衡：扶扶手、台面、墙、椅背（2026-11-10 加）。上下楼一直扶着扶手（规则见系统结构第 2 节）。
- 湿的地面：按估出来的摩擦调整步子；看着湿的地方先轻踩试探、走慢、扶着东西（2026-11-11 加）。

**做法：动作跟踪当作"基础任务"**

1. **SONIC**（NVIDIA，2025）：
   - 证明了"跟踪各种人的动作"这一个任务，规模越大越好：网络从 120 万放大到 4200 万参数，数据超过 1 亿帧（700 小时），用了 9000 GPU 小时。
   - 学到的能力能用在没见过的动作上。
   - 有 C++ 实时推理、PICO VR 遥控。
   - 默认看未来约 200 ms 的参考动作；低延迟版本看 80 ms，给遥控和 VLA 用。
2. **HOVER**（NVIDIA 等，ICRA 2025）：
   - 一个策略支持多种命令方式，上半身和下半身可以分别选，有 15 种以上的组合：
     - 走路速度
     - 关键点（手、头的位置）
     - 关节角度
     - 全身参考动作
   - 先训练能看到仿真里全部信息的"老师"，再教只看传感器的"学生"（DAgger），学生输入最近 25 步的本体感觉。
3. **BeyondMimic**：
   - 跟踪很激烈的动作（侧手翻、跳转），并且上了真机。
   - mjlab 里已经带了它的训练任务。

**Nova 的做法**：照这些方法**自己训练**。
- SONIC 的权重是为 Unitree G1 训练的，Nova 的身体不同：98 个自由度，有脊柱 6、肩胛、脚趾。
- 手指不归小脑层管，它们不影响平衡，由动作脑直接控制。

| 项目 | 做法 |
|---|---|
| 输入 | 本体感觉（关节、IMU、接触）+ 历史；地形高度图（走楼梯时）；命令（HOVER 的多种方式） |
| 输出 | 全部身体关节（不含手指）的目标、刚度、阻尼 |
| 大小 | 先 500 万~2000 万参数，要在实时分区的 CPU 上 2 ms 内算完（实测） |
| 频率 | 50~200 Hz；P1 里和更高的频率（到 1 kHz）比（Figure Helix 02 的全身控制是 1 kHz，自报） |
| 训练 | mjlab（MuJoCo Warp），强化学习（PPO）；随机改质量、摩擦、电机力量、延迟、噪声；先老师后学生 |
| 动作数据 | 自己录的"Nova 动作库"（动作捕捉服）或有商用授权的动作库；转到 Nova 的关节（见第 7 节） |
| 另外的小策略 | 保护性摔倒、自己站起来、"慢慢坐下"（停止时用） |

## 3. 动作脑：四部分

### ① 视觉-动作模型（VLA）：手臂、手、头眼、走路命令

**要的能力**：
- 看相机（眼、手掌）和触觉，听思考脑给的子任务，每秒出几十次动作。
- 两只 22 个自由度的手要用得好。

| 模型 | 大小 | 特点 | 许可证 |
|---|---|---|---|
| **GR00T N1.7**（NVIDIA，2026） | 30 亿 | 为人形机器人做的；里面也分"慢的视觉语言部分"和"快的动作部分"（主干是 Cosmos Reason 2-2B / Qwen3-VL 一类）；2026 年 7 月起可以在 LeRobot 里用 | NVIDIA 开放模型许可，可商用（以官方许可页为准） |
| π0.5（Physical Intelligence） | 约 30 亿 | 在新环境里的泛化强；论文里先预测"下一个子任务"再出动作；官方权重里有没有子任务这部分没查到 | Apache 2.0（openpi） |
| SmolVLA（Hugging Face） | 4.5 亿 | 小，消费级显卡甚至 CPU 能跑 | Apache 2.0 |
| MolmoAct2、X-VLA | - | 2026 年新出的开放模型 | 各自不同 |
| GR00T N2（NVIDIA，预告） | DreamZero 是 140 亿 | 基于"世界-动作模型" DreamZero：同一个模型同时预测未来的画面和动作，用视频扩散模型做底；新任务、新环境的成功率约是最好的 VLA 的 2 倍（自报）；据报道 2026 年第 4 季度出 | **动作脑的升级路线**（2026-11-11 定）：出来后先在仿真里和 N1.7 比，比得过就换 |

**建议**：
- **GR00T N1.7 当主力**：为人形机器人做的，可商用，有 LeRobot 支持。
- **π0.5 当对照**。
- **这台电脑上先用 SmolVLA** 把整条流程打通，等有大显卡再换。

**Nova 要补的两件事**：
1. **22 个自由度的手**：现有模型都没有用这种手训练过，一定要用 Nova 自己的数据再训练。
   - 先在"手的协同"（少数几个组合动作）里学大致的手形，再细化到每个关节：学得快，要的数据少。人手的前两个组合动作就能解释 80% 以上的手形（Santello 1998）。
   - Nova 的手和人手几乎一样，VR 手部追踪的数据几乎能一对一转过来。
2. **触觉**：大多数 VLA 不接触觉。
   - 2026 年的 TaF-VLA 把触觉和力对齐后加进 VLA，在 7 个需要控制力的任务上平均成功率高了约 22%（作者自报）。
   - Nova 第一版：触觉摘要作为输入，快的那部分由脊髓层的防滑反射处理；之后照 TaF-VLA 的做法加深。
   - 摘要用接近物理的简单特征：接触点、力的方向和大小、有没有在滑。不直接给每个格子的原始读数，这样更容易从仿真转到真机。

### ② 全身动作生成：跳舞、坐下、爬起、体操

**要的能力**：从一句话或一个技能名，生成全身的参考动作，连续地交给小脑层去跟踪。

| 做法 | 说明 |
|---|---|
| TextOp（2026） | 自回归的动作扩散模型，一边听文字一边生成短的动作，交给跟踪策略；中途可以改命令 |
| ECHO（2026） | 云上的扩散模型约 1 秒生成动作，机器人上的跟踪策略执行 |
| RoboForge（2026） | 生成后再做物理优化，保证真机能做出来 |

**建议**：照 TextOp 的做法，生成模型放在 GPU 快实例上，输出未来 1~2 秒的参考动作给小脑层。
现在这些方法都还不太看环境（比如绕开桌子）。这个要以后让它接上动作脑的视觉。

### ③ 专门技能：通用模型做不好的

| 技能 | 做法 |
|---|---|
| 手里转东西、按重量调抓力 | 仿真里带触觉的强化学习。2026 年已有不在真机上微调、直接从仿真转到五指手上的例子（快速的虚拟触觉 + 关节力矩） |
| 触觉仿真不够像时 | 先训练看得到仿真全部信息的触觉策略，再教给只看真实触觉的策略（PTLD 的做法） |
| 固定的精细动作 | 模仿学习（ACT、Diffusion Policy） |
| 看哪里（注意力） | 每秒 2~3 次扫视，按 安全 > 任务 > 社交 > 探索 打分（突然动的东西 → 要拿的东西和手 → 说话人的脸、被指着的东西 → 没看过的地方）；抓东西时开手掌相机；第一版按规则，以后让 VLA 自己决定 |

### ④ 价值模型：把握有多大（2026-11-10 加）

**要的能力**：看现在的情况，估计"这个子任务能做成的可能性"。

| 用处 | 怎么用 |
|---|---|
| 求助 | 可能性低，或者突然往下掉 → 停下来，求助（[系统结构](系统结构.md) 5.5 节） |
| 从经验里学 | 每次做都记下结果；人接手改正的过程也是数据。用价值模型挑出"比平常做得好的动作"来多学 |
| 选做法 | 几种做法里挑可能性最高的 |

- 照 Physical Intelligence 的 π*0.6（2025 年 11 月）的 RECAP 做法：用价值模型从自己的经验和人的改正里学。一些最难的任务，每小时做完的量翻了一倍多，失败率降了一半多（自报）。
- 训练：仿真里裁判自动判成败，每做一次就多一个答案；以后再加上真机的结果和人的改正。
- 和视觉-动作模型放在一起（GPU 快实例），读同样的输入。
- 考试里记它估得准不准：说"八成能做成"的，实际是不是八成做成了。

### ⑤ 短时的画面记忆（2026-11-11 加）

- 照 Physical Intelligence 的 MEM（2026 年 3 月）：最近几十秒的画面压缩成短的"视频记忆"，放进动作脑的输入。MEM 做到了长达 15 分钟的任务，抓不起来时会换抓法（自报）。
- 用处：不重复同一个错误；刚看过的东西被挡住了，也知道在哪。
- 只管这一次做事，不是一个家的模型。
- 训练：和动作脑一起在仿真里练（老师教学生）。

### 动作脑的升级路线：世界-动作模型（2026-11-11 定）

- 世界-动作模型是同一个模型同时预测"接下来会看到什么"和"该怎么动"（GR00T N2 / DreamZero）。
- GR00T N2 出来后，先在仿真里和 N1.7 比，比得过就换。
- 接口不变：输入（相机、触觉、身体状态、子任务）和输出（身体命令、手指的目标）都不变，换模型不用改别的层。
- 换了以后，目标画面（第 4 节）和价值模型可以由它来做。
- 要注意：DreamZero 有 140 亿参数，比 N1.7（30 亿）大很多；机器人上的算力要实测（第 8 节）。

## 4. 思考脑

**要的能力**：
- 看几张图就懂场景，懂物理常识（东西会掉、杯子里有水会洒）。
- 把一句话拆成子任务，能用中文对话，能记事。

| 模型 | 大小 | 特点 | 许可证 |
|---|---|---|---|
| **Cosmos Reason 2**（NVIDIA，2026） | 2B / 8B / 32B | 专门用物理常识和具身推理训练；模型说明里写的用途就有"机器人规划"；上下文 256K | NVIDIA 开放模型许可，可商用 |
| Qwen3-VL | 2B~235B | 通用能力强，中文好 | Apache 2.0（多数尺寸） |
| RynnBrain（阿里达摩院，2026） | - | 开放的具身推理模型（时间、空间） | 开放 |
| Vesta（NVIDIA，2026） | 基于 Qwen3-VL-8B | 带记忆的推理，需要记忆的任务成功率高了 35% 以上（作者自报）；有没有开放权重没查到 | - |

**建议**：
- **Cosmos Reason 2-8B 当主力**。它和 GR00T N1.7 的主干是同一族，两层"说同一种话"。
- 中文对话能力要实测，不够就让 Qwen3-VL 负责对话。

**语音**：
- 前端（先做好，后面才听得清）：
  - 回声消除：减掉自己正在说的话，这样才能被打断
  - 自身噪声消除：按电机状态预测并减掉自己的声音
  - 定位、对准说话的人（波束形成）
  - 参考开源的机器人听觉工具 HARK、ODAS
- 第一版用分开的小模型：
  - 有没有人说话：Silero VAD
  - 语音识别：SenseVoice，中文强、快；同时给出语言、情绪和部分声音事件
  - 说话人识别：小模型，知道是谁在说
  - 专门的声音事件识别：SenseVoice 的声音事件不如专门的模型，所以另加
  - 语音合成：CosyVoice，中文
- 和人说话：能被打断；知道是不是在跟它说话（叫了名字、看着 Nova、声音朝着 Nova）；轮流说话
- 以后可以换成"能听能说"的一体模型：Qwen3-Omni 是 Apache 2.0，首包延迟约 0.2 秒，但要很大的显存。

**不做一个家的模型**（2026-11-10 用户定）：Nova 要像人一样，到了哪里都能一样地想、一样地反应。到了没去过的家，不用先建模型就能开始做事。
- 东西该放在哪：按常识判断（书放书架、碗放橱柜），不靠事先记住的家。
- 当场看到的要记一会儿：这次做事时看过什么、东西在哪（像人的工作记忆）。这是"想"的一部分，不是事先存好的家的模型（2026-11-11 用户确认）。
- **做到哪了**（2026-11-11 加）：这次的任务做完了什么、还剩什么、试过什么，用文字记下。这是长时的文字记忆，和动作脑的短时画面记忆是两种尺度（照 MEM）。长的家务不乱；被打断后能接着做。

**沿用上一个项目的做法**：
- 计划先用格式（规约）和意思检查，不对就带着原因再问。
- 流式接收，收到一步就开始做。
- 人的命令优先。
- 用代号丢掉过时的答案。

**云**：联网时可以把难的推理交给云上更大的模型；断网时用机器人上的。

**先想一想**（2026-11-11 加）：
- **目标画面**（2026-11-11 定）：每个子任务开始时，用轻量的世界模型 **Cosmos Predict 2.5（2B）** 画出"这一步做完应该是什么样"，和子任务一起交给动作脑（照 π0.7）。动作脑朝着它做；价值模型拿现在的画面和它比，判断做成了没有。训练很省事：仿真里每一步做完的画面本来就有，直接拿来当答案。
- **指出来**（2026-11-11 定）：Cosmos Reason 2 自己就能在画面上点出、框出东西，还能给出手的轨迹，不用另加模型。
- **边想边做**（2026-11-11 定）：子任务开始时、没把握时，思考脑先用几句话想好怎么做（"先把盒子挪开，再拿后面的杯子"），写进子任务；Nova 也可以把它说出来。以后动作模型自己能边想边做时（像 Gemini Robotics 1.5），再挪到动作脑里。
- 叠高、倒水这类有风险的事的预演：先留接口，等世界-动作模型成熟再接（[系统结构](系统结构.md) 第 2 节）。

## 5. 小感知模块

| 模块 | 方法 | 用不用 AI |
|---|---|---|
| 状态估计 | InEKF | 不用 |
| 地形高度图 | 胸前看脚下的深度相机（一直）+ 额头的深度相机 → GPU 高程地图（ETH 的 elevation_mapping_cupy 一类） | 不用（以后可以换学出来的） |
| 视觉惯性里程计 | 两只眼的相机 + IMU，经典算法 | 不用（以后可以换学出来的） |
| 安全用的"附近有没有东西" | 深度分区 + 接近觉，几何判断 | 不用（安全不靠会出错的模型） |
| 喊"停" | 关键词识别（小模型），在**安全分区**里单独运行 | 用，很小 |
| 回声消除、自身噪声消除、定位、对准说话的人 | 传统的信号处理，电机状态做参考 | 不用（以后可以换学出来的） |
| 飞来物检测 | 事件相机，看东西是不是在变大 | 不用 |
| 热的东西 | 热成像相机：温度阈值 + 位置 | 不用 |
| 透明东西的深度 | 两只眼的双目 + 专门对透明东西训练的深度模型（ClearDepth 一类）；超声波补充 | 用 |
| 地面有多滑 | 落脚时足底的切向力和微小的滑动 → 估摩擦 | 不用 |
| 摸到的是什么材料 | 指尖热感的热流 + 触觉 → 金属、玻璃、木头、塑料，干的还是湿的 | 用，很小 |
| 镜头脏了 | 画面自检：模糊、对比度、斑点 | 不用 |
| 触觉事件（接触开始和结束、打滑、撞击、太热） | 规则 | 不用 |
| 社交触觉（被拍肩膀、握手、拥抱） | 全身皮肤事件的小分类模型 | 用，很小 |
| 声音事件、声音方向 | 声音事件分类（BEATs、PANNs 一类）；方向用传统的阵列算法 | 事件用，方向不用 |
| 人和物体（给思考脑当背景信息） | 开放词汇检测、跟踪、人体姿态（Grounding DINO、RTMPose 一类） | 用 |

## 6. 层与层之间交什么

| 从 → 到 | 内容 | 频率 |
|---|---|---|
| 思考脑 → 动作脑 | 子任务：一句话 + 结构化参数（哪个物体、放到哪、成功的条件）+ **指出来**（画面上的点、框）+ **目标画面** + **怎么做**（几句话，开始时和没把握时）+ 优先级。用 ROS 2 action，可以取消。目标画面晚一点到也不挡动作（异步） | 需要时（约 0.1~1 Hz） |
| 动作脑 → 小脑层 | HOVER 式命令：走路速度、方向、身体高度；上半身目标（手臂、颈、头、眼）；全身参考动作（带未来 80~200 ms） | 30~200 Hz |
| 动作脑 → 脊髓层（直接） | **手指**的目标和抓力。手指不影响平衡，所以不经过小脑层 | 30~200 Hz |
| 小脑层 → 脊髓层 | 每个关节：目标、速度、前馈力矩、刚度、阻尼 | 50~200 Hz |

所有输入输出的格式都写在"观测和动作的规约"里，训练和部署用同一个文件（系统结构第 6.2 节）。

## 7. 数据从哪来（按商用的要求）

2026-11-10 用户定：**数据主要来自仿真里的训练**。"人穿的 Nova"采集套装（[设计一览和升级](research/16-设计一览和升级.md) 升级 1）现在没有条件做，先不做。

2026-11-09 定了**以后要商用**。所以进入训练的数据，都要是自己录的，或者有商用授权的。

只许非商业研究的数据**不进训练**：AMASS、LAFAN1、SMPL-X 人体模型，以及 EgoDex（据第三方说是 CC BY-NC-ND）。
为商用目的做的研发也可能算商业用途，所以这些数据尽量不用；要用时先找律师确认，或者买商用授权。

| 数据 | 给谁 | 来源 |
|---|---|---|
| **仿真里的训练（主要）** | 全部 | 强化学习（小脑层、专门技能）；仿真里自动生成的家、物品、任务，裁判自动判成败（动作脑、价值模型）。没有许可证问题 |
| 人的全身动作 | 小脑层、动作生成 | **自己录的"Nova 动作库"**：动作捕捉服（惯性式或光学式），演员签授权；也可以买有商用授权的动作库 |
| 人手的动作 | 动作脑（手） | 自己录：VR 手部追踪 + 数据手套；也可以买有商用授权的第一人称手部数据 |
| 遥控示范 | 动作脑 | 人戴 VR 头显 + 全身追踪 → 转到 Nova → 在仿真里、以后在真机上录。补仿真里自动学不会的 |
| 合成数据 | 动作脑 | 世界模型生成的视频（以后再考虑；要看生成模型的许可证） |

- 动作转换工具 GMR 是 MIT 许可，可以用。但它读 AMASS 时用的 SMPL-X 只许研究，所以自己录的动作要用我们自己的骨架格式。
- **仿真、考场和裁判是数据的入口，要最先做**（考场 v0 和 P1 一起）。
- **老师教学生**（2026-11-11 定）：老师在仿真里能看到全部信息（每样东西的位置、重量、摩擦），用强化学习练；动作脑是学生，只看相机和触觉，跟着老师学，做错时老师纠正。小脑层已经这样做（HOVER）。
- **一开始就用很多个家**：家、物品、任务由程序生成；裁判自动判成败，这既是老师的奖励，也是价值模型的答案。
- **仿真和真的不一样**（画面、接触、软的东西）：随机化的范围要大；以后用手机扫描的真实的家（考场 v3）；真机来了，用少量真实的数据校正。
- **VR 遥控是补充**：VR 头显 + 手部和身体追踪 → 转到仿真里的 Nova。
  - 遥控软件不绑定某一种设备。
  - 先用能做全身追踪的（如 PICO 加追踪器，SONIC 现成支持）；手的精度不够时，再加 Apple Vision Pro 或数据手套。

## 8. 算力

### 训练在哪做

| 训练 | 规模 | 这台电脑（RTX 4060 Ti 8 GB） |
|---|---|---|
| 小脑层：站、走、少量动作 | 中 | 能 |
| 小脑层：SONIC 那种规模的动作跟踪 | 几千 GPU 小时 | 不能，要云上的大显卡 |
| 动作脑：SmolVLA 微调 | 小 | 能 |
| 动作脑：GR00T N1.7、π0.5 的再训练 | 大 | 不能；推理也要 16 GB 以上（第三方资料） |
| 专门技能：带触觉的强化学习 | 中 | 能，但慢 |
| 思考脑 | 用现成的 | 2B~4B 量化后能跑 |

### 机器人上（Thor 一类，128 GB 内存）的显存预算

| 部分 | 估计 |
|---|---|
| 动作脑：GR00T N1.7（30 亿，bf16） | 约 6~8 GB |
| 动作脑：动作生成、专门技能、小感知 | 约 3~5 GB |
| 思考脑：Cosmos Reason 2-8B（bf16） | 约 16 GB（int4 约 5 GB） |
| 语音 | 约 2 GB |
| 目标画面：Cosmos Predict 2.5（2B） | 约 5~20 GB（含文字编码器，实测） |
| 合计 | 约 35~60 GB：放得下（Thor 一类有 128 GB）。以后换成 140 亿参数的世界-动作模型，动作脑要再多约 30 GB（bf16），也放得下，但算得够不够快要实测 |

小脑层在 CPU 上跑，只要几十 MB。

## 9. 怎么评分（每层的考核）

沿用上一个项目"试验和评分"的思路，每层都有自己的分数，换模型前后比一比：

| 层 | 评什么 |
|---|---|
| 小脑层 | 动作跟踪误差、摔倒率、能承受的最大推力、走路耗电 |
| 动作脑 | 任务成功率、用时、33 种抓握做出来几种、力的"轻柔度"（Tabero 一类的评分） |
| 思考脑 | 计划通过检查的比例、任务完成率、第一个子任务出来要多久、中文对话 |

## 12. 家务、求助、省电（2026-11-09 加）

第一件要做到可靠的事是家务（见 [Nova 考试](Nova考试.md)）。对模型的要求：

| 要求 | 哪一层 | 做法 |
|---|---|---|
| **知道自己没把握** | 动作脑、思考脑 | 价值模型估计能做成的可能性（第 3 节④）；多次生成动作，看差别大不大；判断现在的情况和训练时差多少。没把握就求助（[系统结构](系统结构.md) 5.5 节） |
| 软的东西（衣服、毛巾、床单） | 动作脑 | 仿真里用 MuJoCo 的布料；叠衣服的示范数据 |
| 有关节的东西（门、抽屉、电器） | 动作脑 | 仿真里建出来；开关的技能 |
| 很多种日用品 | 动作脑、思考脑 | 开放词汇的识别（没见过的东西也能叫出名字）；示范要覆盖很多种物品 |
| 长的任务（一轮家务有几十个子任务） | 思考脑 | 计划、记住做到哪了、被打断后能接着做 |
| 东西该放在哪 | 思考脑 | 按常识判断（书放书架、碗放橱柜），不靠事先记住的家；当场看到的东西记一会儿 |
| 中文对话 | 思考脑 | 听指令、被打断、问人（"这个杯子放哪里？"） |
| 电量 | 思考脑 | 电量低了先去充电。省电的安排先不考虑（2026-11-10） |
| 学新家务 | 动作脑 | 看人示范几次（VR 遥控在仿真的家里录）就学会；远程协助录下的过程也拿来学 |
