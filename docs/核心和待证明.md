# 核心和待证明（当前版本 v1.0）

2026-11-12 定。规格里的东西越加越多，每样都有道理，但看不出哪些是必须的（见 [深度检查](research/20-深度检查.md) 第 6 节）。所以每一项都标上记号。
**这张清单只在这一处维护**，各份规格都指到这里。

## 1. 四种记号

| 记号 | 意思 | 什么时候做 |
|---|---|---|
| **核心** | 第一次考试就要用的 | P1 就做 |
| **待证明** | 可能有用，还没有证据 | 只在对比它的时候打开。在 Nova 考试上明显变好，或者某一类考题非它不可，才升为核心；否则真机先不做，模型里留位置 |
| **保底** | 坏了一个零件时救命的东西 | 不拿考试分数来比，用"考故障"的题验证。真机一定做；仿真里到考故障时再建 |
| **以后** | 第一次考试用不上 | 到后面的考试，或者做真机时再做 |

**第一次考试** = 第一批家务（6 项）+ 能力证明里的"基本"（站、被推、摔倒后起来、走、上下楼梯）+ 这几道安全的题（有人走近、被人碰、地上有障碍、东西掉下来、喊"停"）+ 判断上的安全。考题见 [Nova 考试](Nova考试.md)。

规则：
1. **P1 只做核心。**
2. 每打开一个"待证明"，都和核心版比，也和基线比；记下它加了多少重量、多少算力。
3. 结果记进 [决定记录](决定记录.md)，再改这张表。

## 2. 基线：先用一个现成的身体

| 项目 | 内容 |
|---|---|
| 用什么 | **Unitree G1**：MuJoCo Menagerie 里有它的模型（BSD-3，没有完整的手，手的模型另找）；SONIC 的权重就是给它练的；GR00T 有它的流程 |
| 以后加上 | **NVIDIA 的参考人形机器人**（Unitree H2 Plus + Sharpa Wave 的手，75 个自由度，2026 年底供货）。它的手也是 22 个自由度，和 Nova 最像。模型公开后加上 |
| 做什么 | 四层、考场、裁判、接口，都先在基线上跑通；考第一次考试，分数存档 |
| 然后 | Nova 的核心版先要追上基线。之后每打开一个"待证明"，都和核心版、和基线比。这样"98 个自由度值不值"才有答案 |

## 3. 身体和驱动

核心的身体是 75 个自由度：腿 12、腰椎 3、手臂 14、颈 2、手 44。
质量闭环算出来（[报告](报告/质量闭环.md)）：核心版 78~97 kg，完整版（98 个自由度）96~121 kg。多带 1 kg，总重要加 1.7~2 kg。
