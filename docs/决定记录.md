# 决定记录

每条写明：什么时候定的、定了什么、为什么、会影响什么。改主意时不删旧的，在后面加一条新的。

| 日期 | 决定 | 为什么 | 影响 |
|---|---|---|---|
| 2026-11-09 | 项目名、机体名都叫 **Nova** | 用户定 | 不用现有作品的名字和设计。机器人行业里已有同名产品（Dobot 的 Nova 协作机械臂），公开或商用前要查商标 |
| 2026-11-09 | **以后要做真机** | 用户定 | 仿真里的电机、传动、质量、电池、发热都按能买到或能做出来的部件来定；身体结构要能制造、能装配、能维修 |
| 2026-11-09 | 驱动用**关节电机**，但不是"一个关节一个电机"，要多个电机组合，让关节伸缩自如 | 用户定 | 具体怎么组合还在讨论，见 [多电机关节](research/02-多电机关节.md) |
| 2026-11-09 | 尺寸：**成人，约 1.7 m** | 用户定 | 和人的动作捕捉数据（AMASS）最匹配；平衡更难，真机更贵 |
| 2026-11-09 | **一开始就做完整的手** | 用户定 | 手指的驱动和触觉从第一版就要设计，仿真也更慢（要实测） |
| 2026-11-09 | 大脑主要用 **Python** | PyTorch 和各种模型都在 Python 里 | 网页画面还是 TypeScript |
| 2026-11-09 | 文档和画面用**中文** | 用户定 | |
| 2026-11-09 | `humen`（类脑结构）**以后再考虑**要不要接 | 用户定 | 现在不混在一起 |
| 2026-11-09 | 现在**只整理和讨论，不开发** | 用户定 | 先把身体结构、驱动、系统结构讨论清楚 |
| 2026-11-09 | 传感器：**该有的都要有**（做对动作的基建） | 用户定 | 像人的全装，再加对做对动作有用的（腕部和踝部力传感器、深度相机等）。统一时钟、标定、全部记录、冗余也算基建。见 [第二轮讨论](research/05-第二轮讨论.md) 第 3 节 |
| 2026-11-09 | 目标：**人能做的动作，Nova 都能做** | 用户定 | 力量、功率、关节范围按人的水平定；结构要更复杂（胸椎、肩胛上旋、脚）。见 [第二轮讨论](research/05-第二轮讨论.md) 第 2、4 节 |
| 2026-11-09 | 原则：**能做得更好的地方，就做得更好** | 用户定 | 第二轮讨论的建议全部采用：胸椎、下颈、肩胛上旋、大脚趾、足弓；手的全部改进，包括拇指和食指的成对驱动；可选的传感器也全装（仿真里按需打开）；另加眼睑。"更好"指对目标更有利，不是零件越多越好。结果见 [机体规格 v0.2](机体规格.md)：98 个自由度、90 个驱动器 |
| 2026-11-09 | **脸（表情、口型）先不做**，以后再考虑 | 用户定 | 眼睑照样做（保护相机）。头部给脸留位置：安装点、走线、重量余量 |
| 2026-11-09 | 机器本身不做肌肉：每个自由度一个驱动，冲击大的地方加弹簧和阻尼器；急停按分级停止 + 短路制动 | 用户问急停时肌肉会不会更好，分析后的结论 | 电机反应快（1~2 ms），低减速比让等效惯量小；断电时肌肉也不更好。见 [急停](research/06-急停.md) |
| 2026-11-09 | **系统结构 v1.0 确认**：4 层（思考脑、动作脑、小脑层、脊髓层）+ 安全 + 记录和学习；每层只收需要的传感器数据；一台中央计算机分成实时、AI、安全三个分区 + 外部安全控制器；下两层 C++、上两层 Python；ROS 2 + rmw_zenoh；平衡永远由小脑层负责，人优先于 AI | 用户确认（设计时不考虑现在能不能买到） | 见 [系统结构](系统结构.md) |
| 2026-11-09 | **每层的 AI 模型 v1.0 确认**：脊髓层不用 AI；小脑层照 SONIC + HOVER 为 Nova 自己训练；动作脑以 GR00T N1.7 为主、π0.5 对照、这台电脑先用 SmolVLA；思考脑 Cosmos Reason 2-8B（中文不够加 Qwen3-VL）+ 分开的语音小模型 | 用户确认 | 见 [AI 模型](AI模型.md) |
| 2026-11-09 | **以后要商用** | 用户定 | 只许研究的数据（AMASS、LAFAN1、SMPL-X、EgoDex 等）不进训练，动作和手部数据自己录或买商用授权；许可证逐项确认；商标、安全认证、隐私也要考虑。见 [商用要求](商用要求.md) |
| 2026-11-09 | **可以用云**：大规模训练用云上的大显卡 | 用户定 | 这台电脑只做小规模；思考脑联网时也可以用云，断网时用机器人上的模型 |

| 2026-11-09 | **成功的定义：两者都要**——能力证明（像人一样做各种动作）+ 产品（家里每天能用）。先在仿真里证明能力，同时把家务一项项做到可靠 | 用户定 | 见 [怎样做成一个真正成功的机器人](research/09-怎样做成一个真正成功的机器人.md) |
| 2026-11-09 | **第一件要做到可靠的事：家务** | 用户定 | 考场是仿真里的家；身体加家用要求（安静、防水、安全、能过门）；模型加家务的特别需要 |
