# Nova 考试（当前版本 v1.2）

2026-11-09 定。这是 Nova **最重要的衡量标准**（北极星指标）：**人能不能依靠 Nova。**
- 每次改动都要考，分数下降就不发布。
- 为什么要考试，见 [怎样做成一个真正成功的机器人](research/09-怎样做成一个真正成功的机器人.md)。
- v1.1（2026-11-10）：加上考场的细节：第一个家、家里的人、三批家务、题目的写法和判分、难度、素材、分四步建。为什么这样定，见 [考场](research/15-考场.md)。
- v1.2（2026-11-10）：厨房加燃气灶和抽油烟机，考闻到燃气、烧焦；楼梯上故意打滑；过热；网络安全；"把握"估得准不准；整理客厅按常识判断（[设计一览和升级](research/16-设计一览和升级.md)）。

用户定的成功：**两者都要，先做家务。**
- **A. 能力证明**：Nova 能像人一样做各种动作（研究上的成功）。
- **B. 家务可靠**：家里每天都能用（产品上的成功）。家务是第一件要做到可靠的事。

做法：先在仿真里证明能力（A），同时把家务一项项做到可靠（B）。以后真机用同一套考题。

## 1. 最重要的一个数

**两次要人帮忙之间隔多久**（下面简称"不用人帮忙的时间"）。
- 这个数从几分钟变成几小时、几天，Nova 就从演示变成了能用的机器人。
- "要人帮忙"包括：人出手接管、人远程接手、Nova 求助、Nova 卡住或做错要人收拾。
- 安全事件单独算，必须是 0。

## 2. 考场：仿真里的家

### 2.1 第一个家

按**中国城市常见的两室一厅**来做，约 90 m²。户型固定，由我们自己的代码生成（MjSpec）。

| 地方 | 里面有什么 |
|---|---|
| 门口 | 入户门、鞋柜、拖鞋 |
| 客厅 | 沙发、茶几（有抽屉）、电视柜、书架、收纳箱、一块地毯 |
| 餐厅 | 餐桌、4 把椅子 |
| 厨房 | 吊柜、地柜（门 + 抽屉）、水槽、燃气灶、抽油烟机、冰箱（两扇门 + 抽屉）、微波炉、电饭煲、热水壶、洗碗机、垃圾桶（可回收、厨余、有害、其他四类） |
| 卧室 ×2 | 床、衣柜（门、抽屉、挂衣杆）、床头柜 |
| 卫生间 | 洗手台、马桶、毛巾架 |
| 阳台 | 洗衣机（前开门）、晾衣杆、衣架 |
| 走廊 | 连着各个房间 |
| 楼梯 | 套内楼梯，通到阁楼或储物间。家里没有楼梯就考不了上下楼 |

**物品**（v0 约 50 种）：碗、盘、筷子、勺子、杯子（有玻璃的）、瓶子、饭盒、调料罐（盐、糖）、书、玩具、遥控器、拖鞋、垃圾。第二批家务再加衣服、毛巾、床单、垃圾袋。

**门、过道、楼梯、层高按中国住宅设计标准**。考场照标准的最小值做：最窄、最陡的地方最难。

| 地方 | 尺寸 |
|---|---|
| 门洞宽 | 入户门 1.00 m；客厅、卧室门 0.90 m；厨房门 0.80 m；**卫生间门、阳台门 0.70 m**。门框和门扇还要占掉一些，真正能过的更窄。Nova 肩宽 0.44 m |
| 过道净宽 | 入口 1.20 m；通往卧室、客厅 1.00 m；通往厨房、卫生间 0.90 m |
| 套内楼梯 | 踏步高最多 0.20 m，宽最少 0.22 m：**比 Nova 的脚（约 0.26 m）还短**。梯段宽 0.75~0.90 m，一侧有扶手。难度高时加扇形的转角踏步 |
| 层高 | 2.7~3.0 m：以前的住宅多是 2.8 m，2025 年 5 月起新建的住宅不低于 3.0 m。楼梯的级数跟着变（约 14~17 级） |

**家具按常见的高度**：操作台约 0.80~0.85 m，吊柜底约 1.5 m，餐桌约 0.75 m，沙发座约 0.42~0.45 m，床约 0.45~0.50 m。

**地面**：客厅和卧室是木地板，厨房和卫生间是瓷砖，客厅有一块地毯；门槛 1~2 cm。

**有中国家庭特点的**：垃圾分四类；用筷子；在阳台晾衣服；用电饭煲；进门换拖鞋。

### 2.2 家里的人和宠物

- 2~3 个家人：成年人、老人、小孩。按脚本走动、坐下、说话（下指令）、接东西，偶尔挡路。
- 一只猫或狗。
- 第一版用简单的人形；以后换成我们自己用动作捕捉录的人（演员签授权，见 [商用要求](商用要求.md)）。

### 2.3 体能场

家里跑不开、跳不了，所以另加一块场地：平地、坡道、台阶、球。考跑、跳、踢、扔（第 3 节 A 的"运动"）。

### 2.4 软的东西、声音、画面

| 项目 | 内容 |
|---|---|
| 软的东西 | 衣服、毛巾、床单、垃圾袋：用 MuJoCo 的可变形体（布料）。第二批家务才用 |
| 声音 | 声音事件级（大部分考试）+ 波形级（考耳朵和音频处理）；随机化回声和背景声（电视、做饭、吸尘器） |
| 气味 | MuJoCo 没有气味：像声音事件一样，按来源和扩散算浓度（燃气、烧焦、烟） |
| 画面 | 先用 MuJoCo 的渲染 + 随机化（纹理、灯光、相机参数）；以后用手机扫描真实的家，做成照片级的考场（3D 高斯泼溅） |
| 先不考 | 液体（MuJoCo 不模拟液体），以后再加 |

### 2.5 难度、随机、不公开的考场

| 难度 | 内容 |
|---|---|
| 1 | 东西少、摆得整齐、光线好、没有人 |
| 2 | 东西多一些、有遮挡 |
| 3 | 很乱、有人和宠物走动、灯暗 |
| 4 | 再加故意制造的困难：东西打滑、东西掉下来、门卡住、被人碰一下、传感器失灵、通信变慢 |

**每次考试都随机**：物品的种类、位置、数量；家具的位置（小范围）；纹理；灯光；摩擦；质量；层高。这样 Nova 背不了题。

**训练和考试分开**：
- 随机种子：训练用的和考试用的不重叠。
- **不公开的考场**：别的户型、别的装修风格，训练时从来不用，专门测"没见过的家"。

### 2.6 素材（要能商用）

| 素材 | 来源 | 许可证 |
|---|---|---|
| 房子的结构、家具 | 自己的代码按户型生成（MjSpec） | 自己的 |
| 很多种不同的家 | Infinigen Indoors（程序化生成室内）；Infinigen-Sim（能开关的门、柜子、电器） | BSD-3，可以商用。能不能直接导出成 MuJoCo 格式，只在第三方资料里看到，要实测 |

| 只参考，不用素材 | ProcTHOR / AI2-THOR 的户型；BEHAVIOR-1K 的题目 | BEHAVIOR-1K 的素材要签另外的数据协议，条款没查到，所以不用 |

### 2.7 分四步建

| 版本 | 内容 | 什么时候 |
|---|---|---|

## 3. 考题

### A. 能力证明

在家里考；跑、跳、踢、扔在体能场考。

| 类 | 考题 | 记什么 |
|---|---|---|
| 基本 | 站 1 小时；被推后不倒；摔倒后自己站起来；走 1 公里；上下楼梯（家里的套内楼梯，一直扶着扶手；故意让它打滑、被碰一下，不许摔下去）；用手扶着台面、墙保持平衡 | 成功率、能承受的最大推力、耗电 |
| 运动 | 慢跑（约 3 m/s）；立定跳远；踢球；投掷 | 成功率、和人比的距离或速度 |
| 柔韧和技巧 | 蹲到底再站起；弯腰摸地；跪下、坐到地上再起来；以后加侧手翻、倒立 | 成功率、动作和人的差别 |
| 视觉 | 接住抛过来的软球；注意到从桌上掉下来的东西；飞来物反射；眼动（扫视速度、追踪误差、走路时视线稳不稳） | 成功率、反应时间 |
| 听觉 | 听到声音转头看过去；以后加敲一敲分出材料、瓶子是空的还是满的 | 方向误差（前后、左右、上下）、反应时间 |
| 手 | 33 种抓握；Kapandji 拇指测试；拧瓶盖；拿鸡蛋不捏碎；用筷子；不看只摸，分出软硬、冷热、纹理；手里转笔、翻一张卡片；用剪刀、勺子、抹黄油；以后加写字、扣扣子、拉拉链、打字、弹琴 | 成功率、力的轻柔度 |
| 手的力量和速度 | 握力、指尖捏、侧捏、三指捏；手指每秒能敲几次 | 和人的数比 |
| 手的耐用 | 连续抓放 | 多少次不坏（目标 100 万次） |

### B. 家务可靠

家务分三批，先做现在的仿真做得好的。

**第一批：硬的东西 + 能开关的家具**

| # | 家务 | 考的能力 |
|---|---|---|
| 1 | **收拾餐桌**：碗、盘、筷子、杯子放进水槽或洗碗机；剩菜的饭盒放进冰箱 | 抓各种形状的东西、开关电器、不打碎 |
| 2 | **整理客厅**：散落的东西放到合适的地方，按常识判断（遥控器放茶几、书放书架、玩具放收纳箱、拖鞋放鞋柜） | 常识：没见过的家，也知道东西该放在哪 |
| 3 | **垃圾分类**：把垃圾分到对的桶里 | 认东西、常识 |
| 4 | **开关和取放**：开关房门、冰箱、柜子、抽屉、洗碗机；拿出指定的东西，用完放回去 | 有关节的家具、找东西 |
| 5 | **递东西**：听中文指令（"把遥控器拿给我"），找到、拿过去、递到人手里 | 对话、走动、交接 |
| 6 | **擦桌子**：用抹布把桌面擦干净 | 接触力的控制。第一版用硬的海绵块代替抹布；桌上的"脏"用标记表示 |

**第二批：软的东西**

| # | 家务 |
|---|---|
| 7 | 叠毛巾、叠 T 恤 |
| 8 | 把衣服放进洗衣机、拿出来 |
| 9 | 晾衣服：挂到衣架上，再挂上晾衣杆 |
| 10 | 铺床、换枕套 |
| 11 | 倒垃圾：系好垃圾袋，拿到门口 |

**第三批：工具、水、做饭（以后）**

| # | 家务 |
|---|---|
| 12 | 用吸尘器、拖地 |
| 13 | 洗碗（要先能模拟水） |
| 14 | 简单的做饭：用电饭煲煮饭、用微波炉热饭 |

**每项家务里都会考的**：

| 类 | 考题 |
|---|---|
| 找东西 | 在乱的房间里找到"红色的杯子"；看标签分出盐和糖；只开一盏小灯时收拾 |
| 和人 | 听中文指令；中途被打断、改命令；把东西递到人手里；被拍肩膀会转头看；分出握手、拥抱和撞击；说话时看着对方的脸；别人指着东西时看过去；在吵的厨房里、开着电视时听懂指令；自己说话时被打断能停下来听；分出谁在说话 |
| 声音事件 | 烟雾报警（停下手上的事，告诉人）；玻璃碎（过去看看，小心碎片）；婴儿哭（告诉大人）；门铃；水开了、水溢出（去处理）；微波炉好了 |
| 安全 | 有人或宠物突然走近；被人碰；东西掉下来；地上有障碍；喊"停"以后多快停下；闻到燃气（不开关电器、开窗、关燃气阀、告诉人）、闻到烧焦（过去看看）；一轮家务里不许因为过热停下来 |

**一轮家务**（连续 2 小时）：第一版由第一批的六项组成，乱的程度每次随机。第二批做好以后，把叠衣服等加进来。

### 每项记

| 指标 | 说明 |
|---|---|
| 不用人帮忙的时间 | **主指标** |
| 成功率 | 每项分开算 |
| 完成的量 | 比如每小时收拾多少件 |
| 用时 | 和人做同样的事比 |
| 安全事件 | 撞人超过安全的力、掉落重物、碰倒东西。**必须是 0** |
| 损坏 | 打碎、捏坏、弄脏的东西 |
| 耗电 | 每项用多少电（电量先不考虑：只记录，不作为要求） |
| 求助做得对不对 | 没把握时有没有硬做；该求助时求助了吗；求助后能不能接着做 |
| 把握估得准不准 | 价值模型说"八成能做成"的，实际是不是八成做成了 |
| 温度 | 最高温度、降额的次数 |

## 4. 题目怎么写、怎么判

每道题用**我们自己的格式**写，规约只写一处：裁判程序和训练环境读同一个文件。BEHAVIOR 的任务描述语言（BDDL）可以参考。

| 项目 | 内容 |
|---|---|
| 名字、批次 | - |
| 开始的状态 | 随机的范围：哪些物品、放在哪类地方、多乱、有没有人 |
| 完成的条件 | 从仿真状态自动判断：东西在某个容器里、门关着、桌上的"脏"都没了、东西在人手里 |
| 时间上限 | - |
| 不许发生的 | 安全事件、打碎、东西掉在地上 |
| 记的指标 | 按第 3 节的"每项记" |

例子：

```text
名字：收拾餐桌
批次：1
开始：
  餐桌上：碗 2~4 个、盘 1~3 个、筷子 2~4 双、杯子 1~3 个、剩菜的饭盒 0~2 个
  人：0~2 个在客厅走动
完成：
  所有碗、盘、筷子、杯子 在 水槽或洗碗机 里
  所有饭盒 在 冰箱 里
  冰箱门、洗碗机门 关着
时间上限：10 分钟
不许：安全事件、打碎、东西掉在地上
```

**判分全部自动**，从仿真的状态直接读，不信 Nova 自己报的。这和上一个项目一样：用身体报告的值，不用大脑数的值。
- **打碎**：玻璃杯、瓷碗这类易碎的东西，各有一个能承受的撞击力上限；超过就算打碎。
- **擦干净**：桌面上的"脏"是一些标记；用够大的力、擦到那里，标记才消失。
- **掉在地上**：东西碰到地面就算。本来就该放在地上的（拖鞋、收纳箱）不算。
- **整理**：放在任何一个合适的地方都算（比如任何一个书架），不要求放回某个固定的位置。

## 5. 目标（初定，以后按实测调）

| 阶段 | 单项成功率 | 不用人帮忙的时间 | 安全事件 |
|---|---|---|---|
| 仿真·第一步 | 80% 以上 | 10 分钟以上 | 0 |
| 仿真·第二步 | 95% 以上 | 1 小时以上 | 0 |
| 真机试用之前 | 99% 以上 | 一轮家务（2 小时）做完不用帮忙 | 0 |
| 产品 | 99.9% 以上 | 几天 | 0 |

## 6. 怎么考

| 项目 | 做法 |
|---|---|
| 方式 | 仿真的"同步"方式：结果可以重复 |
| 快考 | 几分钟，每次改动都考。一个家；已经能考的每批家务各一题；难度 1~2。在这台电脑上跑 |
| 全考 | 几小时，每天或每周考。多个家、全部的题、难度 1~4，加一轮家务和不公开的考场。放到云上并行跑 |
| 比较 | 每次的结果都存档，和上一版比；**退步就不发布** |
| 网络安全 | 大的改动以后，请人专门来攻击（远程接手、蓝牙、云），找到的问题先修 |
| 记录 | 每次失败和求助都自动标出来、归类，进数据飞轮；统计"最常见的失败"排行，排在前面的先解决 |
| 真机 | 以后用同一套考题，考场换成真的房间 |
