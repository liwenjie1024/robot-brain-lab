# Nova 考试（当前版本 v1.0）

2026-11-09 定。这是 Nova **最重要的衡量标准**（北极星指标）：**人能不能依靠 Nova。**
- 每次改动都要考，分数下降就不发布。
- 为什么要考试，见 [怎样做成一个真正成功的机器人](research/09-怎样做成一个真正成功的机器人.md)。

用户定的成功：**两者都要，先做家务。**
- **A. 能力证明**：Nova 能像人一样做各种动作（研究上的成功）。
- **B. 家务可靠**：家里每天都能用（产品上的成功）。家务是第一件要做到可靠的事。

做法：先在仿真里证明能力（A），同时把家务一项项做到可靠（B）。以后真机用同一套考题。

## 1. 最重要的一个数

**两次要人帮忙之间隔多久**（下面简称"不用人帮忙的时间"）。
- 这个数从几分钟变成几小时、几天，Nova 就从演示变成了能用的机器人。
- "要人帮忙"包括：人出手接管、人远程接手、Nova 求助、Nova 卡住或做错要人收拾。
- 安全事件单独算，必须是 0。

## 2. 考场：仿真里的家

| 项目 | 内容 |
|---|---|
| 房间 | 厨房、客厅、卧室、浴室、走廊、楼梯 |
| 家具和电器 | 桌子、椅子、沙发、床、柜子、抽屉、门；冰箱、洗碗机、洗衣机、微波炉、水槽 |
| 物品 | 餐具、杯子、瓶子、食物盒、衣服、毛巾、书、玩具、遥控器、垃圾 |
| 软的东西 | 衣服、毛巾、床单：用 MuJoCo 的可变形体（布料） |
| 地面 | 木地板、瓷砖、地毯、门槛 |
| 会动的 | 走动的人、宠物 |
| 先不考 | 液体（MuJoCo 不模拟液体），以后再加 |

**每次考试都随机**：物品的位置、种类、数量、光照、摩擦、质量。这样 Nova 背不了题。
- 一部分考场**不公开**，训练时从来不用，专门测"没见过的家"。
- **故意制造困难**：东西掉下来、门卡住、被人碰一下、东西打滑、传感器失灵、通信变慢。

## 3. 考题

### A. 能力证明

| 类 | 考题 | 记什么 |
|---|---|---|
| 基本 | 站 1 小时；被推后不倒；摔倒后自己站起来；走 1 公里；上下楼梯 | 成功率、能承受的最大推力、耗电 |
| 运动 | 慢跑（约 3 m/s）；立定跳远；踢球；投掷 | 成功率、和人比的距离或速度 |
| 柔韧和技巧 | 蹲到底再站起；弯腰摸地；跪下、坐到地上再起来；以后加侧手翻、倒立 | 成功率、动作和人的差别 |
| 手 | 33 种抓握；Kapandji 拇指测试；拧瓶盖；拿鸡蛋不捏碎；用筷子；不看只摸，分出软硬、冷热、纹理；以后加写字 | 成功率、力的轻柔度 |

### B. 家务可靠

| 类 | 考题 |
|---|---|
| 收拾 | 收拾餐桌：餐具放进洗碗机或水槽；把房间里的东西放回原处；倒垃圾 |
| 清洁 | 擦桌子；用吸尘器 |
| 衣物 | 叠衣服和毛巾；把衣服放进、拿出洗衣机；铺床 |
| 开关 | 开关门、抽屉、柜子、冰箱、洗碗机 |
| 和人 | 听中文指令（"把遥控器拿给我"）；中途被打断、改命令；把东西递到人手里；被拍肩膀会转头看；分出握手、拥抱和撞击 |
| 安全 | 有人或宠物突然走近；被人碰；东西掉下来；地上有障碍 |
| 连续工作 | **一轮家务**：连续 2 小时收拾客厅、厨房、叠衣服，乱的程度每次随机 |

每项记：

| 指标 | 说明 |
|---|---|
| 不用人帮忙的时间 | **主指标** |
| 成功率 | 每项分开算 |
| 完成的量 | 比如每小时收拾多少件 |
| 用时 | 和人做同样的事比 |
| 安全事件 | 撞人超过安全的力、掉落重物、碰倒东西。**必须是 0** |
| 损坏 | 打碎、捏坏、弄脏的东西 |
| 耗电 | 每项用多少电；一次充电能做多少 |
| 求助做得对不对 | 没把握时有没有硬做；该求助时求助了吗；求助后能不能接着做 |

## 4. 目标（初定，以后按实测调）

| 阶段 | 单项成功率 | 不用人帮忙的时间 | 安全事件 |
|---|---|---|---|
| 仿真·第一步 | 80% 以上 | 10 分钟以上 | 0 |
| 仿真·第二步 | 95% 以上 | 1 小时以上 | 0 |
| 真机试用之前 | 99% 以上 | 一轮家务（2 小时）做完不用帮忙 | 0 |
| 产品 | 99.9% 以上 | 几天 | 0 |

## 5. 怎么考

| 项目 | 做法 |
|---|---|
| 方式 | 仿真的"同步"方式：结果可以重复 |
| 快考 | 几分钟。每次改动都考 |
| 全考 | 几小时。每天或每周考，包括一轮家务和不公开的考场 |
| 比较 | 每次的结果都存档，和上一版比；**退步就不发布** |
| 记录 | 每次失败和求助都自动标出来、归类，进数据飞轮；统计"最常见的失败"排行，排在前面的先解决 |
| 真机 | 以后用同一套考题，考场换成真的房间 |
