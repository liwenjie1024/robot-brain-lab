# 商用要求

2026-11-09 定了 **Nova 以后要商用**。这份列出商用会影响的地方，设计和选东西时对照。
我不是律师。下面是"要注意什么"，真正商用前，许可证、商标、认证、隐私都要找专业的人确认。

| 方面 | 要求 | 现在怎么做 | 什么时候要定 |
|---|---|---|---|
| 许可证 | 进入产品的模型、数据、软件，都要允许商用 | [AI 模型](AI模型.md) 第 10 节的表；新加的东西先查许可证再用 | 每次选型时 |
| 训练数据 | 自己录，或者买有商用授权的。只许研究的数据（AMASS、LAFAN1、SMPL-X、EgoDex 等）不进训练 | 主要来自仿真里的训练（2026-11-10 用户定，没有许可证问题）；另外自己录"Nova 动作库"（动作捕捉服，演员签授权）、手部数据（VR 手部追踪 + 数据手套）、遥控示范 | 开始录数据之前 |
| 仿真的素材 | 考场和训练环境里的房子、家具、日用品、纹理也要能商用；CC BY 的要注明出处 | 自己生成的 + Infinigen（BSD-3）+ Google Scanned Objects（CC BY 4.0）+ CC0 纹理；BEHAVIOR-1K 的素材不用。见 [Nova 考试](Nova考试.md) 2.6 节 | 选素材时 |
| 名字 | "Nova" 在机器人行业已有同名产品（Dobot 的 Nova 协作机械臂） | 先用着 | 公开或商用之前查商标，必要时改名 |
| 安全认证 | 人形机器人的安全标准还在制定：工业用的 ISO 25785-1 是草案；家用、服务用看 ISO 13482；功能安全看 IEC 61508 | 系统结构里的安全分区 + 外部安全控制器 + 分级停止，已经按这个方向设计；碰到人的力按 ISO/TS 15066 给的人身体各部位的上限（2026-11-11 加）；母线超过 60 V 按高压做（绝缘、防触电、关机放电） | 做真机之前 |
| 隐私 | 相机、麦克风会拍到人、录到话。中国的《个人信息保护法》、欧盟的 GDPR 等都要遵守 | 开发和测试时全部记录；产品里另定"产品模式"：尽量在机器人上处理、要用户同意、限制保存时间、上传到云之前去掉能认出人的信息。听觉：声音事件一直听但不录音，叫名字或被问话时才转文字，听的时候有指示灯。用手机扫描真实的家做考场时，要房主同意，扫描前收起照片、证件这类能认出人的东西 | 做产品之前；扫描第一个真实的家之前 |
| 网络安全 | 家里的机器人有相机、麦克风，能被远程接手，连着云：被攻破就能看、能听、能动 | 按[系统结构](系统结构.md) 5.6 节：只运行签过名的软件和模型、不留后门、加密、远程接手要同意、安全的上限谁都改不了、记录、补漏洞；标准看 IEC 62443、ETSI EN 303 645、欧盟 EN 18031 系列 | 从现在起按这个设计；做真机之前请专业的人检查 |
| 云 | 训练用云（已定）；思考脑联网时可以用云上的大模型 | 断网也要能用（机器人上的模型兜底）；上传的数据按隐私规则 | - |
| 依赖的软件 | ROS 2、MuJoCo 是 Apache 2.0；其它（mjlab 等）逐项查 | - | 选型时 |
| 我们自己的代码 | 将来闭源还是开源、用什么许可证 | 还没定 | 公开之前 |
