# 技术栈

用了什么、哪个版本、为什么。加库、换库要改这份。
规则：版本写死；新版本发布超过两周才用；新的东西先查许可证（[AI 模型](AI模型.md) 第 10 节）。

这里只列**已经在用的**。计划要用的（ROS 2、rmw_zenoh、mjlab、各个模型）在 [系统结构](系统结构.md) 和 [AI 模型](AI模型.md) 里，用到的时候再加进来。

| 用在哪 | 技术 | 版本 | 为什么 | 没选的 |
|---|---|---|---|---|
| 身体：运行环境 | Python，在 Docker 的 Linux 容器里 | `python:3.13.18-slim`，按 digest 写死（`sha256:e48f59cd…ed90`） | 这台电脑的 Windows 会拦没有签名的 `mujoco.dll`，所以只在容器里跑。3.13 是上一个项目验证过的 | 直接在 Windows 上跑（要关安全设置，不行） |
| 身体：计算 | NumPy | 2.5.4 | 拟合"驱动器有多重"的幂律；以后的向量计算 | - |
| 身体：物理 | MuJoCo | 3.17.0 | 关节和接触准、快；能用代码（MjSpec）生成模型。上一个项目在这台电脑上验证过。P1 的 1.2 步开始用：生成身体的模型、在仿真里站着。实测 75 个自由度的身体约是实时的 15 倍 | Isaac Lab（要 16 GB 显存，这台电脑只有 8 GB） |
| 身体：基线的模型 | Unitree G1 的 MuJoCo 模型（MuJoCo Menagerie 的 `unitree_g1/g1.xml`，29 个自由度） | 提交 `cda5236f9838`（2026-10-20），清单在 `third_party/unitree_g1.json` | 现成的、公开的、能商用的身体，练好的权重（SONIC）就是给它练的。按清单下载，每个文件核对 SHA-256，不提交进仓库（`third_party.py`，只用 Python 自带的库） | 同一个目录里的 `g1_mjlab.xml`（没有驱动器和力矩的上限，要自己写）、`g1_with_hands.xml`（带三指的手，到比抓东西时再加）；把文件提交进仓库（20 MB 的网格会一直留在历史里） |
| 身体：画图 | 自己写的 SVG（`drawing.py`，只用 NumPy） | - | 把模型的每个形状投影成多边形，画正面和侧面；现成模型的网格画成凸包。不用显卡、不加库，画出来的文件每次一样，能放进报告 | MuJoCo 自带的渲染（要 OpenGL，现在的容器里没有；做网页（1.4）时再定 3D 怎么画） |
| 身体：检查 | pytest、Ruff | 9.2.0、0.17.3 | 测试；格式和代码规则 | - |
| 仿真：给网页的服务 | aiohttp | 3.14.5 | 一个库就有 HTTP 和 WebSocket；上一个项目在这台电脑上用的就是这个版本 | 只用 Python 自带的库（没有 WebSocket）；FastAPI（要再加一个服务器的库） |
| 规约 | JSON Schema（`contracts/sim`）；Python 用 jsonschema，网页用 ajv | jsonschema 4.26.0、ajv 8.20.0 | 消息长什么样只写一处，仿真和网页用同一份文件检查 | 两边各写一遍（会对不上） |
| 网页：运行环境 | Node.js（直接在这台电脑上跑，不在容器里） | 24.15.0 | 网页的工具没有被智能应用控制拦住；上一个项目就是这样跑的 | 放进容器（要多一个镜像，改了代码刷新也慢） |
| 网页：框架和界面 | Vue 3 + TypeScript + Naive UI | vue 3.5.44、typescript 5.9.3、naive-ui 2.45.3 | [系统结构](系统结构.md) 6.3 节定的，和上一个项目一样；版本也一样，这台电脑上验证过 | - |
| 网页：3D | three.js | 0.186.1（类型 @types/three 0.186.0） | 在浏览器里用显卡画 3D。身体的形状从仿真拿，网页不认身体是哪一个 | 在仿真那边渲染成图片再传过来（容器里没有 OpenGL，也慢） |
| 网页：开发和打包 | Vite（插件 @vitejs/plugin-vue） | 8.3.4（6.0.10） | 开发时改了代码马上看到；把发给仿真的请求转过去，网页和仿真就是同一个地址 | - |
| 网页：检查 | Vitest（jsdom、@vue/test-utils）、ESLint（eslint-plugin-vue、@vue/eslint-config-typescript）、vue-tsc | vitest 5.0.5、jsdom 30.1.3、@vue/test-utils 2.5.1、eslint 10.13.0、eslint-plugin-vue 10.11.1、@vue/eslint-config-typescript 14.9.0、vue-tsc 3.3.13、@vue/tsconfig 0.9.1、@types/node 24.19.2 | 测试；代码规则；类型检查 | - |
| 网页：照规约生成类型 | json-schema-to-typescript | 16.0.0 | 网页里消息的类型是照 JSON Schema 生成的，不手写 | - |

许可证：Python（PSF）、NumPy（BSD-3）、MuJoCo（Apache 2.0）、pytest（MIT）、Ruff（MIT）、Unitree G1 的模型（BSD-3）、aiohttp（Apache 2.0）、jsonschema（MIT）、Node.js（MIT）、TypeScript（Apache 2.0）、Vue、Naive UI、three.js、Vite、Vitest、jsdom、ESLint、vue-tsc、ajv、json-schema-to-typescript（都是 MIT），都可以商用。
