# Nova（humanoid 分支）

目标：做一个真正像人、真正能被人依靠的人形机器人 Nova。先在物理仿真里做，以后做真机。第一件要做到可靠的事是**家务**。
- 成人大小（约 1.7 m），一开始就有完整的手
- 有本体感觉、平衡感、触觉、视觉、听觉
- 按人的神经系统分层控制，从脊髓反射到计划和对话

**现在是整理和讨论阶段，还不写代码。**
